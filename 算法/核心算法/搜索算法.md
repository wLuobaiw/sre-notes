# 搜索算法

## 1. 概念导入

在字典里查一个单词，你是从头翻到尾（线性搜索），还是直接翻到大概的字母位置再前后找（二分搜索）？搜索算法解决的就是"在数据中找到目标"的问题。高效搜索的前提是数据有序或组织合理——就像你对一个乱糟糟的房间无从下手，但一个整洁的书架能让你几秒找到想要的书。

---

## 2. 核心原理

### 2.1 线性搜索（Linear Search）

从头到尾逐个遍历，检查每个元素是否为目标。最直觉的方法，不要求数据有序。

```
数组：[3, 7, 1, 9, 4]，找 9

  → [3] ≠ 9
  → [7] ≠ 9
  → [1] ≠ 9
  → [9] == 9 ✓  返回下标 3
```

最坏情况：遍历整个数组，时间复杂度 O(n)。

### 2.2 二分搜索（Binary Search）

前提：数组**必须有序**。每次与中间元素比较，根据大小关系直接排除一半元素。

```
有序数组：[1, 3, 4, 7, 9, 12, 15]，找 9

左=0  右=6  → mid=3   → arr[3]=7 < 9 → 排除左半 → 左=4
左=4  右=6  → mid=5   → arr[5]=12 > 9 → 排除右半 → 右=4
左=4  右=4  → mid=4   → arr[4]=9 == 9 ✓  返回 4
```

一共 3 次比较（对比线性搜索需要 5 次）。数据量越大，二分搜索的优势越明显。

### 2.3 BFS（广度优先搜索）与 DFS（深度优先搜索）

两者用于遍历树或图结构，核心区别在于搜索的顺序。

```
以这棵树为例：
         A
       /   \
      B     C
     / \   / \
    D   E F   G

BFS（逐层，用队列）：
    A → B → C → D → E → F → G

DFS（深入到底再回溯，用栈/递归）：
    A → B → D → E → C → F → G
```

**BFS** 使用队列（先进先出），先访问离起点近的节点，适合找最短路径。

**DFS** 使用栈（后进先出）或递归，先沿着一条路走到底再回头，适合探索所有路径。

## 3. Python 短代码辅助理解

### 3.1 二分搜索（手动实现）

```python
def binary_search(arr, target):
    """
    在有序数组 arr 中搜索 target，返回下标，未找到返回 -1。
    为什么用 while left <= right 而不是 while left < right：
    当 left == right 时，还有一个元素没检查，不能漏掉。
    """
    left, right = 0, len(arr) - 1

    while left <= right:
        # 为什么不用 (left + right) // 2：防止 left+right 整数溢出
        mid = left + (right - left) // 2

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1   # 目标在右半，收缩左边界
        else:
            right = mid - 1  # 目标在左半，收缩右边界

    return -1


arr = [1, 3, 4, 7, 9, 12, 15]
print(f"搜索 9：下标 {binary_search(arr, 9)}")    # 输出 4
print(f"搜索 6：下标 {binary_search(arr, 6)}")    # 输出 -1
```

### 3.2 BFS —— 逐层遍历二叉树

```python
from collections import deque


def bfs(root):
    """
    广度优先遍历二叉树。
    为什么用队列：队列先进先出，先入队的节点先处理，保证逐层。
    """
    if not root:
        return []

    result = []
    queue = deque([root])  # 初始化队列，根节点入队

    while queue:
        # 从队首取出一个节点处理
        node = queue.popleft()
        result.append(node.value)

        # 子节点入队（先左后右，保持层内从左到右）
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)

    return result
```

### 3.3 DFS —— 深度优先遍历二叉树

```python
def dfs_recursive(node, result):
    """
    深度优先遍历二叉树（递归版本）。
    为什么 DFS 天然适合递归：递归就是"先深入到底再回溯"，
    和 DFS 的"走到底再回头"完全一致。
    """
    if not node:
        return

    result.append(node.value)   # 访问当前节点
    dfs_recursive(node.left, result)   # 深入左子树
    dfs_recursive(node.right, result)  # 深入右子树


def dfs_stack(root):
    """
    深度优先遍历二叉树（栈版本）。
    为什么用栈：后进先出，后入栈的子节点先处理，
    保证先沿着一条路径走到底。
    """
    if not root:
        return []

    result = []
    stack = [root]

    while stack:
        node = stack.pop()
        result.append(node.value)
        # 为什么先压右再压左：栈是后进先出，
        # 先压右能保证左子树先被处理（DFS 从左到右）
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)

    return result
```

## 4. 复杂度与适用场景

| 算法 | 时间复杂度 | 空间复杂度 | 前提条件 | 适用场景 |
|------|-----------|-----------|---------|---------|
| 线性搜索 | O(n) | O(1) | 无 | 无序小数据、数据无规律 |
| 二分搜索 | O(log n) | O(1)（迭代）/ O(log n)（递归） | 数据必须有序 | 有序静态数据（前缀匹配等） |
| BFS | O(V+E) | O(V)（队列 + visited） | 图已知 | 最短路径、层级遍历 |
| DFS | O(V+E) | O(h)（栈深度） | 图已知 | 连通性检测、拓扑排序、路径枚举 |

## 5. 常见变体

### 三分搜索
将搜索区间分成三等份，比较两个分割点后排除 2/3 的区域。适用于**单峰函数**求极值（而非查找值），每次排除 1/3，但每次需两次比较。

### A* 搜索
BFS 的启发式改进版：引入估价函数 `f(n) = g(n) + h(n)`，其中 `g(n)` 是起点到 n 的实际代价，`h(n)` 是 n 到终点的估计代价。优先选择 `f(n)` 最小的节点，广泛应用于路径规划（如游戏中的自动寻路）。

## 6. 经典题目：LeetCode 704 二分查找

### 题目描述
给定一个 n 个元素有序的（升序）整型数组 nums 和一个目标值 target，写一个函数搜索 nums 中的 target，如果目标值存在返回下标，否则返回 -1。

### 思路分析
标准的二分搜索实现。关键点：

1. 区间定义：使用 `[left, right]` 闭区间，所以循环条件是 `while left <= right`。
2. 中间点计算：用 `left + (right - left) // 2` 避免整数溢出。
3. 边界收缩：每次排除 mid 后，新区间不包含 mid（`mid+1` 或 `mid-1`），避免死循环。

### 完整代码

```python
def search(nums, target):
    """
    二分搜索标准实现。
    
    为什么用闭区间 [left, right]：
    这是最常见的版本，边界条件直观，容易验证正确性。
    """
    left, right = 0, len(nums) - 1

    while left <= right:
        # 防止 left + right 在 Python 中不会溢出，
        # 但这是二分搜索的标准写法，体现工程习惯
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1   # 目标在右侧，收缩左边界
        else:
            right = mid - 1  # 目标在左侧，收缩右边界

    return -1


def test():
    """
    测试用例：
    - 目标存在
    - 目标不存在
    - 单元素数组
    - 空数组
    """
    test_cases = [
        ([-1, 0, 3, 5, 9, 12], 9, 4),    # 目标存在
        ([-1, 0, 3, 5, 9, 12], 2, -1),   # 目标不存在
        ([5], 5, 0),                      # 单元素，目标存在
        ([5], 3, -1),                     # 单元素，目标不存在
        ([], 1, -1),                      # 空数组
        ([1, 2, 3, 4, 5], 1, 0),         # 目标在最左端
        ([1, 2, 3, 4, 5], 5, 4),         # 目标在最右端
    ]

    for nums, target, expected in test_cases:
        result = search(nums, target)
        status = "通过" if result == expected else "失败"
        print(f"nums={str(nums):30s} target={target:2d} => {result:2d} "
              f"(预期{expected:2d}) [{status}]")


if __name__ == "__main__":
    test()
```
