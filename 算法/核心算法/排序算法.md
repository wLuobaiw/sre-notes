# 1. 概念导入

整理扑克牌时，你会按大小重新排列，把小的放左边、大的放右边。排序算法就是教计算机如何高效地完成这件事。不同算法有不同的策略——有的像冒泡一样慢慢"浮"到正确位置，有的像快速整理文件柜一样分区处理，理解它们能帮你写出更高效的代码。

# 2. 核心原理

## 2.1 冒泡排序（Bubble Sort）

从左到右依次比较相邻元素，如果前一个比后一个大，就交换。每轮结束后，最大的元素会像气泡一样"浮"到末尾。

```
第一轮（找最大值 9）：
[5, 3, 8, 6, 9, 1]
 5 > 3? → 交换 → [3, 5, 8, 6, 9, 1]
 5 > 8? → 不动
 8 > 6? → 交换 → [3, 5, 6, 8, 9, 1]
 8 > 9? → 不动
 9 > 1? → 交换 → [3, 5, 6, 8, 1, 9]  ← 9 到位

第二轮（找次大值 8）：
[3, 5, 6, 8, 1, 9]
 3 > 5? → 不动
 5 > 6? → 不动
 6 > 8? → 不动
 8 > 1? → 交换 → [3, 5, 6, 1, 8, 9]  ← 8 到位

...以此类推，每轮少比较一个。
```

## 2.2 快速排序（Quick Sort）

选一个元素作为基准（pivot），将小于它的放左边、大于它的放右边（分区），然后递归地对左右两部分做同样的操作。

```
以 [5, 3, 8, 6, 1] 为例，选 1 为 pivot：

第一步：分区
[5, 3, 8, 6, 1]
 5 > 1 → 不动   3 > 1 → 不动   8 > 1 → 不动
 6 > 1 → 不动   1 自身就是 pivot
→ pivot 交换到位置 0： [1, 3, 8, 6, 5]
  （实际实现中分区过程是原地交换的）

第二步：递归排序右半部分 [3, 8, 6, 5]，选 5 为 pivot...
```

## 2.3 归并排序（Merge Sort）

利用分治思想，先将数组切分成单个元素，再两两合并成有序数组。详见"递归与分治"笔记。

## 2.4 堆排序（Heap Sort）

利用最大堆的性质：堆顶永远是最大元素。每次取堆顶放到数组末尾，调整剩余元素维持堆结构。

```
初始数组：[4, 10, 3, 5, 1]

构建最大堆（堆顶最大）：
        10
       /  \
      5    3
     / \
    4   1

取堆顶 10，与末尾交换，堆大小减一：
        5
       /  \
      4    3
     /
    1
...重复直到堆为空。
```

# 3. Python 短代码辅助理解

## 3.1 冒泡排序

```python
def bubble_sort(arr):
    """冒泡排序：每轮把最大值"冒"到末尾"""
    n = len(arr)
    for i in range(n):
        # 每轮少比较 i 个，因为末尾 i 个已排好
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr


arr = [5, 3, 8, 6, 9, 1]
print(f"冒泡排序前：{arr}")
print(f"冒泡排序后：{bubble_sort(arr)}")
```

## 3.2 快速排序 —— 核心分区逻辑

```python
def partition(arr, low, high):
    """
    分区函数：选最后一个元素为 pivot，
    将小于 pivot 的换到左边，大于的留在右边。
    """
    pivot = arr[high]   # 选最右元素为基准
    i = low - 1         # i 指向"小于区域"的末尾

    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]  # 将小元素交换到左边

    # 将 pivot 放到正确位置（大于区域的起始处）
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```

## 3.3 归并排序 —— 合并函数

```python
def merge(left, right):
    """
    合并两个有序数组。
    为什么用双指针：左右已有序，只需逐对比较最小值。
    """
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

## 3.4 堆排序 —— 堆调整

```python
def heapify(arr, n, i):
    """
    调整以 i 为根的子树，使其满足最大堆性质。
    为什么从 i 开始下沉：只有 i 可能不满足堆性质，
    它的左右子树已经是大堆（在构建过程中保证的）。
    """
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left
    if right < n and arr[right] > arr[largest]:
        largest = right
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)  # 递归向下调整


def heap_sort(arr):
    n = len(arr)
    # 从最后一个非叶子节点开始构建最大堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    # 逐个取堆顶放到末尾
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]  # 堆顶与末尾交换
        heapify(arr, i, 0)  # 缩小堆范围，重新调整
    return arr
```

# 4. 复杂度与适用场景

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定 | 适用场景 |
|------|--------------|--------------|-----------|------|---------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 是 | 教学演示，小数据 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 否 | 通用排序（最常用） |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 是 | 外部排序，需要稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 | 需要原地排序且保证最坏 O(n log n) |

**Python 内置排序**：`sorted()` 和 `.sort()` 底层使用 **Timsort**——一种归并排序和插入排序的混合体，利用了数据中已有的有序片段（run），在最坏情况下 O(n log n)，在已有序数据上可达到 O(n)，且是稳定的。

# 5. 常见变体

## 三路快排
将数组分成小于、等于、大于 pivot 的三部分，适合有大量重复元素的场景。等于 pivot 的部分不再参与递归，大幅提升重复数据时的效率。

## 希尔排序
插入排序的改进版，先将数组按一定间隔分组排序，再逐步缩小间隔，最终变为插入排序。利用"部分有序时插入排序很快"的特点。

# 6. 经典题目：实现快速排序

## 题目描述
手写快速排序算法，包含分区函数和排序函数，对给定数组 `[3, 6, 8, 10, 1, 2, 1]` 进行升序排序，并打印排序前后结果。

## 思路分析
1. **partition**：选最后一个元素为 pivot，用双指针将数组分成"小于区"和"大于区"，返回 pivot 最终位置。
2. **quick_sort**：递归地对 pivot 左右两部分排序。终止条件为 `low >= high`（区间为空或只有一个元素）。

## 完整代码

```python
def partition(arr, low, high):
    """
    分区函数：选 arr[high] 为 pivot，原地重排数组。
    返回 pivot 最终所在下标。

    为什么用 i 追踪"小于区域"边界：
    遍历时遇到小元素就扩大"小于区域"，保证区域外全是大于等于 pivot 的。
    """
    pivot = arr[high]   # 选最右元素为基准
    i = low - 1         # i 指向"小于区域"的最后一个位置

    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]  # 把当前元素换入"小于区域"

    # 将 pivot 放到正确位置（"小于区域"的下一个位置）
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1


def quick_sort(arr, low, high):
    """
    快速排序递归实现。
    分治三部曲：
    1. 分解：partition 分出 left 和 right 两部分
    2. 解决：递归排序 left 和 right
    3. 合并：原地排序，无需显式合并
    """
    if low < high:
        # 分区，得到 pivot 的最终位置
        pi = partition(arr, low, high)

        # 递归排序左右两部分
        # 为什么不包括 pi：pi 已经在正确位置上，不用再动
        quick_sort(arr, low, pi - 1)
        quick_sort(arr, pi + 1, high)


def main():
    arr = [3, 6, 8, 10, 1, 2, 1]
    print(f"排序前：{arr}")

    quick_sort(arr, 0, len(arr) - 1)

    print(f"排序后：{arr}")

    # 用内置排序验证结果
    assert arr == sorted([3, 6, 8, 10, 1, 2, 1]), "排序结果不正确！"
    print("验证通过")


if __name__ == "__main__":
    main()
```

## 运行结果

```
排序前：[3, 6, 8, 10, 1, 2, 1]
排序后：[1, 1, 2, 3, 6, 8, 10]
验证通过
```
