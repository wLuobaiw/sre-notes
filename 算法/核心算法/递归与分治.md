# 1. 概念导入

想象你面前有一排俄罗斯套娃，你想知道一共有多少个。打开最外面那个，里面是一个一模一样但更小的套娃；再打开，又是更小的一个……直到最后一个，里面什么都没有了。这个过程就是**递归**——用同样的方法解决规模更小的同类问题。**分治**则是递归的一种典型应用：把一个大问题分解成多个独立的小问题，分别解决后合并结果。

---

# 2. 核心原理

## 2.1 递归三要素

任何一个递归函数，都必须包含以下三个部分：

```
def solve(problem):
    if problem is small enough:     ← ① 终止条件（base case）
        return answer                    问题小到可以直接解决

    sub_answer = solve(smaller)     ← ② 递归调用，向终止条件推进

    return combine(sub_answer)      ← ③ 合并结果
```

- **终止条件**：递归必须有个"出口"，否则会无限调用下去，最终栈溢出。
- **递归调用**：每次调用时，问题规模必须比上一次更小，逐步逼近终止条件。
- **合并结果**：将子问题的解组合成原问题的解。

## 2.2 调用栈

每次函数调用，计算机会在内存的"栈"区域压入一个栈帧，记录参数、局部变量和返回地址。

```
调用 factorial(3) 时的栈变化（从下往上看）：

           ← 返回 1                    [栈顶]
    factorial(0) → 返回 1
    factorial(1) → 等待 factorial(0)
    factorial(2) → 等待 factorial(1)
    factorial(3) → 等待 factorial(2)   [栈底]

当 factorial(0) 返回后，逐层向上返回：
    factorial(0) = 1
    factorial(1) = 1 * 1 = 1
    factorial(2) = 2 * 1 = 2
    factorial(3) = 3 * 2 = 6          ← 最终结果
```

递归深度过大（如 10000 层）会导致**栈溢出（Stack Overflow）**。

## 2.3 分治：分解 → 解决 → 合并

分治是递归最重要的应用场景之一，分三步走：

1. **分解（Divide）**：将原问题拆分成规模更小的相同子问题。
2. **解决（Conquer）**：递归地解决每个子问题。
3. **合并（Combine）**：将子问题的解组合成原问题的解。

以**归并排序**为例，图示整个过程：

```
原始数组：[38, 27, 43, 3, 9, 82, 10]

                    [38, 27, 43, 3, 9, 82, 10]
                   /                          \
          [38, 27, 43]                    [3, 9, 82, 10]
           /        \                     /            \
       [38]      [27, 43]             [3, 9]        [82, 10]
       /         /      \            /     \          /    \
    [38]      [27]     [43]        [3]     [9]      [82]   [10]
       \         \      /            \     /          \    /
       [38]      [27, 43]             [3, 9]        [10, 82]
           \        /                     \           /
          [27, 38, 43]                  [3, 9, 10, 82]
                 \                          /
              [3, 9, 10, 27, 38, 43, 82]    ← 最终有序数组
```

上半部分全是**分解**，最底层到达终止条件（单个元素天然有序）；下半部分全是**合并**。

# 3. Python 短代码辅助理解

## 3.1 阶乘 —— 演示递归三要素

```python
def factorial(n):
    """
    计算 n!，演示递归三要素：
    终止条件 → 递归调用 → 合并结果
    """
    # 终止条件：0! = 1，再小就无法继续分解了
    if n == 0:
        return 1
    # 递归调用（n-1 比 n 更小） + 合并结果（乘 n）
    return n * factorial(n - 1)


print(factorial(5))  # 输出 120
```

## 3.2 归并排序 —— 演示分治思想

```python
def merge(left, right):
    """
    合并两个有序数组。
    为什么用双指针：两个数组已各自有序，只需逐对比较，
    每次取较小的那个，合并后自然有序。
    """
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    # 剩余元素直接追加（剩下的肯定都比已合并的大）
    result.extend(left[i:])
    result.extend(right[j:])
    return result


def merge_sort(arr):
    """
    归并排序：典型分治。
    分解 → 从中间切分；解决 → 递归排序；合并 → merge()。
    """
    if len(arr) <= 1:
        return arr  # 终止条件：单个元素天然有序

    mid = len(arr) // 2
    # 分解 + 解决
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    # 合并
    return merge(left, right)


arr = [38, 27, 43, 3, 9, 82, 10]
print(f"排序前：{arr}")
print(f"排序后：{merge_sort(arr)}")
```

# 4. 复杂度与适用场景

| 方法 | 时间复杂度 | 空间复杂度 | 适用场景 | 不适用场景 |
|------|-----------|-----------|---------|-----------|
| 递归（阶乘类） | O(n) | O(n)（调用栈） | 问题天然有递归结构 | 迭代容易实现或深度过大时 |
| 分治（归并排序） | O(n log n) | O(n) | 大规模数据排序、外部排序 | 数据量极小 |
| 分治（快速排序） | 平均 O(n log n)，最坏 O(n²) | O(log n)（栈空间） | 通用排序 | 近乎有序的数据（不加优化） |

# 5. 常见变体

## 尾递归优化
如果递归调用是函数的**最后一步**（调用后直接返回，不做额外操作），某些编译器可以优化为循环，将栈空间从 O(n) 降到 O(1)。上面的阶乘不是尾递归（返回前还要乘 n），改写后为：

```python
def factorial_tail(n, acc=1):
    if n == 0:
        return acc
    return factorial_tail(n - 1, acc * n)  # 调用后直接返回，无事做
```

## 记忆化递归
当递归中存在大量重复子问题时（如斐波那契数列），用缓存记录已算过的结果，避免重复计算，将指数级时间降为线性。

# 6. 经典题目：汉诺塔问题

## 题目描述
有三根柱子 A、B、C，A 柱上有 n 个大小不同的圆盘，大盘在下、小盘在上。要求将所有圆盘从 A 移到 C，每次只能移动一个圆盘，且任何时候大盘不能压在小盘上。请打印每一步移动方案。

## 思路分析
汉诺塔完美体现了递归分治思想：

- **终止条件**：只有一个盘子时，直接从 source 移到 target。
- **分解**：把 n 个盘子从 A 移到 C，可以分解为：
  1. 将上面 n-1 个盘子从 A 移到 B（借助 C）。
  2. 将最下面的盘子从 A 直接移到 C。
  3. 将 B 上的 n-1 个盘子移到 C（借助 A）。
- **合并**：三步加起来就是完整方案。

## 完整代码

```python
def hanoi(n, source, target, auxiliary):
    """
    汉诺塔递归解法。
    将 n 个盘子从 source 移到 target，借助 auxiliary。

    为什么需要 auxiliary 参数：
    三根柱子的角色会交替变化——今天的辅助柱子可能是明天的源柱子。
    """
    if n == 1:
        # 终止条件：只剩一个盘子，直接从 source 移到 target
        print(f"将盘子 1 从 {source} 移到 {target}")
        return

    # 第一步：将上面 n-1 个盘子从 source 移到 auxiliary
    # 为什么需要辅助柱子：大圆盘不能压在小圆盘上，
    # 所以必须先把上面的小盘子挪走，才能移动最大的
    hanoi(n - 1, source, auxiliary, target)

    # 第二步：将最大的盘子直接移到 target
    print(f"将盘子 {n} 从 {source} 移到 {target}")

    # 第三步：将 auxiliary 上的 n-1 个盘子移到 target
    hanoi(n - 1, auxiliary, target, source)


def main():
    """演示 3 层汉诺塔的移动过程"""
    n = 3
    print(f"===== {n} 层汉诺塔移动步骤 =====")
    print("起始柱: A  目标柱: C  辅助柱: B\n")

    hanoi(n, 'A', 'C', 'B')

    total = 2 ** n - 1
    print(f"\n共需 {total} 步")


if __name__ == "__main__":
    main()
```

```

起始柱: A  目标柱: C  辅助柱: B

将盘子 1 从 A 移到 C
将盘子 2 从 A 移到 B
将盘子 1 从 C 移到 B
将盘子 3 从 A 移到 C
将盘子 1 从 B 移到 A
将盘子 2 从 B 移到 C
将盘子 1 从 A 移到 C

共需 7 步
```
