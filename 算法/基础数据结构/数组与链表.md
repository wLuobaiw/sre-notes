# 1. 概念导入

数组和链表是两种最基本的数据存储方式。如果把数据比作一排连续的储物柜，数组就是这些柜子紧挨着排在一起，你知道第 3 号柜子在哪里就能直接走过去打开它；链表则像寻宝游戏，每个柜子里都藏着一张纸条告诉你下一个柜子在哪，你必须从第一个柜子开始一张一张纸条找下去。数组擅长按位置快速查找，链表擅长在中间插入和删除。

# 2. 核心原理

## 2.1 数组：连续内存 + 随机访问

数组在内存中占用一块 **连续** 的空间。每个元素大小相同，因此只要知道起始地址和元素下标，就能通过一次地址运算直接定位：

```
内存地址  | 100 | 104 | 108 | 112 | 116 |
          |  5  |  3  |  8  |  1  |  9  |
下标      |  0  |  1  |  2  |  3  |  4  |
```

要取 `arr[3]`，计算 `100 + 3 * 4 = 112`，直接取出值 `1`。这就是 **O(1) 随机访问** 的来源。

但数组的缺点也很明显：中间插入或删除一个元素时，后面的所有元素都要移动，最坏情况是 O(n)。

```python
# Python 的 list 本质是动态数组
arr = [5, 3, 8, 1, 9]

# 随机访问 —— 直接通过下标，O(1)
print(arr[2])  # 输出 8

# 末尾追加 —— 大多数情况下 O(1)
arr.append(7)

# 中间插入 —— 需要移动后续元素，O(n)
# 为什么需要移动：必须为新元素腾出连续空间
arr.insert(2, 99)  # 在下标 2 处插入 99，后面的 8,1,9... 都右移
print(arr)  # [5, 3, 99, 8, 1, 9, 7]

# 删除也同理
arr.pop(2)  # 删除下标 2，后面的元素左移
```

## 2.2 链表：离散节点 + 指针连接

链表的每个元素是一个 **节点（Node）**，节点之间通过指针链接，不要求内存连续：

```
内存布局（离散）：
  [5 | *] ---> [3 | *] ---> [8 | *] ---> [1 | None]
   head         Node2       Node3       tail
```

每个节点包含两部分：**数据域** 和 **指针域**（指向下一个节点）。

```python
# 定义链表节点类
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val    # 数据域
        self.next = next  # 指针域，指向下一个节点

# 手动构建链表: 5 -> 3 -> 8
node3 = ListNode(8)
node2 = ListNode(3, node3)
head = ListNode(5, node2)

# 遍历链表 —— 为什么必须从头开始？因为无法通过下标直接定位
def traverse(head: ListNode):
    # 为什么用 cur 变量：不直接移动 head，保留头指针不丢失
    cur = head
    while cur:
        print(cur.val, end=" -> ")
        cur = cur.next
    print("None")

traverse(head)  # 5 -> 3 -> 8 -> None
```

## 2.3 链表的插入与删除

由于不需要移动其他元素，链表在已知位置插入或删除只需修改指针，时间复杂度 O(1)。

```
在节点 A 之后插入新节点 X：
  A ---> B         原来的连接
  变成：
  A ---> X ---> B  修改 A.next 指向 X，X.next 指向 B

删除节点 B（已知 B 的前驱 A）：
  A ---> B ---> C  原来的连接
  变成：
  A ---> C         直接让 A.next 跳过 B
```

```python
# 在节点 A 后插入值为 99 的新节点
def insert_after(prev_node: ListNode, val: int):
    # 为什么先创建新节点，再改指针：如果先改 prev.next 就会丢失后续链
    new_node = ListNode(val)
    new_node.next = prev_node.next
    prev_node.next = new_node

# 删除 A 的后继节点
def delete_next(prev_node: ListNode):
    if prev_node.next:
        # 跳过要删除的节点，直接指向下下个节点
        prev_node.next = prev_node.next.next
```

# 3. 复杂度与适用场景

| 操作 | 数组（动态数组） | 链表 |
|------|-----------------|------|
| 随机访问（按下标） | **O(1)** | O(n) |
| 末尾插入/删除 | **均摊 O(1)** | O(n)（需先遍历到末尾） |
| 已知位置插入/删除 | O(n)（移动元素） | **O(1)** |
| 查找指定值 | O(n) | O(n) |
| 额外空间开销 | 几乎没有 | 每个节点多存一个指针 |

**什么情况用数组：** 需要频繁按索引访问、末尾操作多、对缓存友好（连续内存）。
**什么情况用链表：** 需要在中间频繁插入/删除、数据量不确定且需要灵活伸缩、对随机访问无要求。

# 4. 常见变体

- **双向链表（Doubly Linked List）**：每个节点多一个 `prev` 指向前驱。可以从两个方向遍历，删除节点时更方便（无需知道前驱）。Python 内置的 `collections.deque` 底层就是双向链表。
- **循环链表（Circular Linked List）**：尾节点指向头节点，形成环。适合需要循环遍历的场景（如操作系统进程调度的时间片轮转）。

# 5. 经典题目：反转链表（LeetCode 206）

## 题目描述
反转一个单链表。输入 `1 -> 2 -> 3 -> 4 -> 5`，输出 `5 -> 4 -> 3 -> 2 -> 1`。

## 思路分析
使用 **迭代法**，逐个节点反转指针方向。准备三个指针：
- `prev`：当前节点的前驱（初始为 None）
- `curr`：当前要处理节点
- `next_temp`：暂存下一个节点（防止反转后丢失）

```
初始状态：
  None   1 -> 2 -> 3 -> 4 -> 5
  prev  curr

第一步（反转 1 的指针）：
  None <- 1    2 -> 3 -> 4 -> 5
  prev  curr  next_temp

第二步（后移所有指针）：
  None <- 1 <- 2    3 -> 4 -> 5
          prev  curr
```

## 完整代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_list(head: ListNode) -> ListNode:
    """
    迭代反转链表。
    为什么用迭代：空间复杂度 O(1)，比递归更省内存。
    """
    prev = None   # 前驱节点初始为 None，因为反转后原头变尾
    curr = head   # 从头部开始处理

    while curr:
        # 为什么先保存 next：一旦修改 curr.next，原后续就断了
        next_temp = curr.next
        # 关键操作：当前节点指向前驱，完成反转
        curr.next = prev
        # 后移指针：prev 到 curr，curr 到下一节点
        prev = curr
        curr = next_temp

    # 结束时 curr 为 None，prev 为原链表最后一个节点（新头）
    return prev


# 辅助函数：从 list 构建链表
def build_list(arr):
    dummy = ListNode()
    cur = dummy
    for val in arr:
        cur.next = ListNode(val)
        cur = cur.next
    return dummy.next

# 辅助函数：打印链表
def print_list(head):
    res = []
    cur = head
    while cur:
        res.append(str(cur.val))
        cur = cur.next
    print(" -> ".join(res) if res else "空链表")

# 测试
head = build_list([1, 2, 3, 4, 5])
print("原链表：", end="")
print_list(head)

reversed_head = reverse_list(head)
print("反转后：", end="")
print_list(reversed_head)
# 输出：
# 原链表：1 -> 2 -> 3 -> 4 -> 5
# 反转后：5 -> 4 -> 3 -> 2 -> 1
```
