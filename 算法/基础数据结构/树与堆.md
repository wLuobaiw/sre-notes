# 1. 概念导入

树（Tree）是一种 **非线性** 的数据结构，元素之间存在"父子"层级关系。如果说数组和链表是"一维排列"的数据，树就是"分叉生长"的数据——就像公司的组织架构或电脑的文件系统。**堆（Heap）** 是一种特殊的树，它解决了"如何快速获取最大（或最小）元素"的问题，而不关心其他元素的顺序。

# 2. 核心原理

## 2.1 二叉树的定义

二叉树（Binary Tree）是每个节点最多有两个子节点（左子节点、右子节点）的树结构。

```
        1          ← 根节点（root）
       / \
      2   3        ← 2 是左子节点，3 是右子节点
     / \   \
    4   5   6      ← 叶子节点（没有子节点）
```

```python
# 定义二叉树节点类
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val      # 节点值
        self.left = left    # 左子树指针
        self.right = right  # 右子树指针

# 构建上面的二叉树
node4 = TreeNode(4)
node5 = TreeNode(5)
node6 = TreeNode(6)
node2 = TreeNode(2, node4, node5)
node3 = TreeNode(3, None, node6)
root = TreeNode(1, node2, node3)
```

## 2.2 二叉树的三种遍历

三种遍历以"访问根节点"的时机来区分：

```
前序遍历（根 → 左 → 右）： 1 → 2 → 4 → 5 → 3 → 6
中序遍历（左 → 根 → 右）： 4 → 2 → 5 → 1 → 3 → 6
后序遍历（左 → 右 → 根）： 4 → 5 → 2 → 6 → 3 → 1
```

```python
# 前序遍历 —— 为什么先访问根：常用于复制树结构
def preorder(node: TreeNode):
    if node is None:
        return
    print(node.val, end=" ")
    preorder(node.left)
    preorder(node.right)

# 中序遍历 —— 为什么左先于根：在二叉搜索树中能按升序输出
def inorder(node: TreeNode):
    if node is None:
        return
    inorder(node.left)
    print(node.val, end=" ")
    inorder(node.right)

# 后序遍历 —— 为什么最后访问根：先处理完子树，再处理当前节点
def postorder(node: TreeNode):
    if node is None:
        return
    postorder(node.left)
    postorder(node.right)
    print(node.val, end=" ")

preorder(root); print()   # 1 2 4 5 3 6
inorder(root); print()    # 4 2 5 1 3 6
postorder(root); print()  # 4 5 2 6 3 1
```

## 2.3 堆：完全二叉树的数组存储

**堆（Heap）** 是一棵 **完全二叉树**，满足每个节点大于等于（大顶堆）或小于等于（小顶堆）其子节点。堆用数组存储，父子关系由下标直接计算，无需指针：

```
        3              数组：
       / \            ┌─────┬─────┬─────┬─────┬─────┐
      5   7   →       │  3  │  5  │  7  │  9  │  8  │
     / \              └─────┴─────┴─────┴─────┴─────┘
    9   8              下标:  0     1     2     3     4

  parent(i) = (i - 1) // 2
  left(i)   = 2 * i + 1
  right(i)  = 2 * i + 2
```

```python
# 为什么用数组存堆：完全二叉树的节点位置可由下标直接算出
def parent(i):    return (i - 1) // 2
def left(i):      return 2 * i + 1
def right(i):     return 2 * i + 2

# 验证 [3, 5, 7, 9, 8] 是否满足小顶堆（每个节点 <= 子节点）
arr = [3, 5, 7, 9, 8]
for idx in range(3):  # 只需检查有子节点的前 3 个
    print(f"arr[{idx}]={arr[idx]}, left={arr[left(idx)]}, right={arr[right(idx)]}")
```

## 2.4 Python 的 heapq 模块

Python 的 `heapq` 提供了小顶堆操作（最小值始终在 `heap[0]`）：

```python
import heapq

heap = []
for v in [5, 3, 8, 1, 2]:
    heapq.heappush(heap, v)
print(heap)                 # [1, 2, 8, 5, 3] —— 堆顶是 1
print(heapq.heappop(heap))  # 1
print(heap[0])              # 2（查看堆顶不弹出）

# 从列表原地建堆 —— O(n)，比逐个插入 O(n log n) 更快
heapq.heapify([9, 4, 7, 1, 6])  # [1, 4, 7, 9, 6]

# 大顶堆技巧：存负数，取时取反
max_heap = []
for v in [3, 1, 4, 1, 5]:
    heapq.heappush(max_heap, -v)
print(-heapq.heappop(max_heap))  # 5
```

# 3. 复杂度与适用场景

| 操作 | 二叉树（递归遍历） | 堆 |
|------|-------------------|-----|
| 插入 | O(log n)（平衡树） | **O(log n)** |
| 获取最值 | O(log n)（二叉搜索树） | **O(1)**（堆顶） |
| 查找指定值 | O(log n)（平衡树） | O(n)（不擅长查找） |
| 遍历全部 | **O(n)** | O(n) |
| 空间 | O(n)（节点+指针） | O(n)（数组，更紧凑） |

**什么情况用树：** 需要层级关系（组织架构）、需要排序后快速查找（二叉搜索树）。
**什么情况用堆：** 需要反复取最值（优先队列、Top-K、Dijkstra 算法）。
**不要用堆的场景：** 查找任意值（堆只能高效查最值）、需要有序遍历全部元素。

# 4. 常见变体

- **平衡二叉树**：通过旋转保持左右子树高度差有限，避免退化成链表。典型实现有 AVL 树和红黑树。
- **二叉搜索树（BST）**：左子树所有节点小于根，右子树所有节点大于根，中序遍历即得有序序列。

# 5. 经典题目：二叉树的最大深度（LeetCode 104）

## 题目描述
给定一棵二叉树，求最大深度（根节点到最远叶子节点的路径上的节点数）。

```
    3
   / \
  9  20
     / \
    15  7
最大深度 = 3（路径：3 → 20 → 15 或 3 → 20 → 7）
```

## 思路分析
**递归 DFS（后序遍历思想）**：空节点深度为 0；非空节点深度 = `1 + max(左子树深度, 右子树深度)`。

## 完整代码

```python
# TreeNode 类已在 2.1 节定义，此处不再重复

def max_depth(root: TreeNode) -> int:
    """
    递归计算二叉树的最大深度。
    为什么用递归：树的定义本身就是递归的，递归解法最符合直觉。
    """
    if root is None:
        return 0
    left_depth = max_depth(root.left)
    right_depth = max_depth(root.right)
    # 为什么加 1：当前节点本身也算一层
    return 1 + max(left_depth, right_depth)


# 辅助函数：根据层序列表构建二叉树（LeetCode 标准输入格式）
def build_tree(values: list) -> TreeNode:
    if not values:
        return None
    root = TreeNode(values[0])
    queue = [root]
    i = 1
    while queue and i < len(values):
        node = queue.pop(0)
        if i < len(values) and values[i] is not None:
            node.left = TreeNode(values[i])
            queue.append(node.left)
        i += 1
        if i < len(values) and values[i] is not None:
            node.right = TreeNode(values[i])
            queue.append(node.right)
        i += 1
    return root


# 测试
for values, expected in [
    ([3, 9, 20, None, None, 15, 7], 3),
    ([1, None, 2], 2),
    ([], 0),
    ([1], 1),
]:
    tree = build_tree(values)
    depth = max_depth(tree)
    status = "✓" if depth == expected else "✗"
    print(f'{status} {values} → 深度={depth}（期望 {expected}）')
```
