# 1. 概念导入

栈（Stack）和队列（Queue）是两种限制数据访问顺序的线性结构。栈像一叠盘子——你只能从最上面取、也只能往最上面放，**后进先出（LIFO, Last In First Out）**；队列像排队买东西——先来的人先结账，**先进先出（FIFO, First In First Out）**。它们解决的核心问题是：当数据有明确的"先来后到"需求时，如何约束访问顺序以避免混乱。

# 2. 核心原理

## 2.1 栈：后进先出（LIFO）

栈只允许在一端（称为 **栈顶**）进行插入（push）和删除（pop）操作。

```
  栈顶方向
  ┌─────┐
  │  3  │  ← 栈顶（最新元素）
  ├─────┤
  │  7  │
  ├─────┤
  │  5  │
  ├─────┤
  │  2  │  ← 栈底（最早元素）
  └─────┘

push(9) 后：
  ┌─────┐
  │  9  │  ← 新栈顶
  ├─────┤
  │  3  │
  ├─────┤
  │  ...│
  └─────┘

pop() 后：返回 9，栈顶回到 3
```

可以用 Python 的 `list` 轻松模拟栈：

```python
# 用 list 实现栈
stack = []

# push —— 入栈，元素加到末尾
# 为什么用 append 而非 insert(0, x)：末尾操作 O(1)，头部操作 O(n)
stack.append(2)
stack.append(5)
stack.append(7)
stack.append(3)
print(stack)   # [2, 5, 7, 3]

# pop —— 出栈，从末尾取出
top = stack.pop()   # 返回 3
print(top)          # 3
print(stack)        # [2, 5, 7]

# peek —— 查看栈顶但不删除
print(stack[-1])    # 7

# 判空
print(len(stack) == 0)  # False
```

## 2.2 队列：先进先出（FIFO）

队列在一端（队尾）插入，在另一端（队头）删除。

```
  出队 ← ┌─────┬─────┬─────┬─────┬─────┐ ← 入队
         │  2  │  5  │  7  │  3  │  9  │
         └─────┴─────┴─────┴─────┴─────┘
         队头                       队尾
```

Python 的 `list` 在头部插入/删除是 O(n)，不适合做队列。标准做法用 `collections.deque`（双向队列，底层是双向链表）：

```python
from collections import deque

# 创建队列
queue = deque()

# 入队 —— 从右边添加
queue.append(2)
queue.append(5)
queue.append(7)
print(queue)  # deque([2, 5, 7])

# 出队 —— 从左弹出
# 为什么用 popleft 而非 pop(0)：popleft 是 O(1)，list.pop(0) 是 O(n)
front = queue.popleft()  # 返回 2
print(front)             # 2
print(queue)             # deque([5, 7])

# 查看队头
print(queue[0])          # 5
```

## 2.3 更多队列操作

```python
q = deque()

# 从左端入队（双端队列的额外能力）
q.appendleft(1)   # 从左边插入
print(q)          # deque([1])

# 限制队列长度 —— 达到最大长度后，自动从另一端弹出
# 为什么有用：实现"最近 N 条记录"时自动丢弃旧数据
limited = deque(maxlen=3)
for i in range(5):
    limited.append(i)
    print(limited)
# 输出：
# deque([0], maxlen=3)
# deque([0, 1], maxlen=3)
# deque([0, 1, 2], maxlen=3)
# deque([1, 2, 3], maxlen=3)  <- 0 被自动弹出
# deque([2, 3, 4], maxlen=3)  <- 1 被自动弹出
```

# 3. 复杂度与适用场景

| 操作 | 栈（list 实现） | 队列（deque 实现） |
|------|----------------|-------------------|
| 入栈/入队 | **O(1)** | **O(1)** |
| 出栈/出队 | **O(1)** | **O(1)** |
| 查看顶部/队头 | **O(1)** | **O(1)** |
| 查找指定值 | O(n) | O(n) |
| 空间开销 | 低 | 稍高（双向链表节点） |

**什么情况用栈：** 需要撤销/回退（浏览器后退、编辑器 Ctrl+Z）、括号匹配、函数调用栈、深度优先搜索（DFS）。
**什么情况用队列：** 任务排队（打印机任务）、广度优先搜索（BFS）、消息队列、缓冲数据流。
**不要用栈或队列的场景：** 需要随机访问中间元素时，应用数组或链表。

# 4. 常见变体

- **双端队列（Deque）**：两端都可以入队出队。Python 的 `collections.deque` 就是双端队列，兼具栈和队列的能力。
- **优先队列（Priority Queue）**：不是按入队顺序出队，而是按优先级出队。底层通常用 **堆（Heap）** 实现，Python 使用 `heapq` 模块。

# 5. 经典题目：有效的括号（LeetCode 20）

## 题目描述
给定一个只包含 `(){}[]` 的字符串，判断括号是否有效配对。要求：左括号必须用同类型的右括号闭合，且必须按正确顺序嵌套。

## 思路分析
用栈匹配：遇到左括号就入栈，遇到右括号就检查栈顶是不是对应的左括号——如果是则弹出，否则无效。最后检查栈是否为空。

```
输入: "({[]})"
遍历过程：
  ( → 入栈 → [ '(' ]
  { → 入栈 → [ '(', '{' ]
  [ → 入栈 → [ '(', '{', '[' ]
  ] → 匹配栈顶 '[' → 弹出 → [ '(', '{' ]
  } → 匹配栈顶 '{' → 弹出 → [ '(' ]
  ) → 匹配栈顶 '(' → 弹出 → [ ]
栈为空 → 有效
```

## 完整代码

```python
def is_valid(s: str) -> bool:
    """
    用栈判断括号是否有效。
    为什么用栈：括号的嵌套关系天然符合 LIFO——最内层的左括号
    必须最先被匹配，这正是栈的特性。
    """
    # 建立右括号到左括号的映射，用于快速判断配对
    bracket_map = {')': '(', '}': '{', ']': '['}
    stack = []

    for char in s:
        if char in bracket_map:
            # char 是右括号
            # 为什么用 pop() 而不是 peek：匹配成功后该左括号不再需要
            top = stack.pop() if stack else '#'
            # 为什么用 # 作为默认值：它不在映射值中，必不匹配
            if bracket_map[char] != top:
                return False
        else:
            # char 是左括号，入栈等待匹配
            stack.append(char)

    # 为什么最后检查栈是否为空：可能有未匹配的左括号（如 "(("）
    return not stack


# 测试
test_cases = [
    ("()", True),
    ("()[]{}", True),
    ("(]", False),
    ("([)]", False),
    ("{[]}", True),
    ("((", False),
    ("", True),  # 空字符串视为有效
]

for s, expected in test_cases:
    result = is_valid(s)
    status = "✓" if result == expected else "✗"
    print(f'{status} "{s}" → {result}（期望 {expected}）')

# 输出：
# ✓ "()" → True（期望 True）
# ✓ "()[]{}" → True（期望 True）
# ✓ "(]" → False（期望 False）
# ✓ "([)]" → False（期望 False）
# ✓ "{[]}" → True（期望 True）
# ✓ "((" → False（期望 False）
# ✓ "" → True（期望 True）
```
