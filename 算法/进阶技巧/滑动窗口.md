# 1. 概念导入

想象你坐在一列飞驰的火车上，透过车窗看外面的风景。车窗的宽度可能固定（标准窗）或可以拉伸（天窗），但不管怎样，你看到的始终是窗外**连续的一段**。火车前进时，旧风景从左边离开，新风景从右边进入。**滑动窗口就是在数组或字符串上维护一个连续子区间，通过移动左右边界来避免重复扫描。** 很多子数组/子串问题用暴力需要 O(n^2)，滑动窗口可以降到 O(n)。

# 2. 核心原理

## 2.1 固定窗口 —— 先满窗，再平移

窗口大小固定为 k，先在起始位置构建窗口，然后每次右移一格：左边移除一个元素，右边加入一个元素。

**举例：求长度为 k 的子数组最大平均值。**

```python
def fixed_window_avg(nums, k):
    # 先算第一个窗口的和
    window_sum = sum(nums[:k])
    max_sum = window_sum
    # 窗口右移，每次去掉左边、加入右边
    for i in range(k, len(nums)):
        # 为什么 i-k 是左边要移除的元素？
        # 因为窗口覆盖 [i-k+1, i]，左边那个是 i-k
        window_sum += nums[i] - nums[i - k]
        max_sum = max(max_sum, window_sum)
    return max_sum / k
```

每次窗口滑动只需 O(1) 更新和，整体 O(n)。

## 2.2 可变窗口 —— 左右边界自由伸缩

左右指针（left, right）都从 0 开始，right 不断右移**扩张**窗口，直到窗口不再满足条件；然后 left 右移**收缩**窗口，直到条件重新满足。这种模式特别适合"找满足某条件的最长/最短子数组"。

**模板框架：**

```python
left = 0
for right in range(len(nums)):
    # 将 nums[right] 纳入窗口，更新状态
    while 窗口不满足条件:
        # 将 nums[left] 移出窗口，更新状态
        left += 1
    # 此时窗口满足条件，可以记录答案
```

关键点：right 负责**扩张**，left 负责**收缩**。每次 right 移动后，窗口可能不再合法，需要通过 while 收缩到合法为止。

## 2.3 为什么滑动窗口能省时间？

暴力做法是枚举所有子数组：`for i in range(n): for j in range(i, n):`，每次从头扫描，O(n^2)。滑动窗口利用的是**子数组连续性**——right 向右一步只用处理一个新元素，left 向右一步只用移除一个旧元素，不需要重新计算窗口内所有元素。

```python
# 暴力：每次计算子数组和都要重新累加 —— O(n^2)
def brute_force(nums, target):
    count = 0
    for i in range(len(nums)):
        s = 0
        for j in range(i, len(nums)):
            s += nums[j]           # 重复计算了很多次
            if s == target:
                count += 1
    return count
```

# 3. 复杂度与适用场景

| 类型 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 固定窗口 | O(n) | O(1)（或 O(k) 取决于窗口内数据结构） |
| 可变窗口 | O(n) | O(1) 或 O(字符集大小) |

为什么都是 O(n)？每个元素最多被加入一次（right 扫过）和移除一次（left 扫过），总操作次数是 2n 级别。

**用滑动窗口的场景**：输入是数组/字符串、求连续子区间的最优解或计数、问题可以高效地通过"添加一个元素/移除一个元素"来更新状态。

**不用滑动窗口的场景**：子区间不连续、元素顺序无关（用哈希表即可）、不能通过头尾增删高效更新状态。

# 4. 常见变体

- **固定窗口 + 计数**：窗口内元素出现次数满足某条件（如 LeetCode 438 找到字符串中所有字母异位词）。用数组或哈希表维护窗口内字符频次。
- **最多替换 K 次**：求替换最多 K 个字符后能得到的最长重复子串（LeetCode 424）。窗口内记录出现最多的字符频次，窗口大小减频次 <= K。

# 5. 经典题目：LeetCode 3 —— 无重复字符的最长子串

**题目描述**：给定一个字符串 s，找出其中不含有重复字符的**最长子串**的长度。

**思路分析**：可变窗口 + 哈希集。right 不断右移加入字符，如果遇到重复字符，left 右移直到窗口内不再有重复。窗口始终合法，记录最大宽度即可。

```python
def length_of_longest_substring(s: str) -> int:
    """滑动窗口 + 哈希集，O(n) 时间"""
    char_set = set()         # 为什么用集合？O(1) 判断字符是否在窗口内
    left = 0
    max_len = 0

    for right in range(len(s)):
        # right 指向的字符如果已在窗口中，收缩左边界直到它被移出
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1        # 为什么 left 跟着移？因为窗口必须连续
        # 此时窗口内无重复，可以安全加入
        char_set.add(s[right])
        # 更新最大长度
        max_len = max(max_len, right - left + 1)

    return max_len


if __name__ == "__main__":
    tests = ["abcabcbb", "bbbbb", "pwwkew", ""]
    for t in tests:
        print(f'"{t}" -> {length_of_longest_substring(t)}')
    # 输出:
    # "abcabcbb" -> 3
    # "bbbbb" -> 1
    # "pwwkew" -> 3
    # "" -> 0
```

注意这里的 `while` 可能让人担心 O(n^2)，但 left 和 right 各自最多移动 n 次，总移动次数是 O(2n)=O(n)。每个字符最多被加入和移出集合各一次。
