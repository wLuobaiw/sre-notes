# 1. 概念导入

假设你每天都要算一遍自己从月初到今天一共花了多少钱——每次都从 1 号开始逐日累加，实在太蠢了。更好的办法是：拿个账本，记下"截至昨天的总额"，今天只需做"昨天的总额 + 今天的花费"一次计算。**动态规划（Dynamic Programming，DP）*的核心思想就是*"记住已经算过的结果，避免重复计算"**。它适用于那些可以拆分成重叠子问题的大问题。

# 2. 核心原理

## 2.1 递归的困境 —— 重复计算

以斐波那契数列为例：F(0)=0，F(1)=1，F(n)=F(n-1)+F(n-2)。用递归写最直观：

```python
def fib_recursive(n):
    if n <= 1:
        return n
    return fib_recursive(n-1) + fib_recursive(n-2)
```

画出 F(5) 的调用树：

```
          F(5)
         /    \
     F(4)      F(3)
    /    \     /   \
  F(3)  F(2) F(2)  F(1)
  /  \   / \  / \
F(2) F(1) ... ...
```

肉眼可见 F(3) 被算了 2 次、F(2) 被算了 3 次。n 越大，重复越严重，复杂度 O(2^n)。

## 2.2 记忆化搜索 —— 自顶向下记账

为什么重复？因为没有"账本"。用一个数组把算过的结果存起来，遇到相同参数直接返回，不再递归。

```python
def fib_memo(n, memo=None):
    if memo is None:
        memo = {}          # 账本：key=参数，value=结果
    if n in memo:          # 已经算过了，直接取
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib_memo(n-1, memo) + fib_memo(n-2, memo)
    return memo[n]
```

每个 n 只算一次，复杂度降为 O(n)。这种方式叫**自顶向下** —— 从大问题出发，需要子问题时去查账本。

## 2.3 DP 递推 —— 自底向上填表

记忆化搜索仍然用了递归（有函数调用栈开销）。更彻底的做法是：从最小的子问题开始，依次往上推，用**迭代**填表。

```python
def fib_dp(n):
    if n <= 1:
        return n
    dp = [0] * (n + 1)     # dp[i] = F(i)
    dp[1] = 1              # 初始条件
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]  # 状态转移方程
    return dp[n]
```

这就是**自底向上**——先解决最基础的子问题，逐步构建到大问题。省去了递归调用，性能更优。

## 2.4 四个关键概念

- **状态定义**：`dp[i]` 表示什么含义（例如 dp[i] = 斐波那契第 i 项）。定义好状态是 DP 的第一步。
- **状态转移方程**：大问题和小问题之间的递推关系（`dp[i] = dp[i-1] + dp[i-2]`）。这是 DP 的核心。
- **最优子结构**：大问题的最优解包含了子问题的最优解。F(5) 的最优解依赖于 F(4) 和 F(3) 的最优解。
- **重叠子问题**：递归树中同一个子问题被反复求解。没有重叠子问题的问题不适合 DP（如二分查找）。

# 3. 复杂度与适用场景

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 朴素递归 | O(2^n) | O(n)（栈深度） |
| 记忆化搜索 | O(n) | O(n) |
| DP 递推 | O(n) | O(n)，可优化至 O(1) |

**用 DP 的场景**：问题可拆分子问题、子问题有重叠、存在最优子结构。

**不用 DP 的场景**：子问题不重叠（用分治）、数据规模极小（暴力更快）。

# 4. 常见变体

- **0-1 背包问题**：每个物品选或不选，求容量限制下的最大价值。状态 `dp[i][w]` 表示前 i 个物品、背包容量 w 时的最大价值。
- **区间 DP**：状态是某个区间 `[i, j]` 上的最优解，常用于回文、矩阵链乘等问题。

# 5. 经典题目：LeetCode 70 —— 爬楼梯

**题目描述**：爬楼梯需要 n 阶才能到楼顶，每次可以爬 1 或 2 个台阶。有多少种不同的方法爬到楼顶？

**思路分析**：爬到第 i 阶的方法数 = 爬到第 i-1 阶的方法数（再爬 1 阶）+ 爬到第 i-2 阶的方法数（再爬 2 阶）。这就是斐波那契数列。下面用三种写法对比，体会 DP 的演进。

```python
def climb_recursive(n):
    """纯递归 —— 大量重复计算，n=40 就很慢了"""
    if n <= 2:
        return n
    return climb_recursive(n-1) + climb_recursive(n-2)


def climb_memo(n, memo=None):
    """记忆化搜索 —— 账本去重，避免重复递归"""
    if memo is None:
        memo = {}
    if n in memo:               # 查账本，算过就不算了
        return memo[n]
    if n <= 2:
        return n
    memo[n] = climb_memo(n-1, memo) + climb_memo(n-2, memo)
    return memo[n]


def climb_dp(n):
    """DP 递推 —— 自底向上，只保留两个变量"""
    if n <= 2:
        return n
    prev2, prev1 = 1, 2          # prev2 = dp[1], prev1 = dp[2]
    for _ in range(3, n + 1):
        # 为什么用滚动变量：因为 dp[i] 只依赖于前两个值，不需要整个数组
        cur = prev1 + prev2
        prev2, prev1 = prev1, cur
    return prev1


if __name__ == "__main__":
    n = 10
    print(f"n={n}: 递归={climb_recursive(n)}, "
          f"记忆化={climb_memo(n)}, DP={climb_dp(n)}")
    # 输出: n=10: 递归=89, 记忆化=89, DP=89
```

三种写法结果一致，但效率天差地别。DP 递推是 O(n) 时间、O(1) 空间，是最终推荐的做法。
