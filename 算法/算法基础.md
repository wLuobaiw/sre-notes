# 一、算法概述

算法是解决特定问题的一系列明确步骤，就像菜谱中的烹饪步骤——给定食材（输入），按步骤操作，得到菜肴（输出）。

对于 SRE 而言，算法思维是理解系统内部机制的基础：Linux 调度器用红黑树管理进程、Redis 用跳表实现有序集合、Kubernetes 调度器用优先队列分配 Pod、数据库索引背后是 B+ 树。**算法不是面试八股，而是理解这些系统为什么这样设计的前提。**

## 1.1 数据结构 vs 算法

| | 数据结构 | 算法 |
|------|---------|------|
| 是什么 | 数据在内存中的组织方式 | 对数据执行的操作步骤 |
| 类比 | 储物柜、书架、文件夹 | 整理方法、查找方法 |
| 例子 | 数组、链表、哈希表、树 | 排序、搜索、递归、动态规划 |
| 关系 | **数据结构是算法的载体**，不同的结构适合不同的算法 | |

简单来说：数据结构决定"怎么存"，算法决定"怎么算"。两者一起学，才能真正理解计算机如何高效处理数据。

## 1.2 为什么先学数据结构

排序算法需要了解数组的随机访问特性；BFS/DFS 建立在栈和队列之上；动态规划的状态转移依赖数组/矩阵存储中间结果。

**本笔记的学习路径就是从底层结构到上层算法，逐层构建。**

```
基础数据结构 ──► 核心算法 ──► 进阶技巧
                                │
                   自动机 ◄──────┘
```

- **基础数据结构**：理解数据如何存储，是所有算法的基础

# 三、模块索引

## 3.1 基础数据结构 —— 数据怎么存

数据结构的核心问题：**如何在内存中组织数据，让增删改查更高效？** 没有万能结构，只有更适合当前场景的结构。

- [数组与链表](基础数据结构/数组与链表.md) —— 顺序存储 vs 链式存储，随机访问与插入删除的取舍
- [栈与队列](基础数据结构/栈与队列.md) —— LIFO 与 FIFO，函数调用栈、BFS 队列
- [哈希表](基础数据结构/哈希表.md) —— O(1) 查找的秘密，Python dict 的内部机制
- [树与堆](基础数据结构/树与堆.md) —— 层级关系建模，优先队列的底层实现

**学完这四篇，你就能回答**：为什么 Python 的 list 在末尾追加很快但中间插入很慢？为什么 dict 查找比 list 快？堆排序和快速排序的底层差异是什么？

## 3.2 核心算法 —— 最常用的算法思想

这些是最基础的算法思想，几乎每个复杂算法都能看到它们的影子。

- [递归与分治](核心算法/递归与分治.md) —— 大问题拆小问题，函数调用栈，归并排序
- [排序算法](核心算法/排序算法.md) —— 冒泡、快排、归并、堆排，Python Timsort
- [搜索算法](核心算法/搜索算法.md) —— 二分搜索、BFS（逐层探索）、DFS（一路到底）

**学完这三篇，你就能回答**：为什么 Python 的 `sorted()` 是 O(n log n)？二分搜索的前提条件是什么？BFS 为什么能找最短路径而 DFS 不能？

## 3.3 进阶技巧 —— 解决复杂问题的策略

这些是面试和实际工程中最常见的高阶算法模式。

- [动态规划](进阶技巧/动态规划.md) —— 记住算过的结果，避免重复计算，以爬楼梯为例
- [滑动窗口](进阶技巧/滑动窗口.md) —— 用左右边界锁定子区间，避免重复扫描
- [贪心算法](进阶技巧/贪心算法.md) —— 每步选最优，需要满足局部最优=全局最优
- [回溯算法](进阶技巧/回溯算法.md) —— 穷举所有可能，发现走不通就回头

**学完这四篇，你就能回答**：动态规划和递归的区别是什么？什么情况下贪心策略会失败？回溯与暴力枚举有什么本质不同？

## 3.4 自动机 —— 状态驱动的计算模型

自动机是正则表达式引擎和编译器的理论基石，也是理解字符串匹配算法的基础。

- [DFA 确定有限自动机](自动机/DFA 确定有限自动机.md) —— 每个状态+输入唯一确定下一状态，没有分支
- [NFA 非确定有限自动机](自动机/NFA 非确定有限自动机.md) —— 同一状态可以有多个转移路径，更灵活

**学完这两篇，你就能回答**：为什么 `grep` 能快速匹配正则表达式？DFA 和 NFA 的性能差异在哪里？

# 四、阅读建议

1. **先看索引再深入**：每篇笔记结构一致——概念导入 → 核心原理 → Python 短代码 → 复杂度对比 → 常见变体 → 经典题目
2. **代码一定要自己敲**：笔记中的 Python 代码可以直接复制运行，但建议逐行手敲一遍，理解每个"为什么"
3. **经典题目是检验标准**：每篇末尾的题目代码完整可运行，能独立实现这些题目才算真正掌握
4. **遇到不懂的概念先跳过**：如果某处引用了还未学过的数据结构，可以先去对应的基础篇补一下再回来
