# 1. 概念导入

想象你在地铁站刷卡进站：无论刷多少次卡，闸机的行为是确定的——刷一次开，再刷一次关，不会"有时开有时关"。DFA（Deterministic Finite Automaton，确定有限自动机）就是这种"给定当前状态和输入，下一状态唯一确定"的数学模型。它解决的核心问题是：对于任意输入序列，判断其是否具有某种模式特征。

# 2. 核心原理

## 2.1 什么是 DFA

DFA 是一个五元组 (Q, Σ, δ, q₀, F)：
- **Q**：有限的状态集合
- **Σ**：有限的输入字母表
- **δ**：转移函数 Q × Σ → Q，每个状态 + 每个输入 **有且仅有一个** 下一状态
- **q₀**：初始状态（q₀ ∈ Q）
- **F**：接受状态集合（F ⊆ Q）

**确定性**是 DFA 的核心特征。对于任意状态 q 和输入 a，查 δ(q, a) 只会得到一个结果，绝不会模棱两可。

## 2.2 用 DFA 检测子串 "abc"

假设要判断一个字符串是否包含连续子串 "abc"，可以构造 4 状态的 DFA：

- 状态 0（初始）：还没匹配到任何字符
- 状态 1：刚匹配到 'a'
- 状态 2：刚匹配到 "ab"
- 状态 3（接受）：已匹配到 "abc"

状态转移图：

```
                    ┌──────────────────────┐
                    │ 不是 b/c             │
                    ▼                      │
┌─────┐   'a'   ┌─────┐   'b'   ┌─────┐  │  'c'   ┌─────┐
│  0  │────────►│  1  │────────►│  2  │──┘───────►│  3  │
└─────┘         └─────┘         └─────┘           └─────┘
  ▲               │  'a'          │  'a'
  └───────────────┘               └───────────────────┘
     回到 0 或 1                      回到 1
```

完整转移关系：

| 当前状态 | 输入 | 下一状态 | 原因 |
|---------|------|---------|------|
| 0 | 'a' | 1 | 匹配到第一个字符 |
| 0 | 非 'a' | 0 | 未匹配，原地等待 |
| 1 | 'b' | 2 | 匹配到第二个字符 |
| 1 | 'a' | 1 | 重叠：新的 'a' 可作新起点 |
| 1 | 其他 | 0 | 匹配中断，回起点 |
| 2 | 'c' | 3 | 匹配完成，进入接受态 |
| 2 | 'a' | 1 | 重叠：'a' 可作新起点 |
| 2 | 其他 | 0 | 匹配中断，回起点 |
| 3 | 任意 | 3 | 一旦接受，永远接受 |

## 2.3 用 Python 实现转移表

DFA 最直接的实现是用字典存储转移表：

```python
# 状态转移表：key = (当前状态, 输入字符)，value = 下一状态
# 为什么用元组做 key：方便查表，逻辑集中在一处
TRANS = {
    (0, 'a'): 1,
    (1, 'b'): 2,
    (1, 'a'): 1,   # 'a' 可以重新开始匹配
    (2, 'c'): 3,
    (2, 'a'): 1,   # 同理，'a' 重新开始
}

def delta(state, char):
    """DFA 转移函数：有定义就走定义，无定义回到初始态 0"""
    return TRANS.get((state, char), 0)
```

`delta` 函数确保了"确定性"：对任意 (state, char) 组合，返回值永远唯一。

## 2.4 DFA 的执行过程

执行就是反复调用转移函数，直到输入结束：

```python
def run_dfa(text: str) -> bool:
    state = 0  # 初始状态
    for ch in text:
        state = delta(state, ch)
        # 为什么根据 char 决定下一状态：DFA 的"确定性"保证只有一个路径可走
    return state == 3  # 最终是否处于接受态

# 测试
print(run_dfa("helloabc"))   # True
print(run_dfa("ababc"))      # True
print(run_dfa("abac"))       # False
```

跟踪 "ababc" 的执行路径：
```
输入:  a   →   b   →   a   →   b   →   c
状态: 0 → 1 → 2 → 1 → 2 → 3 ✓
```
从 2 遇到 'a' 回到 1，这是关键——重叠匹配的处理体现了 DFA 设计的精妙之处。

# 3. 复杂度与适用场景

| 维度 | 指标 |
|------|------|
| 时间复杂度 | O(n)，n 为输入长度。每个字符只处理一次，无回溯 |
| 空间复杂度 | O(|Q| × |Σ|)，状态数 × 字母表大小 |
| 预处理时间 | O(|Q| × |Σ|) 构造转移表 |

**适用场景：**
- 子串查找（如文本中的关键词检测）
- 词法分析器（编译器将源代码拆分为 token）
- 协议状态机（如 TCP 连接状态管理）
- 输入格式验证（如邮箱、电话号码格式检查）

**不适用场景：**
- 模式复杂导致状态爆炸（如需要描述"括号嵌套"——DFA 无记忆能力）
- 模式频繁变化（每次变化需重新构造整个转移表）

# 4. 常见变体

## 4.1 最小化 DFA
同一语言可以有多个等价的 DFA，其中状态数最少的是最小 DFA。通过 Hopcroft 算法或 Moore 算法合并等价状态，可节省存储空间而不影响执行效率。

## 4.2 Mealy 机与 Moore 机
DFA 只输出"接受/拒绝"二元结果。Mealy 机和 Moore 机在转移过程中产生输出（如序列检测器输出"匹配成功"信号），常用于数字电路设计和通信协议解析。

# 5. 经典题目：检测字符串是否包含子串 "abc"

### 问题描述

实现一个基于 DFA 的检测器，判断给定字符串 s 中是否包含连续子串 "abc"。

### 思路分析

构建 4 状态 DFA（状态 0→1→2→3），状态编号即已匹配的前缀长度。关键设计点在于状态 1 和状态 2 的"重叠匹配"处理：失配时如果当前字符可作为新匹配起点，不要直接回退到 0。

### 完整代码

```python
class AbcDFA:
    """
    检测子串 "abc" 的 DFA
    
    为什么用类封装：把转移表和状态管理放在一起，逻辑内聚
    """
    ACCEPT = 3  # 接受状态的编号

    def __init__(self):
        # 状态转移表
        # 为什么只定义有意义的转移：无定义项默认回到状态 0
        self._trans = {
            (0, 'a'): 1,      # 匹配到 'a'
            (1, 'b'): 2,      # 匹配到 'ab'
            (1, 'a'): 1,      # 重叠：新的 'a' 重新开始
            (2, 'c'): self.ACCEPT,  # 匹配到 'abc'
            (2, 'a'): 1,      # 重叠："ab" 之后遇 'a'，可作新起点
        }

    def _next(self, state: int, ch: str) -> int:
        """DFA 转移函数：确定性保证"""
        return self._trans.get((state, ch), 0)

    def contains_abc(self, s: str) -> bool:
        state = 0
        for ch in s:
            state = self._next(state, ch)
            if state == self.ACCEPT:
                return True
        return False


def test():
    dfa = AbcDFA()
    cases = [
        ("helloabcworld", True),   # 中间包含 abc
        ("ababc", True),           # 重叠匹配 ab-abc
        ("abcabc", True),          # 两次出现
        ("abac", False),           # 不包含
        ("", False),               # 空字符串
        ("abc", True),             # 恰好
        ("ab", False),             # 不完整
        ("aabc", True),            # 前缀重叠
        ("abca", True),            # abc 在开头，后面还有字符
    ]
    for s, expected in cases:
        result = dfa.contains_abc(s)
        mark = "✓" if result == expected else "✗"
        print(f'{mark} contains_abc("{s}") = {result} (expected {expected})')


if __name__ == "__main__":
    test()
```
