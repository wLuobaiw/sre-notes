# git init

用于在指定目录初始化新的本地 Git 仓库，生成隐藏的 `.git` 文件夹（存储版本库核心数据）

```bash
git init [选项] [目录]
```

**选项**

- **-q, --quiet**：安静模式，减少初始化过程的输出信息，仅显示必要提示
- **--bare**：创建 “裸仓库”（仅包含版本库数据，无工作区，本地开发极少使用，多用于服务器）
- **--initial-branch <name>**：指定仓库的初始分支名称（默认值为 `main`，替代老版本的 `master`）
- **--template <dir>**：使用自定义模板目录初始化仓库（可预设忽略规则、钩子脚本等）
- **--separate-git-dir <dir>**：将 `.git` 目录存储到指定路径（分离工作区和版本库）
- **-h, --help**：显示帮助信息

> **注意**
>
> 1. 已初始化的目录重复执行 `git init` 不会覆盖现有版本库，仅更新部分配置
> 2. 初始化后 `.git` 文件夹默认隐藏，Windows 需显示隐藏文件才能查看
> 3. 目录默认为当前目录

# git status

用于查看本地仓库的文件状态，明确文件处于「工作区 / 暂存区 / 版本库」的哪个阶段（未跟踪、已修改、待提交等）

```bash
git status [选项]
```

**选项**

- **-s, --short**：简洁输出格式（一行显示一个文件的状态码 + 文件名）
- **--long**：详细输出格式（默认格式，包含文件状态说明）
- **--ignored**：显示被 `.gitignore` 规则忽略的文件 / 目录
- **--untracked-files=<mode>**：控制未跟踪文件的显示规则
  - `no`：不显示未跟踪文件
  - `normal`：默认，显示未跟踪的文件和目录
  - `all`：显示未跟踪目录下的所有文件
- **--porcelain**：机器可读的标准化输出格式（适合脚本解析）
- **-b, --branch**：额外显示当前分支及与远程分支的差异
- **-h, --help**：显示帮助信息

> **注意**
>
> 1. 中文文件名显示乱码时，可执行 `git config --global core.quotepath false` 修复
> 2. 执行 `git status` 是排查文件状态问题的首要步骤
> 3. 无额外参数时，默认显示当前目录下所有文件的状态
