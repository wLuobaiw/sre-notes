
# 什么是进程

进程是**正在运行的程序实例**。程序是静态的二进制文件，进程是动态的执行过程。每个进程有独立的地址空间（代码段、数据段、堆栈段），由系统分配唯一的 PID 标识。

# 进程状态

| 状态符 | 含义 | 说明 |
|--------|------|------|
| R | Running/Runnable | 正在运行或等待 CPU 调度 |
| S | Sleeping（可中断） | 等待事件完成（如 IO）——可以被信号唤醒 |
| D | Sleeping（不可中断） | 等待硬件 IO——不能被信号打断，kill -9 也无效 |
| T | Stopped | 被 `SIGSTOP` 或 `SIGTSTP`（Ctrl+Z）暂停 |
| Z | Zombie（僵尸） | 已结束但父进程尚未回收资源 |
| X | Dead | 已死亡——此状态极短暂，几乎不可见 |

# 进程生命周期

```
fork() → 子进程创建 → ... 运行 ... → exit() → 僵尸状态 → 父进程 wait() 回收 → 结束
```

- **孤儿进程**：父进程先于子进程退出，子进程被 `systemd`（PID=1）接管。属于正常现象，systemd 会负责回收。
- **僵尸进程**：子进程已退出但父进程未调用 `wait()` 回收。系统中僵尸进程累积会耗尽 PID——需要排查应用程序。

# 常用进程查看命令

## ps——查看进程快照

```shell
ps aux          # 显示所有进程，BSD 风格输出
ps -ef          # 显示所有进程，标准 Unix 风格
ps -eo pid,ppid,ni,pri,cmd  # 自定义输出列
```

输出列说明：
- `PID`：进程 ID
- `%CPU` / `%MEM`：CPU / 内存占用百分比
- `VSZ` / `RSS`：虚拟内存 / 常驻内存大小（KB）
- `TTY`：所属终端（`?` 表示守护进程）
- `STAT`：进程状态
- `TIME`：累计 CPU 时间

## top——实时进程监控

```shell
top
top -d 2        # 每 2 秒刷新
top -u username # 只看某用户的进程
top -p PID      # 只看指定进程
```

交互快捷键：`P` 按 CPU 排序，`M` 按内存排序，`k` 输入 PID 杀死进程，`q` 退出

## pstree——树形显示进程关系

```shell
pstree
pstree -p       # 显示 PID
pstree -u       # 显示进程所有者
```

# 信号与进程控制

## kill——发送信号

```shell
kill PID                # 发送 SIGTERM（15），正常终止
kill -9 PID             # 发送 SIGKILL（9），强制终止
kill -15 PID            # 同默认
kill -l                 # 列出所有信号
```

| 信号编号 | 信号名 | 作用 |
|---------|--------|------|
| 1 | SIGHUP | 重新加载配置（常用于 reload） |
| 2 | SIGINT | 终端中断信号（Ctrl+C） |
| 9 | SIGKILL | 强制终止——进程无法捕获或忽略 |
| 15 | SIGTERM | 正常终止——可被进程捕获做清理 |
| 19 | SIGSTOP | 暂停进程 |
| 18 | SIGCONT | 恢复被暂停的进程 |

## pkill / pgrep——按名称匹配

```shell
pkill -f "pattern"      # 按完整命令行匹配并发送信号
pkill -9 -f "pattern"   # 强制杀死匹配的进程
pgrep -f "nginx"        # 查找匹配进程的 PID
```

> `pkill` 前建议先用 `pgrep` 验证匹配结果，避免误杀。
