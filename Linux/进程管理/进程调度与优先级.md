
# 优先级数值

Linux 进程优先级由两个值共同决定：

## nice 值——用户可调整的优先级

| 特性 | 说明 |
|------|------|
| 取值范围 | -20（最高优先级）到 +19（最低优先级） |
| 默认值 | 0 |
| 调整权限 | root 可设全范围，普通用户只能上调（0→+19，降低优先级） |

## PR 值——内核实际使用的调度优先级

| 特性 | 说明 |
|------|------|
| 普通进程（SCHED_OTHER） | PR = 20 + nice（范围 0～39） |
| 实时进程（SCHED_FIFO/RR） | PR = -1 ～ -99（负数越小优先级越高） |

**为什么分两个值？** nice 是给用户的简单接口（-20～19），PR 是内核内部统一表示（覆盖普通和实时进程的优先级范围）。

# 调度策略

| 策略 | 类型 | 说明 |
|------|------|------|
| SCHED_OTHER | 普通分时 | 默认策略，CFS 完全公平调度器 |
| SCHED_FIFO | 实时 | 先进先出——无时间片，运行到主动让出或更高优先级抢占 |
| SCHED_RR | 实时 | 轮转调度——同优先级按时间片轮转 |
| SCHED_BATCH | 普通 | 类似 OTHER，但更适合批处理（减少上下文切换） |
| SCHED_IDLE | 普通 | 最低优先级——只在系统空闲时运行 |

# 调整优先级

## nice——启动时设置

```shell
nice -n -10 ./my_program      # 以 nice=-10 启动（需 root）
nice -n 10 ./low_priority.sh  # 降低优先级启动
```

## renice——运行时调整

```shell
renice -n 5 -p 1234           # 将 PID 1234 的 nice 值改为 5
renice -n -5 -u username       # 调整某用户所有进程
```

## chrt——设置实时调度策略

```shell
chrt -f -p 50 1234             # 将 PID 1234 设为 SCHED_FIFO，优先级 50
chrt -r -p 30 1234             # 将 PID 1234 设为 SCHED_RR，优先级 30
chrt -o -p 0 1234              # 恢复为 SCHED_OTHER

chrt -m                        # 显示实时优先级范围
```

# 后台任务管理

## jobs——查看当前 Shell 的作业

```shell
jobs            # 列出所有作业
jobs -l         # 含 PID
jobs -r         # 只看运行中的
```

## bg / fg——前后台切换

```shell
# 启动程序时直接放后台
./long_running_task &

# 运行中暂停（Ctrl+Z），然后放后台或回前台
bg %1           # 将作业 1 放后台继续运行
fg %1           # 将作业 1 调回前台

# 作业标识：%n=作业号，%str=命令开头字符串，%%或%+=当前作业
```

## nohup——免疫挂断信号

```shell
nohup ./long_task &
nohup ./long_task > output.log 2>&1 &
```

nohup 使进程忽略 SIGHUP 信号，终端退出后进程不终止。默认输出重定向到 `nohup.out`。对于长期运行的服务，建议用 `systemd` 管理而非 nohup。

## disown——从 Shell 作业表中移除

```shell
disown %1       # 从作业列表中移除，终端关闭后进程继续运行
disown -h %1    # 不移除但标记为忽略 SIGHUP
```

比较 nohup：nohup 需要在启动时指定，disown 可以在启动后操作，更灵活。
