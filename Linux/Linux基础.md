
# 概述

Linux 是一个类 Unix 操作系统的内核。一个 Linux 系统分为两层：

- **内核空间（Kernel Space）**：直接管理硬件——进程调度、内存管理、设备驱动、文件系统、网络协议栈
- **用户空间（Userspace）**：所有应用程序（包括 `systemd`、Shell、服务进程）运行在此层，通过**系统调用**与内核交互

这种分层设计保证了系统的稳定性——用户程序崩溃不会导致内核崩溃。

# 系统启动流程

```
BIOS/UEFI 固件
  → Boot Loader（GRUB2）加载内核
  → 内核初始化（硬件检测、驱动加载、挂载根文件系统）
  → 启动第一个用户空间进程：systemd（PID=1）
  → systemd 启动所有服务（网络、SSH、日志...）
  → 系统就绪
```

# 文件系统层次结构标准（FHS）

| 目录 | 用途 |
|------|------|
| `/` | 根目录——所有文件的起点 |
| `/boot` | 启动文件（内核 vmlinuz、GRUB 配置） |
| `/etc` | 系统配置文件——**运维最常操作的目录之一** |
| `/home` | 普通用户家目录 |
| `/root` | root 用户家目录 |
| `/var` | 可变数据：日志（`/var/log`）、缓存、数据库文件 |
| `/tmp` | 临时文件——重启后可能清空 |
| `/usr` | 用户程序和数据（`/usr/bin`、`/usr/lib`、`/usr/share`） |
| `/opt` | 第三方软件安装目录 |
| `/proc` | 进程和内核信息——虚拟文件系统，不占磁盘 |
| `/sys` | 内核和设备信息——虚拟文件系统 |
| `/dev` | 设备文件——一切设备皆文件 |
| `/mnt` / `/media` | 临时挂载点 / 自动挂载介质（U盘等） |

# 关键概念

## 一切皆文件

Linux 中，硬盘、键盘、网络连接、进程信息都以文件形式呈现。这种设计使所有资源可通过统一的文件操作接口（open/read/write/close）访问，极大简化了编程模型。

## 标准输入/输出/错误（stdin/stdout/stderr）

| 流 | 文件描述符 | 默认目标 |
|----|----------|---------|
| stdin | 0 | 键盘 |
| stdout | 1 | 终端 |
| stderr | 2 | 终端 |

```shell
command > file        # stdout 重定向到文件
command 2> file       # stderr 重定向到文件
command &> file       # stdout 和 stderr 都重定向到文件
command < file        # 从文件读取 stdin
cmd1 | cmd2           # 管道——cmd1 的 stdout 作为 cmd2 的 stdin
```

## 退出状态码

- `0`：成功
- `1-255`：失败（不同程序含义不同）

```shell
echo $?           # 查看上一条命令的退出码
cmd1 && cmd2      # cmd1 成功才执行 cmd2
cmd1 || cmd2      # cmd1 失败才执行 cmd2
```

> 重定向与管道的详细讲解见 [重定向与管道](./重定向与管道.md)。
