# 文件管理

## ls——列出目录内容

```shell
ls [选项] [路径]
```

| 选项 | 作用 |
|------|------|
| `-a` | 显示所有文件（含隐藏文件 `.` 开头） |
| `-l` | 详细信息（权限、所有者、大小、时间） |
| `-h` | 人类可读大小（搭配 `-l`） |
| `-t` | 按时间排序 |
| `-r` | 反向排序 |
| `-R` | 递归子目录 |

## cd——切换目录

```shell
cd /path    # 绝对路径
cd ../      # 上级目录
cd ~        # 家目录
cd -        # 回到上次所在目录
```

## pwd——显示当前目录

```shell
pwd         # 逻辑路径
pwd -P      # 物理路径（解析符号链接）
```

## mkdir——创建目录

```shell
mkdir dir
mkdir -p a/b/c   # 递归创建
```

## cp——复制

```shell
cp src dst
cp -r dir1 dir2     # 递归复制目录
cp -p src dst       # 保留权限和时间
```

## mv——移动/重命名

```shell
mv old new          # 重命名
mv file /path/      # 移动
```

## rm——删除

```shell
rm file
rm -r dir           # 递归删除目录
rm -f file          # 强制删除（不确认）
```

## touch——创建空文件或更新时间

```shell
touch newfile
```

## ln——创建链接

```shell
ln -s target link    # 符号链接（软链接）
ln target link       # 硬链接
```

> 详见 [文件操作](./文件管理/文件操作.md)

# 文件查找

## find——文件搜索

```shell
find [路径] [条件] [动作]
```

| 常用条件 | 说明 |
|---------|------|
| `-name '*.log'` | 按文件名匹配 |
| `-type f` | 文件类型（f=普通文件, d=目录） |
| `-mtime -7` | 7天内修改的文件 |
| `-size +100M` | 大于 100MB 的文件 |
| `-user username` | 按所有者查找 |
| `-exec cmd {} \;` | 对匹配文件执行命令 |

> 详见 [文件查找](./文件管理/文件查找.md)

# 文本处理

> **文本三剑客**：[grep](./文件管理/grep.md) | [sed](./文件管理/sed.md) | [awk](./文件管理/awk.md) —— 点击查看完整用法与示例

## grep——文本搜索

```shell
grep [选项] 模式 [文件...]
```

| 常用选项 | 作用 |
|---------|------|
| `-i` | 忽略大小写 |
| `-v` | 反向匹配 |
| `-n` | 显示行号 |
| `-r` | 递归搜索目录 |
| `-E` | 扩展正则 |
| `-o` | 只输出匹配片段 |

> 详见 [grep](./文件管理/grep.md)

## sed——流编辑器

```shell
sed [选项] '命令' [文件...]
```

| 常用命令 | 作用 |
|---------|------|
| `s/old/new/g` | 替换 |
| `d` | 删除行 |
| `p` | 打印行 |
| `-i` | 直接修改文件 |

> 详见 [sed](./文件管理/sed.md)

## awk——文本分析

```shell
awk [选项] '模式 {动作}' [文件...]
```

| 常用写法 | 作用 |
|---------|------|
| `{print $1, $3}` | 打印第 1、3 列 |
| `-F:` | 指定分隔符 |
| `$3 > 100` | 条件过滤 |
| `END {print sum}` | 末尾输出汇总 |

> 详见 [awk](./文件管理/awk.md)

## wc——统计

```shell
wc -l file      # 统计行数
wc -w file      # 统计单词数
wc -c file      # 统计字节数
```

## tr——字符转换/删除

```shell
echo "abc" | tr 'a-z' 'A-Z'    # 转大写
echo "abc" | tr -d 'a'          # 删除字符 a
```

# 进程管理

## ps——查看进程快照

```shell
ps aux          # 所有进程，BSD风格
ps -ef          # 所有进程，Unix风格
```

## top——实时进程监控

```shell
top
# 交互：P=按CPU排序, M=按内存排序, k=杀进程, q=退出
```

## kill——发送信号

```shell
kill PID            # SIGTERM（正常终止）
kill -9 PID         # SIGKILL（强制终止）
kill -1 PID         # SIGHUP（重载配置）
```

## pkill——按名称杀进程

```shell
pkill -f "pattern"
pgrep -f "pattern"      # 先查看匹配哪些进程
```

## lsof——查看打开的文件

```shell
lsof -i :80             # 查看 80 端口被谁占用
lsof -p PID             # 查看进程打开的文件
lsof /path/to/file      # 查看文件被谁打开
```

## jobs / bg / fg——作业控制

```shell
command &           # 后台启动
Ctrl+Z              # 暂停当前前台进程
bg %1               # 将作业1放后台继续
fg %1               # 将作业1调回前台
```

## nohup——免疫挂断

```shell
nohup command &
```

> 详见 [进程管理基础](./进程管理/进程管理基础.md) | [systemd与systemctl](./进程管理/systemd与systemctl.md)

# 用户/权限管理

## useradd——创建用户

```shell
useradd -m -s /bin/bash username
useradd -G wheel username        # 添加到 wheel 组（可 sudo）
```

## usermod——修改用户

```shell
usermod -aG docker username      # 追加到附加组
usermod -L username              # 锁定账户
```

## userdel——删除用户

```shell
userdel -r username              # 删除用户及家目录
```

## passwd——密码管理

```shell
passwd                  # 修改自己密码
passwd username         # root 修改指定用户密码
```

## chage——密码过期策略

```shell
chage -l username       # 查看密码策略
chage -d 0 username     # 强制下次登录改密码
```

## groupadd / groups

```shell
groupadd groupname
groups username
```

## chmod——修改权限

```shell
chmod 755 file          # 数字模式
chmod u+x file          # 符号模式
chmod -R 755 dir/       # 递归
```

## chown / chgrp——修改所有者

```shell
chown user:group file
chown -R user:group dir/
chgrp group file
```

## sudo / su——用户切换

```shell
su - username           # 切换用户
sudo command            # 以 root 执行
sudo -i                 # root shell
```

## id / whoami

```shell
id              # UID、GID、所属组
whoami          # 当前用户名
```


# 计划任务

## crontab

```shell
crontab -e                  # 编辑当前用户定时任务
```

# 重定向与管道

```shell
command > file           # stdout 覆盖写入文件
command >> file          # stdout 追加写入文件
command 2> file          # stderr 覆盖写入文件
command > file 2>&1      # stdout 和 stderr 合并写入文件
command &> file          # 同上（bash 简写）
command > /dev/null 2>&1  # 丢弃所有输出
cmd1 | cmd2              # 管道——cmd1 的 stdout 传给 cmd2
cmd1 | tee file          # 分流——输出同时写文件和传管道
```

> 详见 [重定向与管道](./重定向与管道.md)

# 实用命令

## clear——清屏

```shell
clear
# 等效: Ctrl+L
```

## export——设置环境变量

```shell
export PATH=$PATH:/new/path
export VAR=value
```

## ssh——远程登录

```shell
ssh user@host
ssh -p 2222 user@host       # 指定端口
ssh -i ~/.ssh/key user@host # 使用密钥
```

## git——版本控制

```shell
git status
git add file && git commit -m "message"
git push / git pull
```

## echo / cat

```shell
echo "text"
echo $VAR                    # 输出变量
cat file                     # 输出文件内容
cat file1 file2 > merged     # 合并文件
```

## head / tail

```shell
head -n 20 file              # 前20行
tail -n 20 file              # 后20行
tail -f /var/log/syslog      # 实时追踪
```

注意：
- `cd` 等 Shell 内建命令不适用于 `--help`——请用 `man cd` 或 `help cd`
- 大多数 Linux 命令可用 `command --help` 查看简要帮助、`man command` 查看完整手册
