# 语法

```
find [路径] [匹配条件] [动作]
```

## 参数说明 

**路径** 是要查找的目录路径，可以是一个目录或文件名，也可以是多个路径，多个路径之间用空格分隔，如果未指定路径，则默认为当前目录。

**匹配参数** 是可选参数，用于指定查找的条件，可以是文件名、文件类型、文件大小等等。

**动作** 是可选的，用于对匹配到的文件执行操作，比如删除、复制等。

## 匹配条件

### 全局 / 路径控制参数

- `-mount`/`-xdev`：不跨文件系统查找，仅检索当前挂载分区的文件。
- `-follow`：跟随符号链接（默认不跟随）。
- `-daystart`：时间条件的计算起点改为当天 0 点（默认从当前时间倒推）。
- `-ignore_readdir_race`：忽略目录读取时的竞争错误（如查找中目录被删除）。
- `-quit`：找到第一个匹配文件后立即退出查找。
- `-maxdepth N`：限制查找深度为 N 层（仅向下查找 N 级子目录）。
- `-mindepth N`：从第 N 层子目录开始查找（跳过前 N-1 层）。
- `-empty`：匹配空普通文件或空目录。
- `-depth`：先处理目录内文件，再处理目录本身（配合 `-delete` 删目录）。
- `-links N`：匹配硬链接数为 N 的文件（支持 `+N`/`-N`）。
- `-inum N`：按 inode 号匹配文件（用于查找硬链接）。

### 文件类型匹配（-type）

需搭配类型字符使用，格式：`-type [字符]`

- `-type f`：匹配普通文件。
- `-type d`：匹配目录。
- `-type l`：匹配符号链接。
- `-type b`：匹配块设备文件（如磁盘）。
- `-type c`：匹配字符设备文件（如串口）。
- `-type p`：匹配管道文件（FIFO）。
- `-type s`：匹配套接字文件（socket）。

### 文件名 / 路径匹配

- `-name "pattern"`：按文件名匹配（区分大小写），支持 `*`/`?`/`[]` 通配符。
- `-iname "pattern"`：按文件名匹配（不区分大小写），通配符规则同 `-name`。
- `-path "pattern"`：匹配文件完整路径（非仅文件名），如 `-path "*/test/*"` 匹配路径含 `/test/` 的文件。
- `-ipath "pattern"`：路径匹配（不区分大小写）。
- `-regex "pattern"`：按 POSIX 基本正则匹配完整路径。
- `-iregex "pattern"`：正则路径匹配（不区分大小写）。

### 文件大小匹配（-size）

格式：`-size [±数值][单位]`，`+` 表示大于、`-` 表示小于，无符号为等于

- `-size [数值]b`：按 512 字节块匹配（默认单位，可省略）。
- `-size [数值]c`：按字节（bytes）匹配。
- `-size [数值]k`：按千字节（KB，1024 字节）匹配。
- `-size [数值]M`：按兆字节（MB，1024KB）匹配。
- `-size [数值]G`：按吉字节（GB，1024MB）匹配。

### 时间属性匹配

基于文件访问 / 修改 / 状态时间，`N` 支持 `+`/`-` 表示范围，无符号为等于

- `-atime N`：按访问时间（最后读取）匹配，单位为天。
- `-mtime N`：按修改时间（文件内容变更）匹配，单位为天（最常用）。
- `-ctime N`：按状态时间（权限 / 所有者等元数据变更）匹配，单位为天。
- `-amin N`：按访问时间匹配，单位为分钟。
- `-mmin N`：按修改时间匹配，单位为分钟。
- `-cmin N`：按状态时间匹配，单位为分钟。

### 权限匹配

- `-perm mode`：精确匹配文件权限（支持数字 / 符号模式，如 `-perm 644`）。
- `-perm -mode`：文件权限包含指定所有权限位（如 `-perm -007` 表示其他用户有读 / 写 / 执行）。
- `-perm /mode`：文件权限至少包含指定其中一位（GNU 版，部分系统用 `-perm +mode`）。
- `-executable`：匹配当前用户可执行的文件。
- `-readable`：匹配当前用户可读的文件。
- `-writable`：匹配当前用户可写的文件。

### 所有权匹配

- `-user 用户名/UID`：匹配所有者为指定用户 / UID 的文件。
- `-group 组名/GID`：匹配所属组为指定组 / GID 的文件。
- `-uid N`：按数字用户 ID（UID）匹配文件。
- `-gid N`：按数字组 ID（GID）匹配文件。
- `-nouser`：匹配无有效所有者的文件（UID 不在 `/etc/passwd`）。
- `-nogroup`：匹配无有效所属组的文件（GID 不在 `/etc/group`）。

### 逻辑运算符（组合条件）

- `-and`/`-a`：逻辑与（默认，可省略），多个条件需同时满足。
- `-or`/`-o`：逻辑或，满足任一条件即可。
- `-not`/`!`：逻辑非，取反条件（`!` 需转义为 `\!`）。
- `()`：分组条件（需转义为 `\(\)`），改变条件优先级。

## 匹配后操作动作

### 输出

- `-print`：打印匹配文件路径（默认动作，可省略）。
- `-print0`：打印路径并以 `\0` 字符分隔（解决文件名含空格 / 特殊字符问题）。
- `-ls`：以 `ls -l` 格式列出匹配文件的详情。

### 删除

- `-delete`：删除匹配的文件 / 空目录（谨慎使用）。

### 执行命令（**重要参数）

- `-ok 命令 {} \;`：执行命令前交互式确认（需输入 y/n），结束符只能使用 `\;`
- `-execdir 命令 {} \;`：在文件所在目录执行命令（更安全，避免路径注入）。
- `-exec 命令 {} \;`：对每个匹配文件执行指定命令，`{}` 代指文件名，`\;` 结束命令。
- `-exec 命令 {} +`：批量执行命令（减少进程创建，效率更高）。

#### 格式说明

无论是哪种执行命令的参数，都会用到 `{}` 和 `结束符` 

-  **`{}`** ：指的是 `find` 命令根据前面的匹配条件匹配到的文件或目录，可以看作一个存储了匹配结果的数组变量，而这个变量是遍历访问还是直接访问就取决于 **结束符** 是什么
- **结束符**
  - `\;`：是结束符的一种，用于对单个文件执行命令，将 `find` 命令匹配到的文件挨个执行命令，匹配 N 个文件就启动 N 个进程，可以用于任何命令
  - `+`：是另一种结束符，用于对批量文件执行命令，自动将 `find` 命令匹配到的文件按照系统指定的参数上限来分组之后，批量执行命令，可以大量节省进程开销，当时仅适配可以使用“多文件参数”的文件，如：`ls`、`du`
