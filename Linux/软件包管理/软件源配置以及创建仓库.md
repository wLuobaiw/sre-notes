
# 仓库配置文件

仓库定义在 `/etc/yum.repos.d/*.repo`，每个 `.repo` 文件可包含多个仓库：

```ini
# /etc/yum.repos.d/example.repo
[baseos]
name=Rocky Linux $releasever - BaseOS
baseurl=https://mirror.example.com/rocky/$releasever/BaseOS/$basearch/os/
# 或使用 mirrorlist
# mirrorlist=https://mirrors.rockylinux.org/mirrorlist?arch=$basearch&repo=BaseOS-$releasever
enabled=1
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-Rocky-$releasever

[epel]
name=Extra Packages for Enterprise Linux $releasever - $basearch
baseurl=https://mirror.example.com/epel/$releasever/Everything/$basearch/
enabled=1
gpgcheck=1
```

# 字段说明

| 字段 | 说明 |
|------|------|
| `[id]` | 仓库唯一标识——方括号括起 |
| `name` | 仓库描述名称 |
| `baseurl` | 仓库地址（http/https/ftp/file） |
| `mirrorlist` | 镜像列表 URL（与 baseurl 二选一） |
| `enabled` | 是否启用（1=启用，0=禁用） |
| `gpgcheck` | 是否校验 GPG 签名（强烈建议开启） |
| `gpgkey` | GPG 公钥地址 |

# 内置变量

| 变量 | 含义 |
|------|------|
| `$releasever` | 发行版版本号（如 8、9） |
| `$basearch` | 系统架构（如 x86_64、aarch64） |
| `$arch` | 精确架构 |

# 常用操作

```shell
# 查看已配置的仓库
dnf repolist
dnf repolist all            # 含禁用仓库

# 临时启用/禁用仓库
dnf --enablerepo=epel install package
dnf --disablerepo=* --enablerepo=baseos update

# 添加第三方仓库（如 Docker）
dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 清除缓存
dnf clean all
dnf makecache               # 重建缓存
```

# 自定义本地 YUM 仓库

场景：离线环境或内网无法访问公网仓库时，搭建本地仓库。

```shell
# 1. 准备 RPM 包目录
mkdir -p /repo/local/Packages
cp /path/to/*.rpm /repo/local/Packages/

# 2. 安装 createrepo 工具
dnf install createrepo

# 3. 创建仓库元数据
createrepo /repo/local/

# 4. 创建 .repo 文件指向本地仓库
cat > /etc/yum.repos.d/local.repo << 'EOF'
[local]
name=Local Repository
baseurl=file:///repo/local
enabled=1
gpgcheck=0
EOF

# 5. 验证
dnf repolist
```

如果是挂载 ISO 镜像作为仓库：
```shell
mount -o loop Rocky-9.iso /mnt/iso
cat > /etc/yum.repos.d/iso.repo << 'EOF'
[iso]
name=ISO Repository
baseurl=file:///mnt/iso/BaseOS
enabled=1
gpgcheck=0
EOF
```

# 配置 APT 源

APT 的仓库配置在 `/etc/apt/sources.list` 及 `/etc/apt/sources.list.d/*.list`：

```ini
# 格式：deb 仓库URL 发行版代号 组件名...
deb https://mirror.example.com/ubuntu/ jammy main restricted universe multiverse
deb https://mirror.example.com/ubuntu/ jammy-updates main restricted
```

修改后执行 `apt update` 生效。
