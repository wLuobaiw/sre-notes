
包管理器负责软件包的**安装、卸载、更新和依赖管理**。它从软件仓库下载预编译的二进制包，自动解析依赖关系，并维护系统中所有已安装软件的数据库。

# 各发行版体系

| 发行版家族 | 代表发行版 | 底层工具 | 高层工具 | 包格式 |
|-----------|----------|---------|---------|--------|
| Debian 系 | Debian / Ubuntu / Kali | dpkg | apt / apt-get | `.deb` |
| RHEL 系 | RHEL / Rocky / CentOS / Fedora | rpm | yum / dnf | `.rpm` |
| SUSE 系 | openSUSE / SLES | rpm | zypper | `.rpm` |
| Alpine | Alpine Linux | apk | apk | `.apk` |
| Arch 系 | Arch / Manjaro | pacman | pacman | `.pkg.tar.zst` |

# Debian vs RHEL 两大阵营

- **Debian 系**：`dpkg` 是底层，`apt` 负责依赖解析和仓库管理。配置文件在 `/etc/apt/sources.list`。
- **RHEL 系**：`rpm` 是底层，`yum` 或 `dnf` 负责依赖解析和仓库管理。仓库定义在 `/etc/yum.repos.d/*.repo`。

RHEL 8+ 和 Rocky 8+ 默认使用 `dnf`——yum 的下一代，性能更好、依赖解析更快、API 更清晰。日常使用中两者几乎完全兼容。

# 仓库概念

仓库（Repository）是软件包的集合，托管在远程服务器或本地目录。包管理器从仓库索引下载元数据（包名、版本、依赖），再按需下载实际软件包。

- **官方仓库**：发行版维护，稳定可靠
- **EPEL**（RHEL 系）：Extra Packages for Enterprise Linux——社区维护的额外高质量包
- **第三方仓库**：如 Docker、Kubernetes、Nginx 官方仓库
- **本地仓库**：ISO 镜像或本地目录
