
Debian 系底层包管理工具，直接操作 `.deb` 文件。

```shell
# 安装本地 deb 包
dpkg -i package.deb

# 卸载（保留配置文件）
dpkg -r package_name

# 完全卸载（含配置文件）
dpkg -P package_name

# 列出所有已安装包
dpkg -l

# 查看包安装的文件列表
dpkg -L package_name

# 查找文件属于哪个包
dpkg -S /path/to/file

# 查看包详细信息
dpkg -s package_name

# 查看 deb 包内容
dpkg -c package.deb

# 配置未完成配置的包（安装中断后修复）
dpkg --configure -a
```

# apt（Advanced Package Tool）

Debian 系高层包管理，自动处理依赖。现代系统推荐用 `apt` 替代 `apt-get`（输出更友好）。

```shell
# 更新软件包索引
apt update

# 安装
apt install package_name

# 卸载（保留配置）
apt remove package_name

# 完全卸载（含配置）
apt purge package_name

# 升级所有可升级的包
apt upgrade

# 全面升级（处理依赖变更，可能移除旧包）
apt full-upgrade

# 自动清理不再需要的依赖
apt autoremove

# 搜索
apt search keyword

# 查看包信息
apt show package_name

# 列出可升级的包
apt list --upgradable

# 查看包的依赖关系
apt depends package_name

# 清理下载的 deb 缓存
apt clean
```

# rpm（Red Hat Package Manager）

RHEL 系底层包管理，直接操作 `.rpm` 文件。

```shell
# 安装（v=详细信息, h=进度条）
rpm -ivh package.rpm

# 升级（已安装则升级，未安装则安装）
rpm -Uvh package.rpm

# 卸载
rpm -e package_name

# 列出所有已安装包
rpm -qa

# 查看包安装的文件
rpm -ql package_name

# 查找文件属于哪个包
rpm -qf /path/to/file

# 查看包详细信息
rpm -qi package_name

# 查看包内文件（未安装的 rpm 文件）
rpm -qpl package.rpm

# 验证包完整性
rpm -V package_name

# 导入 GPG 公钥
rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-*
```

# yum / dnf

RHEL 系高层包管理，自动处理依赖。RHEL 8 / Rocky 8+ 默认使用 `dnf`（yum 的下一代），两者基本兼容。

```shell
# 安装
yum install package_name          # dnf install package_name

# 卸载
yum remove package_name           # dnf remove package_name

# 更新指定包
yum update package_name           # dnf update package_name

# 更新所有包
yum update                        # dnf upgrade

# 搜索
yum search keyword                # dnf search keyword

# 列出已安装包
yum list installed                # dnf list installed

# 列出可用包
yum list available                # dnf list available

# 查找提供某命令/文件的包
yum provides /path/to/file        # dnf provides /path/to/file

# 列出仓库
yum repolist                      # dnf repolist

# 清除缓存
yum clean all                     # dnf clean all

# 查看包信息
yum info package_name             # dnf info package_name

# 查看包依赖
yum deplist package_name          # dnf deplist package_name

# 查看历史事务（dnf 独有优势）
dnf history
dnf history undo <事务ID>
```

# yum vs dnf 主要区别

| 特性 | yum | dnf |
|------|-----|-----|
| 依赖解析 | Python 实现，大型仓库慢 | C 实现 + libsolv，更快 |
| API | 无公开 API | 提供 Python API |
| 历史回滚 | 不支持 | `dnf history undo` |
| 默认版本 | RHEL 7 及以下 | RHEL 8+ / Fedora |

# zypper（SUSE/openSUSE）

SUSE 系的包管理器，底层也是 rpm 格式。

```shell
# 安装
zypper install package_name

# 卸载

# 搜索
zypper search keyword

# 更新所有包
zypper update

# 列出仓库

# 查看包信息

# 清理缓存

```

# apk（Alpine Linux）

Alpine 的包管理器，基于 `.apk` 包，速度极快。容器镜像中常见（Alpine 是 Docker 首选轻量基础镜像）。

```shell
# 更新索引并安装
apk add package_name

# 卸载
apk del package_name

# 搜索
apk search keyword

# 更新索引
apk update

# 升级所有包
apk upgrade

# 查看包信息
apk info package_name

# 列出已安装包
apk info -v

# 查看包内文件
apk info -L package_name
```

# pacman（Arch Linux / Manjaro）

Arch 系的包管理器，设计简洁、速度快。

```shell
# 安装
pacman -S package_name

# 卸载（保留依赖）
pacman -R package_name

# 卸载（含不需要的依赖）
pacman -Rs package_name

# 搜索（含已安装和仓库）
pacman -Ss keyword

# 查看已安装包
pacman -Qs keyword

# 查看包信息
pacman -Si package_name

# 查看包信息（已安装）
pacman -Qi package_name

# 更新数据库并升级所有包
pacman -Syu

# 清理缓存
pacman -Sc
```

# 跨发行版操作对照表

| 操作 | Debian/Ubuntu | RHEL/Rocky | SUSE | Alpine | Arch |
|------|--------------|------------|------|--------|------|
| 安装包 | `apt install pkg` | `dnf install pkg` | `zypper install pkg` | `apk add pkg` | `pacman -S pkg` |
| 卸载 | `apt remove pkg` | `dnf remove pkg` | `zypper remove pkg` | `apk del pkg` | `pacman -R pkg` |
| 搜索 | `apt search kw` | `dnf search kw` | `zypper search kw` | `apk search kw` | `pacman -Ss kw` |
| 更新索引 | `apt update` | `dnf check-update` | `zypper refresh` | `apk update` | `pacman -Sy` |
| 升级所有 | `apt upgrade` | `dnf upgrade` | `zypper update` | `apk upgrade` | `pacman -Su` |
| 本地安装 | `dpkg -i file.deb` | `rpm -ivh file.rpm` | `rpm -ivh file.rpm` | `apk add file.apk` | `pacman -U file` |
| 文件归属 | `dpkg -S /path` | `rpm -qf /path` | `rpm -qf /path` | - | `pacman -Qo /path` |
| 已安装列表 | `dpkg -l` | `rpm -qa` | `rpm -qa` | `apk info -v` | `pacman -Q` |
| 清理缓存 | `apt clean` | `dnf clean all` | `zypper clean` | - | `pacman -Sc` |

# YUM/DNF 仓库配置

## 仓库配置文件

仓库定义在 `/etc/yum.repos.d/*.repo`，每个 `.repo` 文件可包含多个仓库：

```ini
# /etc/yum.repos.d/Rocky-BaseOS.repo
[baseos]
name=Rocky Linux $releasever - BaseOS
baseurl=https://mirror.example.com/rocky/$releasever/BaseOS/$basearch/os/
enabled=1
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-Rocky-$releasever

[epel]
name=Extra Packages for Enterprise Linux $releasever - $basearch
baseurl=https://mirror.example.com/epel/$releasever/Everything/$basearch/
enabled=1
gpgcheck=1
```

## 字段说明

| 字段 | 说明 |
|------|------|
| `[id]` | 仓库唯一标识——方括号括起 |
| `name` | 仓库描述名称 |
| `baseurl` | 仓库地址（http/https/ftp/file） |
| `mirrorlist` | 镜像列表 URL——与 baseurl 二选一 |
| `enabled` | 是否启用（1=启用，0=禁用） |
| `gpgcheck` | 是否校验 GPG 签名——强烈建议开启 |
| `gpgkey` | GPG 公钥地址 |
| `priority` | 优先级——数值越小越优先（需 yum-plugin-priorities） |
| `exclude` | 排除的包名——逗号分隔 |
| `includepkgs` | 白名单——只包含指定包 |

## 内置变量

| 变量 | 含义 | 示例值 |
|------|------|--------|
| `$releasever` | 发行版版本号 | 8、9 |
| `$basearch` | 系统架构 | x86_64、aarch64 |
| `$arch` | 精确架构 | x86_64 |

## 常用仓库操作

```shell
# 查看已配置的仓库
dnf repolist
dnf repolist all            # 含禁用仓库

# 临时启用/禁用仓库
dnf --enablerepo=epel install htop
dnf --disablerepo=* --enablerepo=baseos update

# 查看仓库详细信息
dnf repoinfo baseos

# 添加第三方仓库（如 Docker）
dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 启用 EPEL 仓库
dnf install epel-release    # RHEL/Rocky 8+
dnf config-manager --set-enabled epel
```

## 自定义本地 YUM 仓库

离线环境或内网无法访问公网仓库时，搭建本地仓库：

```shell
# 1. 准备 RPM 包目录
mkdir -p /repo/local/Packages
cp /path/to/*.rpm /repo/local/Packages/

# 2. 安装 createrepo 工具
dnf install createrepo

# 3. 创建仓库元数据
createrepo /repo/local/

# 4. 创建 .repo 文件指向本地仓库
cat > /etc/yum.repos.d/local.repo << 'EOF'
[local]
name=Local Repository
baseurl=file:///repo/local
enabled=1
gpgcheck=0
EOF

# 5. 验证
dnf repolist
```

## 挂载 ISO 镜像作为仓库

```shell
mount -o loop Rocky-9.iso /mnt/iso

cat > /etc/yum.repos.d/iso.repo << 'EOF'
[iso-baseos]
name=ISO - BaseOS
baseurl=file:///mnt/iso/BaseOS
enabled=1
gpgcheck=0

[iso-appstream]
name=ISO - AppStream
baseurl=file:///mnt/iso/AppStream
enabled=1
gpgcheck=0
EOF
```

# DNF 进阶功能

## 模块化（Module Streams）

RHEL 8+ 引入了模块化——同一软件有多个版本流（stream），可独立选择：

```shell
# 列出所有模块
dnf module list

# 查看某模块的可用流
dnf module list nodejs

# 启用模块流
dnf module enable nodejs:20

# 安装模块默认 profile
dnf module install nodejs

# 切换模块流（先重置再启用新流）
dnf module reset nodejs
dnf module enable nodejs:22
dnf module install nodejs

# 查看已启用的模块
dnf module list --enabled
```

每个模块有多个 profile（安装组合），如 `default`、`minimal`、`development`。

## 软件包组（Group）

```shell
# 列出所有包组
dnf group list

# 查看包组内容
dnf group info "Development Tools"

# 安装包组
dnf group install "Development Tools"

# 卸载包组
dnf group remove "Development Tools"
```

## 历史事务与回滚

```shell
# 查看事务历史
dnf history

# 查看某次事务的详情
dnf history info 42

# 回滚到指定事务之前的状态
dnf history undo 42

# 重做某次事务
dnf history redo 42

# 回滚最近一次操作
dnf history undo last
```

## 包锁定——防止意外升级

```shell
# 安装 versionlock 插件
dnf install dnf-plugin-versionlock

# 锁定指定包——不随 dnf upgrade 升级
dnf versionlock add kernel-*

# 查看锁定的包
dnf versionlock list

# 解除锁定
dnf versionlock delete kernel-*

# 清除所有锁定
dnf versionlock clear
```

## 下载而不安装

```shell
# 安装 download 插件
dnf install dnf-plugins-core

# 下载 RPM 包到当前目录（不安装）
dnf download nginx

# 下载含依赖的包
dnf download --resolve nginx

# 指定下载目录
dnf download --destdir /tmp/rpms nginx
```

## 安全更新

```shell
# 查看可用的安全更新
dnf updateinfo list sec

# 只安装安全更新
dnf update --security

# 查看安全更新详情
dnf updateinfo info --security

# 按 CVE 查看
dnf updateinfo list cves
```

## 缓存管理

```shell
# 清除所有缓存
dnf clean all

# 只清除元数据
dnf clean metadata

# 只清除已下载的包
dnf clean packages

# 重建缓存
dnf makecache

# 设置缓存过期时间：/etc/dnf/dnf.conf
# metadata_expire=7d   (默认 48 小时)
```

# 配置 APT 源

APT 仓库配置在 `/etc/apt/sources.list` 及 `/etc/apt/sources.list.d/*.list`：

```ini
# 格式：deb 仓库URL 发行版代号 组件名...
deb https://mirror.example.com/ubuntu/ jammy main restricted universe multiverse
deb https://mirror.example.com/ubuntu/ jammy-updates main restricted
deb https://mirror.example.com/ubuntu/ jammy-security main restricted
```

修改后执行 `apt update` 生效。

# YUM/DNF 与 APT 概念对照

| 概念 | RHEL 系 | Debian 系 |
|------|---------|----------|
| 仓库配置 | `/etc/yum.repos.d/*.repo` | `/etc/apt/sources.list` |
| EPEL（额外包） | `dnf install epel-release` | 对应 universe 组件 |
| 包组 | `dnf group install` | 无直接等价——用 meta-package |
| 历史回滚 | `dnf history undo` | 无内置等价 |
| 模块化 | `dnf module` | 无等价概念 |
| 包锁定 | `dnf versionlock` | `apt-mark hold pkg` |
| 下载不安装 | `dnf download` | `apt download pkg` |
| 安全更新 | `dnf update --security` | `apt upgrade` + unattended-upgrades |
| 缓存路径 | `/var/cache/dnf/` | `/var/cache/apt/` |
