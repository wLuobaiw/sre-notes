
# 日志体系概览

Linux 日志主要由两个系统管理：

| 系统 | 职责 | 日志存储 |
|------|------|---------|
| journald（systemd 内置） | 收集内核和服务的日志 | 二进制文件（`/run/log/journal/` 或 `/var/log/journal/`） |
| rsyslog（传统 syslog） | 接收和转发各类日志 | 文本文件（`/var/log/` 下） |

两者可以共存——journald 收集后转发给 rsyslog 写入文本文件。

# journalctl——查看 systemd 日志

```shell
# 查看所有日志（从旧到新）
journalctl

# 从最新开始看
journalctl -r

# 实时跟踪
journalctl -f

# 查看指定服务的日志
journalctl -u nginx.service
journalctl -u nginx.service -f       # 实时跟踪

# 按时间过滤
journalctl --since "2026-06-03"
journalctl --since "2026-06-03 08:00" --until "2026-06-03 10:00"
journalctl --since "1 hour ago"
journalctl --since yesterday

# 按优先级过滤
journalctl -p err                    # 错误及以上
journalctl -p warning                # 警告及以上

# 查看最近 N 条
journalctl -n 50

# 查看内核日志
journalctl -k

# 查看启动日志
journalctl -b                        # 本次启动
journalctl -b -1                     # 上一次启动

# 查看某用户的日志
journalctl _UID=1000
```

日志优先级（从低到高）：`debug` → `info` → `notice` → `warning` → `err` → `crit` → `alert` → `emerg`

# /var/log/ 目录结构

| 文件/目录 | 内容 |
|-----------|------|
| `/var/log/messages` | 系统通用日志（RHEL 系） |
| `/var/log/syslog` | 系统通用日志（Debian 系） |
| `/var/log/secure` | 认证相关日志（SSH 登录、sudo 等） |
| `/var/log/cron` | 定时任务执行日志 |
| `/var/log/boot.log` | 系统启动日志 |
| `/var/log/dmesg` | 内核启动日志 |
| `/var/log/audit/` | SELinux 审计日志 |
| `/var/log/nginx/` | Nginx 日志（访问/错误） |
| `/var/log/httpd/` | Apache 日志 |

# 日志分析实用命令

```shell
# 查看最近的 SSH 登录失败
grep 'Failed password' /var/log/secure | tail -20

# 统计暴力破解 IP Top 10
grep 'Failed password' /var/log/secure | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn | head -10

# 查看某时间段的日志
sed -n '/Jun  3 08:00/,/Jun  3 09:00/p' /var/log/messages

# 查看 sudo 操作记录
grep 'sudo' /var/log/secure

# 查看 cron 最近的执行记录
tail -50 /var/log/cron
```

> 这些命令中涉及的管道、重定向语法，详见 [重定向与管道](../重定向与管道.md#快速参考--日志场景对照表)。

# logrotate——日志轮转

日志文件会不断增长，logrotate 定期轮转（归档+清理）旧日志。

## 配置文件

- `/etc/logrotate.conf`：全局配置
- `/etc/logrotate.d/`：各服务的轮转配置

## 示例配置

```conf
# /etc/logrotate.d/myapp
/var/log/myapp/*.log {
    daily                   # 每天轮转
    rotate 7                # 保留 7 个归档
    compress                # 压缩归档
    delaycompress           # 延迟一天压缩（当前归档不压缩）
    missingok               # 日志文件不存在时不报错
    notifempty              # 空文件不轮转
    copytruncate            # 复制后截断（适合不支持重载的进程）
    # 或使用 postrotate 通知进程重载
    # postrotate
    #     /bin/kill -HUP $(cat /var/run/myapp.pid)
    # endscript
}
```

## 手动触发和调试

```shell
logrotate -d /etc/logrotate.conf    # 调试模式——不实际执行
logrotate -f /etc/logrotate.conf    # 强制执行轮转
logrotate -v /etc/logrotate.conf    # 详细输出
```

# 注意

- 磁盘满是最常见的事故之一——配置好 logrotate，监控 `/var/log/` 的空间
- journald 的持久化存储默认可能未开启——检查 `/etc/systemd/journald.conf` 中的 `Storage` 设置
- `tail -f` 实时查看文本日志，`journalctl -f` 实时查看 journald 日志
- 排查问题先看日志——日志是第一手信息，比猜测快得多
