
Linux 文件管理建立在"一切皆文件"的核心理念上——硬盘、键盘、网络连接、进程信息都以文件形式呈现在 `/dev`、`/proc`、`/sys` 等目录下。

# 文件系统层次结构（FHS）

| 目录 | 用途 |
|------|------|
| `/` | 根目录——所有文件的起点 |
| `/boot` | 启动文件（内核、GRUB） |
| `/etc` | 系统配置文件 |
| `/home` | 用户家目录 |
| `/root` | root 用户家目录 |
| `/var` | 可变数据（日志、缓存、数据库） |
| `/tmp` | 临时文件（重启后可能清空） |
| `/usr` | 用户程序和数据（/usr/bin、/usr/lib） |
| `/opt` | 第三方软件安装目录 |
| `/proc` | 进程和内核信息（虚拟文件系统） |
| `/sys` | 内核和设备信息（虚拟文件系统） |
| `/dev` | 设备文件 |
| `/mnt` / `/media` | 临时挂载点 / 自动挂载介质 |

# 文件类型

Linux 不以文件后缀判断类型，而是通过文件系统中的类型标记。

| 符号 | 类型 | 示例 |
|------|------|------|
| `-` | 普通文件 | 文本、二进制、图片 |
| `d` | 目录 | 文件夹 |
| `l` | 符号链接（软链接） | 快捷方式 |
| `b` | 块设备文件 | 硬盘 `/dev/sda` |
| `c` | 字符设备文件 | 终端 `/dev/tty1` |
| `s` | 套接字文件 | 网络连接 |
| `p` | 管道文件（FIFO） | 进程间通信 |

用 `ll`（`ls -l`）查看第一个字符就是文件类型。`file` 命令可以识别文件实际内容类型。

# 文件时间属性

每个文件有三个时间戳，用 `stat` 命令查看：

| 时间 | 英文 | 含义 |
|------|------|------|
| Access（atime） | 访问时间 | 文件被读取时更新 |
| Modify（mtime） | 修改时间 | 文件**内容**被修改时更新 |
| Change（ctime） | 改变时间 | 文件**元数据**（权限/所有者）变更时更新 |

> RHEL 6 起默认开启 `relatime`——atime 不会在每次读取时更新，而是满足条件（距上次更新 86400 秒或发生了写操作）才更新，减少磁盘 IO。

# 文件权限

## 基本权限（rwx）

| 符号 | 数值 | 文件 | 目录 |
|------|------|------|------|
| r | 4 | 读取内容 | 列出目录内容 |
| w | 2 | 修改内容 | 创建/删除目录内文件 |
| x | 1 | 执行为程序 | 进入目录（cd） |

三组权限：**所有者 — 所属组 — 其他人**。用 `ls -l` 查看：

```
-rwxr-xr--  1  alice  dev  1024  Jun  3 10:00  script.sh
 ├┘├┘├┘
 │ │ └─ others: r--
 │ └─── group:  r-x
 └───── owner:  rwx
```

## 特殊权限

| 权限 | 数值 | 文件 | 目录 |
|------|------|------|------|
| SUID | 4 | 以**文件所有者**身份执行 | 无效 |
| SGID | 2 | 以**文件所属组**身份执行 | 新建文件继承目录所属组 |
| SBIT | 1 | 无效 | 只有文件所有者能删除自己的文件 |

常见示例：`/usr/bin/passwd`（SUID——普通用户改密码需要写 `/etc/shadow`）、`/tmp`（SBIT——任何人可创建但只能删自己的文件）。

> 权限管理的详细命令（chmod/chown/chgrp、ACL、umask）见 [权限管理](../用户权限/权限管理.md)。
