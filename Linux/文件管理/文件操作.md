
# 目录操作

## ls——列出目录内容

```shell
ls [选项] [路径]
```

| 选项 | 作用 |
|------|------|
| `-a` | 显示所有文件，含隐藏文件（`.` 开头） |
| `-l` | 详细信息（权限、所有者、大小、时间） |
| `-h` | 人类可读的大小格式（搭配 `-l`） |
| `-t` | 按修改时间排序 |
| `-r` | 反向排序 |
| `-R` | 递归显示子目录 |
| `-S` | 按文件大小排序 |
| `-F` | 文件类型标识符（目录加 `/`，可执行加 `*`） |

## cd——切换目录

```shell
cd /path/to/dir    # 绝对路径
cd ../              # 上级目录
cd ~                # 当前用户家目录
cd -                # 回到上一次的目录
```

## pwd——显示当前目录

```shell
pwd         # 逻辑路径（可能含符号链接）
pwd -P      # 物理路径（解析所有符号链接）
```

## mkdir / rmdir——创建/删除目录

```shell
mkdir -p a/b/c      # 递归创建多层目录
mkdir -m 755 dir    # 指定权限创建
rmdir dir           # 删除空目录
```

## tree——树形显示目录结构

```shell
tree -L 2           # 限制显示 2 层深度
tree -d             # 只显示目录
```

# 文件操作

## cp——复制

```shell
cp source dest
cp -r dir1 dir2     # 递归复制目录
cp -p source dest   # 保留权限和时间
cp -i source dest   # 覆盖前确认
cp -a dir1 dir2     # 归档模式（= -rpP）
```

## mv——移动/重命名

```shell
mv old new          # 重命名
mv file /path/      # 移动
mv -i old new       # 覆盖前确认
```

## rm——删除

```shell
rm file
rm -r dir           # 递归删除目录
rm -f file          # 强制删除（不提示）
rm -rf dir          # 强制递归删除——谨慎使用
```

## touch——创建空文件/更新文件时间

```shell
touch newfile       # 创建空文件
touch -a file       # 只更新 atime
touch -m file       # 只更新 mtime
```

## ln——创建链接

```shell
ln source link       # 硬链接
ln -s source link    # 符号链接（软链接）
ln -sf source link   # 强制覆盖已有的符号链接
```

| 特性 | 硬链接 | 软链接 |
|------|--------|--------|
| 本质 | 指向同一 inode | 指向路径字符串 |
| 跨文件系统 | 不支持 | 支持 |
| 链接目录 | 不支持 | 支持 |
| 源文件删除后 | 仍然可访问 | 链接失效（悬空链接） |
| `ls -l` 显示 | 链接数递增 | `l` 权限 + `->` 指向 |

## file——识别文件类型

```shell
file unknown_file
file -i unknown_file    # 输出 MIME 类型
```

# 文本查看

## cat——连接并输出文件内容

```shell
cat file                # 输出全部内容
cat -n file             # 带行号输出
cat file1 file2 > merged # 合并文件
```

## less / more——分页浏览

```shell
less file               # 上下翻页，/ 搜索，q 退出
more file               # 只能向下翻，功能较少
```

**less 快捷键**：`Space` 下一页，`b` 上一页，`/pattern` 搜索，`n` 下一个匹配，`G` 末尾，`g` 开头

## head / tail——查看头/尾行

```shell
head -n 20 file         # 前 20 行（默认 10 行）
tail -n 20 file         # 后 20 行
tail -f /var/log/syslog  # 实时追踪文件新增内容
```

# 文本编辑器

## vim

```shell
vim file
```

基本操作：`i` 进入插入模式，`Esc` 回到普通模式，`:w` 保存，`:q` 退出，`:wq` 保存退出，`:q!` 强制不保存退出

## nano（简单编辑器）

```shell
nano file
```

底部有快捷键提示，`^` 表示 Ctrl 键。

# 文件查找

## locate——文件名快速查找（基于数据库）

```shell
locate filename
locate -i filename      # 忽略大小写
```

依赖 `updatedb` 定期更新数据库，新建文件可能搜不到。

## which / whereis——查找可执行文件

```shell
which python             # 显示在 PATH 中找到的可执行文件路径
whereis python           # 同时显示二进制、源码、man 页位置
```
