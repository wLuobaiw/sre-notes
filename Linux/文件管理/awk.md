
# 是什么

awk 是一种**模式扫描与处理语言**——它按行读取文本，按列（字段）分析和处理数据。awk 远不止是一个命令，它是一门完整的编程语言，广泛用于日志分析、报表生成、数据提取等场景。

Linux 上默认的 awk 实现是 GNU awk（`gawk`）。

# 语法

```shell
awk [选项] '模式 {动作}' [文件...]
awk [选项] -f 脚本文件 [文件...]
```

- **模式**：条件表达式或正则，决定对哪些行执行动作（可选，省略则处理所有行）
- **动作**：在匹配行上执行的代码块（可选，省略则默认 `{print}`）
- **不指定文件**时从标准输入读取

# 核心概念

| 概念 | 说明 |
|------|------|
| 记录（Record） | 一行文本就是一条记录，用 `$0` 表示整行 |
| 字段（Field） | 按分隔符切分的列：`$1` 第一列，`$2` 第二列...`$NF` 最后一列 |
| FS | **输入字段分隔符**——默认是空白（空格/Tab） |
| OFS | **输出字段分隔符**——默认是空格 |
| RS | 输入记录分隔符——默认是换行 |
| ORS | 输出记录分隔符——默认是换行 |
| NR | 已读的记录数（行号） |
| FNR | 当前文件内的行号（多文件时区别 NR） |
| NF | 当前行的字段数 |
| FILENAME | 当前正在处理的文件名 |

# 特殊模式

| 模式 | 执行时机 |
|------|----------|
| `BEGIN { }` | 读取任何输入**之前**执行——常用于初始化变量、打印表头 |
| `END { }` | 处理完所有输入**之后**执行——常用于输出汇总结果 |
| `/正则/` | 匹配正则表达式的行 |
| `条件表达式` | 如 `$3 > 100`、`NR <= 10` |
| `模式1, 模式2` | 范围匹配——从匹配模式1的行到匹配模式2的行 |

# 常用选项

| 选项 | 作用 |
|------|------|
| `-F 分隔符` | 指定输入字段分隔符 |
| `-v var=value` | 定义变量 |
| `-f script.awk` | 从脚本文件读取程序 |

# 内置函数

| 函数 | 作用 |
|------|------|
| `length(str)` | 返回字符串长度 |
| `substr(str, start, len)` | 截取子串 |
| `index(str, sub)` | 子串首次出现的位置 |
| `split(str, arr, sep)` | 按分隔符拆分字符串到数组 |
| `tolower(str)` / `toupper(str)` | 大小写转换 |
| `int(num)` | 取整 |
| `sprintf(fmt, ...)` | 格式化字符串 |

# 实用示例

```shell
# 打印第 1、3 列
awk '{print $1, $3}' access.log

# 指定分隔符——查看系统用户（/etc/passwd 用 : 分隔）
awk -F: '{print $1, $7}' /etc/passwd

# 条件过滤——找出 root 用户
awk -F: '$1 == "root" {print $0}' /etc/passwd

# 范围过滤——打印行号 5-10 之间的行
awk 'NR >= 5 && NR <= 10' file.txt

# 统计总大小
awk '{sum += $3} END {print "Total:", sum}' data.txt

# 带表头的报表
awk 'BEGIN {printf "%-20s %s\n", "User", "Shell"}
     {printf "%-20s %s\n", $1, $NF}
     END {print "---END---"}' /etc/passwd

# 统计每个 IP 的访问次数
awk '{ip[$1]++} END {for (i in ip) print ip[i], i}' access.log | sort -rn

# 打印行长度超过 80 的行号
awk 'length($0) > 80 {print NR, $0}' file.txt

# 多文件处理——区分不同文件的统计
awk 'FNR == 1 {print FILENAME}' *.log
```

# 注意

- awk 适合**结构化文本**（列式数据），不适合处理非结构化文本（如 HTML/JSON）——用 `jq` 处理 JSON
- 简单搜索用 `grep`，简单替换用 `sed`，需要计算/统计/格式化时用 awk
- `-F` 分隔符支持正则，如 `-F '[: ]+'` 表示冒号或空格分隔
- awk 脚本复杂时建议写成独立 `.awk` 文件，方便维护
- 数值运算默认是浮点数
