
# 是什么

sed（Stream Editor）是一个**逐行处理**文本流的编辑器。它读取输入行，按指令编辑，输出结果——整个过程不修改原文件（除非用 `-i`）。适用于批量文本替换、删除、插入等场景。

# 语法

```shell
sed [选项] '命令' [文件...]
sed [选项] -f 脚本文件 [文件...]
```

# 核心命令

| 命令 | 作用 |
|------|------|
| `s/旧/新/` | 替换——每行替换**第一个**匹配 |
| `s/旧/新/g` | 替换——每行替换**所有**匹配 |
| `s/旧/新/N` | 替换——每行替换**第 N 个**匹配 |
| `d` | 删除行 |
| `p` | 打印行（常与 `-n` 配合） |
| `a\文本` | 在匹配行**之后**追加文本 |
| `i\文本` | 在匹配行**之前**插入文本 |
| `c\文本` | 用新文本**替换**整行 |
| `y/源/目标/` | 字符逐对转换（类似 `tr`） |
| `=` | 打印行号 |

# 常用选项

| 选项 | 作用 |
|------|------|
| `-n` | 取消默认输出——只输出被 `p` 命令选中的行 |
| `-e` | 执行多个命令：`sed -e 'cmd1' -e 'cmd2'` |
| `-f` | 从脚本文件读取命令 |
| `-i` | **直接修改文件**（就地编辑） |
| `-i.bak` | 修改前创建 `.bak` 备份 |
| `-r` / `-E` | 扩展正则表达式 |

# 地址定界——决定对哪些行执行命令

| 定界方式 | 示例 | 含义 |
|----------|------|------|
| 单行号 | `sed '3d'` | 删除第 3 行 |
| 行范围 | `sed '2,5d'` | 删除第 2-5 行 |
| 最后一行 | `sed '$d'` | 删除最后一行 |
| 正则匹配 | `sed '/^#/d'` | 删除以 # 开头的行 |
| 正则范围 | `sed '/start/,/end/d'` | 删除 start 到 end 之间的行 |
| 步进 | `sed '1~2d'` | 删除奇数行（1,3,5...） |
| 取反 | `sed '/^#/!d'` | 删除**不是**以 # 开头的行 |

# 替换标记（s 命令的修饰符）

| 标记 | 作用 |
|------|------|
| `g` | 替换行内所有匹配 |
| `N` | 替换行内第 N 个匹配 |
| `p` | 打印替换成功的行 |
| `i` | 忽略大小写 |
| `e` | 将替换结果作为 shell 命令执行 |

# 实用示例

```shell
# 替换文件中所有 old 为 new（先测试，再加 -i）
sed 's/old/new/g' file.txt

# 就地修改并备份
sed -i.bak 's/old/new/g' file.txt

# 删除空行和纯空格行
sed '/^\s*$/d' file.txt

# 删除注释行（# 开头）
sed '/^#/d' /etc/ssh/sshd_config

# 打印第 10 到 20 行（-n 取消默认输出，p 只打印选中行）
sed -n '10,20p' file.txt

# 在匹配行后追加内容
sed '/\[Service\]/a\Environment=MYVAR=value' service.conf

# 提取日志时间范围
sed -n '/2026-06-01 08:00/,/2026-06-01 09:00/p' app.log

# 给行首加空格缩进
sed 's/^/    /' file.txt

# 删除行尾空格
sed 's/\s\+$//' file.txt

# 多个编辑命令
sed -e 's/foo/bar/g' -e '/^$/d' file.txt
```

# 注意

- `-i` 直接修改文件，**务必先不加 `-i` 测试输出**，确认无误再加
- macOS 的 BSD sed 与 Linux 的 GNU sed 差异较大——`-i` 在 macOS 上必须带备份后缀：`sed -i '' 's/old/new/' file`
- 分隔符不限于 `/`：当替换内容含 `/` 时，可用其他字符，如 `sed 's|/path/old|/path/new|g'`
- sed 本质是逐行处理，不适合跨多行的复杂操作——此时考虑 `awk` 或 `perl`
