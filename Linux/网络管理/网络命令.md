
# 接口与地址管理

## ifconfig（传统工具，逐步被 ip 取代）

```shell
# 查看所有网卡
ifconfig

# 查看指定网卡
ifconfig eth0

# 启用/禁用网卡
ifconfig eth0 up
ifconfig eth0 down

# 设置 IP 地址（临时）
ifconfig eth0 192.168.1.100 netmask 255.255.255.0
```

## ip（推荐——iproute2 套件）

```shell
# 查看所有网卡和 IP
ip addr show          # 简写: ip a

# 查看指定网卡
ip addr show eth0

# 启用/禁用网卡
ip link set eth0 up
ip link set eth0 down

# 添加/删除 IP
ip addr add 192.168.1.100/24 dev eth0
ip addr del 192.168.1.100/24 dev eth0

# 查看链路层信息
ip link show          # 简写: ip l
```

## nmcli（NetworkManager 命令行）

```shell
# 查看所有网络连接
nmcli connection show

# 查看所有设备状态
nmcli device status

# 激活/停用连接
nmcli connection up eth0
nmcli connection down eth0

# 查看 Wi-Fi
nmcli device wifi list

# 重载配置
nmcli connection reload
```

# 路由管理

## route（传统工具）

```shell
# 查看路由表
route -n

# 添加默认网关
route add default gw 192.168.1.1

# 添加静态路由
route add -net 10.0.0.0/8 gw 192.168.1.254
```

## ip route（推荐）

```shell
# 查看路由表
ip route show         # 简写: ip r

# 添加默认网关
ip route add default via 192.168.1.1

# 添加静态路由
ip route add 10.0.0.0/8 via 192.168.1.254

# 删除路由
ip route del 10.0.0.0/8
```

# 连接与端口查看

## ss（推荐——替代 netstat）

```shell
# 查看所有 TCP 连接
ss -t

# 查看所有监听端口
ss -tln

# 查看所有连接（含进程信息）
ss -tlnp

# 查看所有 UDP 连接
ss -u

# 查看所有 socket 摘要
ss -s
```

## netstat（传统工具，逐步废弃）

```shell
# 查看所有连接和监听端口
netstat -tlnp

# 查看路由表
netstat -r

# 查看网络接口统计
netstat -i
```

# 连通性测试

## ping

```shell
# 基本连通性测试
ping 8.8.8.8

# 指定次数后停止
ping -c 4 8.8.8.8

# 指定间隔（秒）
ping -i 0.5 8.8.8.8
```

**原理**：发送 ICMP Echo Request，等待 Echo Reply。不通不代表服务不可用——可能是防火墙禁了 ICMP。

## traceroute

```shell
# 追踪到达目标的路径（跳数）
traceroute 8.8.8.8

# 使用 ICMP 而非 UDP
traceroute -I 8.8.8.8
```

**原理**：利用 TTL 递增，每跳返回 ICMP Time Exceeded 来发现路由节点。

# DNS 查询

## nslookup

```shell
# 正向解析
nslookup google.com

# 反向解析
nslookup 8.8.8.8

# 指定 DNS 服务器
nslookup google.com 8.8.8.8
```

## dig（推荐——信息更详细）

```shell
# 正向解析
dig google.com

# 简洁输出（只显示 IP）
dig +short google.com

# 反向解析
dig -x 8.8.8.8

# 指定 DNS 服务器
dig @8.8.8.8 google.com

# 查看解析全过程（含递归/迭代）
dig +trace google.com

# 查看指定记录类型
dig google.com MX
dig google.com NS
dig google.com TXT
```

# 文件下载

## curl

```shell
# 下载文件
curl -O https://example.com/file.tar.gz

# 指定输出文件名
curl -o myfile.tar.gz https://example.com/file.tar.gz

# 仅显示响应头
curl -I https://example.com

# 跟随重定向
curl -L https://short.link

# POST 请求
curl -X POST -d 'key=value' https://api.example.com

# 带请求头
curl -H 'Authorization: Bearer token' https://api.example.com

# 安静模式（不显示进度条）
curl -s https://example.com
```

## wget

```shell
# 下载文件
wget https://example.com/file.tar.gz

# 指定输出文件名
wget -O myfile.tar.gz https://example.com/file.tar.gz

# 递归下载整个站点
wget -r https://example.com/docs/

# 断点续传
wget -c https://example.com/large_file.iso

# 后台下载
wget -b https://example.com/file.tar.gz

# 限速下载
wget --limit-rate=1M https://example.com/file.tar.gz
```

# 注意

- `ifconfig` / `netstat` / `route` 属于 net-tools 套件，已不再积极维护，推荐使用 `ip` / `ss` 替代
- `ss` 直接从内核获取 socket 信息，比 `netstat` 快（大量连接时差距明显）
- DNS 解析用 `dig` 而非 `nslookup`——dig 输出更规范，适合脚本解析
- 防火墙可能阻止 ICMP——ping 不通不等于服务不通
