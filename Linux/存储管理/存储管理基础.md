
# 从物理磁盘到文件系统

Linux 中，存储的完整链路是：

```
物理磁盘 → 分区 → RAID（可选）→ LVM（可选）→ 文件系统 → 挂载 → 使用
```

- **物理磁盘**：被识别为设备文件（`/dev/sda`、`/dev/nvme0n1`）
- **分区**：将磁盘划分为独立区域，通过 MBR 或 GPT 分区表管理
- **RAID**：多盘组合提高性能/冗余（可选层）
- **LVM**：灵活的卷管理，支持动态扩容和快照（可选层）
- **文件系统**：数据在分区/卷上如何组织和存储
- **挂载**：将文件系统接入目录树，用户通过路径访问

# 设备命名规则

| 设备类型 | 命名格式 | 示例 |
|----------|---------|------|
| SATA/SCSI/SAS | `/dev/sd[a-z]` | `/dev/sda` 第一块，`/dev/sdb1` 第二块的第一个分区 |
| NVMe SSD | `/dev/nvme[0-9]n[0-9]` | `/dev/nvme0n1`，分区为 `nvme0n1p1` |
| 虚拟磁盘（KVM） | `/dev/vd[a-z]` | `/dev/vda` |
| IDE/PATA（淘汰） | `/dev/hd[a-z]` | `/dev/hda` |

- **主分区编号** 1-4，**逻辑分区** 从 5 开始（仅 MBR）
- GPT 无主/逻辑之分，所有分区从 1 连续编号

# 磁盘空间查看

## df——文件系统磁盘使用情况

```shell
df -h               # 人类可读格式
df -T               # 显示文件系统类型
df -i               # 显示 inode 使用情况
```

## du——目录/文件空间估算

```shell
du -sh /var/log/     # 总计
du -h --max-depth=1 /home/   # 一层深度
du -ah /tmp/ | sort -rh | head -10  # 找出最大的 10 个文件
```
