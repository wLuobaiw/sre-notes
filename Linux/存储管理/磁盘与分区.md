
# 分区表类型

## MBR vs GPT

| 特性 | MBR | GPT |
|------|-----|-----|
| 最大磁盘容量 | 2TB | 18EB（1EB=1024PB） |
| 最大分区数 | 4 个主分区（或 3 主 + 1 扩展含多个逻辑） | 理论上无限（实际 128 个） |
| 启动方式 | BIOS | UEFI（兼容模式下也可 BIOS） |
| 冗余 | 无备份 | 磁盘尾部有 GPT 备份表 |
| 分区命名 | 主分区 1-4，逻辑分区 5+ | 所有分区连续编号 |

GPT 是当前标准，除非兼容老旧 BIOS 系统，否则首选 GPT。

## MBR 分区结构

```
sda (磁盘)
├── sda1 (主分区)
├── sda2 (主分区)
├── sda3 (主分区)
└── sda4 (扩展分区)
    ├── sda5 (逻辑分区)
    ├── sda6 (逻辑分区)
    └── sda7 (逻辑分区)
```

## GPT 分区结构

```
sda (磁盘)
├── sda1 (EFI 系统分区)
├── sda2 (根分区 /)
├── sda3 (/home 分区)
└── sda4 (swap 分区)
```

# lsblk——查看块设备

```shell
lsblk               # 树形显示设备与分区关系
lsblk -f            # 显示文件系统类型和挂载点
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINT
```

# 分区管理工具

## fdisk——MBR 分区操作

```shell
fdisk -l            # 列出所有设备的分区表
fdisk -l /dev/sda   # 查看指定设备
fdisk /dev/sdb      # 进入交互模式管理 /dev/sdb
```

交互命令：`n` 新建分区，`d` 删除分区，`p` 打印分区表，`t` 修改分区类型，`w` 保存退出，`q` 不保存退出

> fdisk 主要针对 MBR，也支持 GPT 但功能有限。GPT 操作推荐 gdisk。

## gdisk——GPT 分区操作

```shell
gdisk -l /dev/sdb   # 查看分区表
gdisk /dev/sdb      # 进入交互模式
```

交互命令与 fdisk 类似：`n`、`d`、`p`、`t`、`w`、`q`，另有 `?` 查看帮助。

## parted——高级分区（同时支持 MBR 和 GPT）

```shell
parted -l                   # 列出所有设备分区
parted /dev/sdb mklabel gpt  # 创建 GPT 分区表
parted /dev/sdb mkpart primary ext4 0% 50%  # 创建分区
parted /dev/sdb print       # 查看分区表
parted /dev/sdb resizepart 1 100%  # 调整分区大小
```

parted 支持脚本模式（`-s`），适合自动化场景。

# 注意

- 分区操作可能造成数据丢失——操作前确认设备名称正确，备份重要数据
- 修改分区表后可能需要 `partprobe` 让内核重新读取分区表
- 对正在使用的磁盘操作（如系统盘）可能导致系统崩溃
- 大于 2TB 的磁盘必须用 GPT
- 查看设备用 `lsblk` 比 `fdisk -l` 更直观
