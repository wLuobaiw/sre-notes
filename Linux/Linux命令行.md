# 目录操作

## ls

用于显示指定工作目录下之内容（列出目前工作目录所含之文件及子目录)

```shell
ls [选项]... [文件]...
```

**选项** 

- **-a, --all**：显示所有文件及目录（包括以`.`开头的隐藏文件）
- **-l**：显示详细信息（文件类型、权限、拥有者、大小等）
- **-r, --reverse**：以相反顺序显示文件
- **-t**：按文件修改时间排序
- **-A, --almost-all**：同`-a`，但不显示`.`（当前目录）和`..`（父目录）
- **-F, --classify**：在文件名后添加类型标识符（可执行文件加`*`，目录加`/`，链接加`@`）
- **-R, --recursive**：递归显示子目录内容
- **-h, --human-readable**：以易读格式显示文件大小

> **注意**
>
> 默认情况下，ls 被别名化为 ls --color=auto。要使用原始 ls 命令，请使用 \ls

## ln

用于创建文件或目录的链接（硬链接或符号链接/软链接）

```shell
ln [选项] 源文件 [目标文件]
ln [选项] 源文件... 目标目录
```

**常用选项**

- **-s, --symbolic**：创建符号链接（软链接）
- **-f, --force**：强制覆盖已存在的目标文件
- **-i, --interactive**：覆盖前提示确认
- **-n, --no-dereference**：将符号链接视为普通文件
- **-v, --verbose**：显示详细操作信息
- **-b, --backup**：覆盖前创建备份
- **-t, --target-directory=目录**：指定目标目录
- **-T, --no-target-directory**：始终将目标视为普通文件
- **-h, --help**：显示帮助信息
- **--version**：显示版本信息

**软硬链接**：

- **硬链接（hard link）**
  - 可以将它理解为一个“指向原始文件inode的指针”，系统不为它分配独立的inode和文件。所以，硬链接文件与原始文件其实是同一个文件，只是名字不同。我们每添加一个硬链接，该文件的inode连接数就会增加1；而且只有当该文件的inode连接数为0时，才算彻底将它删除。换言之，由于硬链接实际上是指向原文件inode的指针，因此即便原始文件被删除，依然可以通过硬链接文件来访问。需要注意的是，由于技术的局限性，我们不能跨分区对目录文件进行链接。
  - **特点**
    - 不能跨文件系统创建
    - 不能链接到目录（防止循环引用）
    - 删除原始文件不影响硬链接访问
    - 所有硬链接地位平等（没有"原始文件"概念）
    - `ls -l`显示的链接数会递增
- **软链接（也称为符号链接[symbolic link]）**
  - 仅仅包含所链接文件的路径名，因此能链接目录文件，也可以跨越文件系统进行链接。但是，当原始文件被删除后，链接文件也将失效，从这一点上来说与Windows系统中的“快捷方式”具有一样的性质。
  - **特点**
    - 可以跨文件系统
    - 可以链接到目录
    - 原始文件删除后链接会失效（成为"悬空链接"）
    - 权限与原始文件无关（始终显示777）
    - 会显示`->`指示链接目标

**关键区别对比** 

| 特性               | 硬链接                   | 软链接            |
| :----------------- | ------------------------ | :---------------- |
| **inode**          | 与源文件相同             | 新建独立inode     |
| **跨文件系统**     | 不支持                   | 支持              |
| **链接目录**       | 不允许（除.和..）        | 允许              |
| **原始文件删除后** | 仍可访问                 | 链接失效          |
| **文件大小**       | 与源文件相同             | 等于路径字符长度  |
| **相对路径**       | 自动转换为绝对路径       | 保持原始相对路径  |
| **更新影响**       | 同步更新所有硬链接       | 只影响自身路径    |
| **`ls -l`显示**    | 显示普通文件，链接数递增 | 显示l权限和->指向 |

> **最佳实践建议**
>
> 1. 管理配置文件优先使用软链接（如/etc下配置）
> 2. 需要确保数据不丢失时使用硬链接（如备份重要文件）
> 3. 避免创建循环软链接（如a->b->c->a）
> 4. 修改软链接应使用`ln -sf`而非直接删除重建
> 5. 通过`find -samefile`命令可查找所有硬链接副本

# 进程管理

## ps

ps命令用于显示当前进程的状态，类似于 windows 的任务管理器

```shell
ps [选项]
```

**选项** 

- **-a**：显示所有进程
- **-e**：显示所有进程（同`-A`）
- **-f**：显示完整格式信息
- **-H**：以树状结构显示进程
- **-w**：宽行显示
- **-u**：显示详细信息
- **-x**：显示无控制终端的进程

**输出格式** 

- **USER**：进程所有者
- **PID**：进程ID
- **%CPU**：CPU使用率
- **%MEM**：内存使用率
- **VSZ**：虚拟内存使用量
- **RSS**：常驻内存大小
- **TTY**：终端编号
- **STAT**：进程状态
  - **D**：不可中断休眠
  - **R**：运行中
  - **S**：可中断休眠
  - **T**：已停止
  - **Z**：僵尸进程
  - **<**：高优先级
  - **N**：低优先级
  - **+**：前台进程
  - **l**：多线程
  - **s**：会话首进程
- **START**：启动时间
- **TIME**：CPU时间
- **COMMAND**：启动命令

> **拓展：**
>
> 孤儿进程：**父进程已经终止或退出，但子进程仍在运行** 的进程。在 Linux/Unix 系统中，这类进程会被系统的 **init 进程（PID=1，如 systemd 或传统 init）接管**，并由 init 负责回收其资源
> **孤儿进程没有独立的状态符**，但它的父进程会是 `init/systemd`（PID=1），属于正常运行的进程，无需处理
>
> 僵尸进程：每个进程在运行结束后都会处于僵死状态，等待父进程调用进而释放系统资源，处于该状态的进程已经运行结束，但是它的父进程还没有释放其系统资源

## top

top命令用于实时显示 process 的动态

```shell
top [选项]
```

**选项** 

- **-d**：设置刷新间隔，效果同在交互式指令列( interactive command)按 s
- **-c**：切换命令显示模式，共有两种模式：一是只显示程序的名称，另一种是显示完整的路径与名称
- **-S**：累积模式，会将己完成或消失的子行程 ( dead child process ) 的 CPU time 累积起来
- **-s**：安全模式，将交互式指令取消, 避免潜在的危机
- **-i**：不显示任何闲置 (idle) 或无用 (zombie) 的行程
- **-n**：指定刷新次数后退出
- **-b**：批处理模式
- **-z**：彩色显示

**输出格式** 

- 第1行：系统时间、运行时间、登录终端数、系统负载（三个数值分别为1分钟、5分钟、15分钟内的平 均值，数值越小意味着负载越低）。
- 第2行：进程总数、运行中的进程数、睡眠中的进程数、停止的进程数、僵死的进程数。
- 第3行：用户占用资源百分比、系统内核占用资源百分比、改变过优先级的进程资源百分比、空闲的资源百分比等。
- 第4行：物理内存总量、内存使用量、内存空闲量、作为内核缓存的内存量。（buffer和cache之间的区 别，cache是提高cpu和内存之间的数据交换速度，buffer是io设备和存储设备之间的缓冲区）
- 第5行：虚拟内存总量、虚拟内存使用量、虚拟内存空闲量、已被提前加载的内存量。

**交互模式快捷键** 

| 快捷键 | 功能                                                    |
| :----- | :------------------------------------------------------ |
| 空格   | 立即刷新                                                |
| P      | 按CPU使用排序                                           |
| T      | 按时间排序                                              |
| q      | 退出top命令                                             |
| m      | 切换显示内存信息                                        |
| t      | 切换显示进程和CPU状态信息                               |
| c      | 切换显示命令名称和完整命令行                            |
| M      | 按内存排序                                              |
| W      | 将当前设置写入 ~/.toprc 文件中，这是top配置文件推荐方法 |
| N      | 按PID排序                                               |
| z      | 彩色显示                                                |

## lsof

用于列出系统打开的文件（List Open Files），包括普通文件、目录、设备文件、网络套接字等。

```
lsof [选项] [名称]
```

**选项**

- **-i**：列出所有网络连接
- **-i :端口**：查看指定端口的使用情况
- **-i TCP/UDP**：查看TCP/UDP连接
- **-c 进程名**：显示指定进程打开的文件
- **-p PID**：显示指定进程ID打开的文件
- **-u 用户名**：显示指定用户打开的文件
- **+D 目录**：递归查找目录下被打开的文件
- **-n**：不解析主机名（直接显示IP）
- **-P**：不解析端口名（直接显示端口号）
- **-t**：只输出PID（配合kill使用）
- **-a**：AND条件组合多个选项
- **-V**：显示版本信息
- **-h**：显示帮助信息

**常用输出字段**

- `COMMAND`：进程名称
- `PID`：进程ID
- `USER`：进程所有者
- `FD`：文件描述符
- `TYPE`：文件类型
- `DEVICE`：设备号
- `SIZE/OFF`：文件大小/偏移量
- `NODE`：inode号
- `NAME`：文件名

> **注意**
>
> 1. 需要root权限查看所有进程信息
> 2. 输出可能非常庞大，建议配合grep过滤
> 3. FD列常见值：
>    - `cwd`：当前工作目录
>    - `txt`：程序代码
>    - `mem`：内存映射文件
>    - `数字`：文件描述符
> 4. 可用于解决"设备忙"错误和恢复被删除但仍在使用的文件

## kill

kill 命令用于删除执行中的程序或工作

kill 可将指定的信号送至程序。预设的信号为 SIGTERM(15)，可将指定程序终止

```shell
kill [选项] <pid> [...]
```

**选项** 

- **-l <信号编号>**： 若不加<信号编号>选项，则 -l 参数会列出全部的信号名称
- **-s <信号名称或编号>**：指定要送出的信息
- **[程序]**：[程序]可以是程序的PID或是PGID

**常用信号编号** 

| **编号** | **信号名** | **作用**                                     |
| :------- | :--------- | :------------------------------------------- |
| 1        | SIGHUP     | 重新加载配置                                 |
| 2        | SIGINT     | 通过键盘 `ctrl+c` 打印捕获信息，程序继续运行 |
| 3        | SIGQUIT    | 通过键盘 `ctrl+\` 打印捕获信息，程序优雅退出 |
| 9        | SIGKILL    | 强制终止                                     |
| 15       | SIGTERM    | 正常终止                                     |
| 18       | SIGCONT    | 继续执行                                     |
| 19       | SIGSTOP    | 停止                                         |
| 20       | SIGTSTP    | 暂停执行                                     |

## pkill

pkill 用于杀死一个进程，与 kill 不同的是它会杀死指定名字的所有进程

```shell
pkill [options] name
```

**选项**

- **-<信号>**：指定发送的信号（数字或名称，如-9或-KILL）
- **-n, --newest**：仅匹配最新启动的进程
- **-o, --oldest**：仅匹配最早启动的进程
- **-P, --parent <PPID>**：仅匹配指定父进程的子进程
- **-u, --euid <用户>**：匹配指定有效用户的进程
- **-U, --uid <用户>**：匹配指定实际用户的进程
- **-t, --terminal <终端>**：匹配指定终端上的进程
- **-f, --full**：匹配完整命令行（而不只是进程名）
- **-x, --exact**：精确匹配整个进程名
- **-i, --ignore-case**：忽略大小写
- **-v, --inverse**：反向匹配
- **-c, --count**：只显示匹配的进程数
- **--help**：显示帮助信息
- **--version**：显示版本信息

> **注意**
>
> 1. 默认发送SIGTERM(15)信号
> 2. 需要root权限才能终止其他用户的进程
> 3. 使用-f选项时要小心，可能匹配到意外进程
> 4. 建议先用pgrep测试匹配结果

## nice

nice 是 Linux/Unix 系统中用于调整进程优先级的命令，它通过修改进程的 **nice 值** 来影响系统调度器对进程的优先级分配

```shell
nice [选项] [命令 [参数...]]
```

**选项**

- **-n, --adjustment=N**：设置优先级调整值（-20到19）
- **--help**：显示帮助信息
- **--version**：显示版本信息。

## renice

renice 是 Linux/Unix 系统中用于修改已运行进程优先级的命令，它通过调整进程的 **nice 值** 来改变系统调度器对进程的优先级分配。

```shell
renice [-n] 优先级 [选项] <PID|用户|进程组>...
```

- **-n, --priority=N**：指定新的 nice 值（`N` 范围：`-20` 到 `19`）
- **-p, --pid**：指定要调整的进程 ID（可接多个 PID，用空格分隔）
- **-u, --user**：指定用户（调整对应用户所有进程）
- **-g, --group**：指定进程组（调整对应进程组所有进程）
- **--help**：显示帮助信息
- **--version**：显示版本信息。

> **注意**
>
> 1. 普通用户只能调高已有进程的 nice 值（降低优先级）
> 2. 实时进程（SCHED_FIFO/SCHED_RR）的优先级需用 **chrt** 修改
> 3. 优先级效果在系统负载高时更显著

## chrt

chrt 是 Linux 系统中用于设置实时进程（Real-Time Process）调度策略和优先级的命令。

```shell
chrt [选项] [优先级] 命令 [参数...]
chrt [选项] -p [优先级] pid
```

**选项**

- **-p, --pid PID**：指定进程ID
- **-f, --fifo**：使用 SCHED_FIFO（先进先出）调度策略
- **-r, --rr**：使用 SCHED_RR（轮转调度）策略
- **-o, --other**：设为普通调度策略（SCHED_OTHER）
- **-m, --max**：显示当前系统的实时优先级上限
- **--help**：显示帮助信息
- **--version**：显示版本信息

## jobs

用于显示当前 shell 会话中的作业列表及其状态。作业是指在 shell 中以后台或挂起方式运行的进程。

```shell
jobs [选项] [作业标识...]
```

**选项**

- **-l, --last**：仅显示最后一个作业
- **-p, --pid**：仅显示作业的进程组 ID
- **-n, --newest**：仅显示状态改变的作业
- **-r, --running**：仅显示运行中的作业
- **-s, --stopped**：仅显示已停止的作业
- **--help**：显示帮助信息
- **--version**：显示版本信息

**作业标识符（job_spec）**

- **%n**：作业号为 n 的作业
- **%str**：命令行以 str 开头的作业
- **%?str**：命令行包含 str 的作业
- **%%** 或 **%+**：当前作业（前台作业或最近启动的后台作业）
- **%-**：前一个作业

**输出格式**

```
[作业号] 状态 命令
```

状态可能为：

- **Running**：正在运行
- **Stopped**：已停止（挂起）
- **Done**：已完成（正常退出）
- **Terminated**：已终止（被信号杀死）

> **注意**
>
> 1. jobs 命令仅显示当前 shell 会话中的作业
> 2. 作业号不同于进程 ID（PID），仅在当前 shell 中有效
> 3. 使用 fg 或 bg 命令可以将作业切换到前台或后台继续运行
> 4. 使用 kill 命令可以通过作业号终止作业（如 `kill %1`）

## nohup

用于运行不受挂断信号影响的进程，即使用户退出登录，该进程仍会继续运行

```
nohup 命令 [参数] [&]
```

**选项**

- **--help**：显示帮助信息
- **--version**：显示版本信息

> **注意**
>
> 1. **挂断信号处理**：
>    - 默认忽略 SIGHUP 信号（挂断信号）
>    - 进程不会因终端关闭或用户退出而被终止
> 2. **后台运行**：
>    - 通常与 `&` 符号配合使用使进程在后台运行
>    - 不加 `&` 时进程会在前台运行
> 3. **当使用 `nohup` 时：**
>    - 如果未重定向输出，所有输出将追加到 `nohup.out`
>    - 如果当前目录不可写，输出会重定向到 `$HOME/nohup.out`
> 4. **权限要求：**
>    - 普通用户只能 nohup 自己的进程
>    - root 用户可以 nohup 任何进程
> 5. **对于需要长期运行的重要服务，建议使用专业的进程管理工具如 `systemd`、`supervisord` 等。**

## chage

用于在Linux系统中更改用户密码过期信息

```shell
chage [选项] 用户名
```

**选项**

- **-d, --lastday=最后修改日**：设置上次密码修改日期（YYYY-MM-DD或从1970-01-01的天数）
- **-E, --expiredate=过期日期**：设置账户过期日期（YYYY-MM-DD或从1970-01-01的天数）
- **-h, --help**：显示帮助信息
- **-I, --inactive=天数**：设置密码过期后到账户被禁用的天数
- **-l, --list**：显示账户年龄信息
- **-m, --mindays=最小天数**：设置密码修改的最小间隔天数
- **-M, --maxdays=最大天数**：设置密码有效的最大天数
- **-W, --warndays=警告天数**：设置密码过期前开始警告的天数

**日期格式**

- `YYYY-MM-DD`：标准日期格式（如：2024-12-31）
- 从1970-01-01开始的天数（如：0表示立即过期）

> **注意**
>
> 1. 大多数操作需要root权限执行
> 2. 修改的信息存储在`/etc/shadow`文件中
> 3. 设置`-d 0`会强制用户下次登录时修改密码
> 4. 谨慎设置过期策略，避免意外锁定用户账户
> 5. 建议先使用`chage -l 用户名`查看当前设置

# 磁盘管理

## mkfs

用于在Linux系统上创建文件系统（格式化磁盘或分区）

```shell
mkfs [选项] [-t 文件系统类型] [设备] [大小]
```

**选项**

- **-t, --type=文件系统类型**：指定要创建的文件系统类型（如ext4、xfs、vfat等）
- **-V, --verbose**：显示详细执行过程
- **-c**：在创建文件系统前检查坏块
- **-l, --label=卷标**：设置文件系统卷标
- **-q, --quiet**：安静模式，不显示输出信息
- **--help**：显示帮助信息
- **--version**：显示版本信息

**常用文件系统类型**

- `ext4`：Linux常用日志文件系统
- `xfs`：高性能日志文件系统
- `vfat`：Windows兼容的FAT32文件系统
- `ntfs`：Windows NT文件系统
- `btrfs`：先进的Linux文件系统

> **注意**
> 
> 1. 操作会**永久删除**分区上的所有数据
> 2. 需要root权限执行
> 3. 建议先使用`lsblk`或`fdisk -l`确认设备名称
> 4. 某些文件系统类型需要额外工具包（如创建NTFS需要`ntfsprogs`）

## parted

是 GNU 发布的强大磁盘分区工具，支持多种分区表类型（包括 GPT 和 MBR）

```shell
parted [选项] [设备] [命令 [参数]]
```

**选项**

- **-l, --list**：列出所有设备的分区表
- **-s, --script**：脚本模式，不交互
- **-a, --align=[none|cyl|min|opt]**：设置分区对齐方式
- **-v, --version**：显示版本信息
- **-h, --help**：显示帮助信息

**常用交互命令**

- **mklabel**：创建新的分区表类型（如 gpt, msdos）
- **mkpart**：创建新分区
- **rm**：删除分区
- **print**：显示分区表
- **resizepart**：调整分区大小
- **set**：设置分区标志（如 boot, lvm）
- **unit**：设置显示单位（如 GB, MB, s）
- **quit**：退出

> **注意**
>
> 1. 支持大于2TB的磁盘
> 2. 操作会直接影响磁盘数据，务必谨慎
> 3. 部分操作需要卸载分区
> 4. 调整分区大小可能需要额外工具（如 e2fsck/resize2fs）

## gdisk

是专门用于 GPT 分区表的交互式分区工具

```
gdisk [选项] [设备]
```

**选项**

- **-l, --list**：列出分区表后退出
- **-p, --print**：显示分区表
- **-e, --edit**：进入交互模式（默认）
- **-v, --version**：显示版本信息
- **-h, --help**：显示帮助信息

**常用交互命令**

- **n**：创建新分区
- **d**：删除分区
- **p**：打印分区表
- **t**：更改分区类型
- **w**：保存并退出
- **q**：不保存退出
- **i**：显示分区详细信息
- **c**：更改分区名称
- **x**：专家功能菜单

> **注意**
>
> 1. 专用于GPT分区表（替代fdisk的GPT版本）
> 2. 支持创建最大18EB的分区
> 3. 操作前建议备份重要数据
> 4. 修改后可能需要 partprobe 更新内核分区表

## fdisk

用于创建、删除、修改和管理磁盘分区表

```
fdisk [选项] <设备>
```

**选项**

- **-l, --list**：列出指定设备的分区表
- **-b, --sector-size**：指定扇区大小
- **-u, --units**：显示单位（cylinders柱面/sectors扇区）
- **-s, --partitions**：显示分区大小（块数）
- **-v, --version**：显示版本信息
- **-h, --help**：显示帮助信息

**交互命令（在fdisk操作界面中使用）**

- **m**：显示帮助菜单
- **n**：创建新分区
- **d**：删除分区
- **p**：打印分区表
- **t**：更改分区类型
- **w**：保存并退出
- **q**：不保存退出
- **l**：列出已知分区类型
- **a**：设置/取消启动标志

> **注意**
>
> 1. 操作会直接影响磁盘数据，务必提前备份重要数据
> 2. 修改分区表后需要执行`partprobe`或重启使内核重新读取分区表
> 3. 对正在使用的磁盘进行操作可能导致系统崩溃
> 4. GPT分区磁盘建议使用`gdisk`工具
> 5. 对于大于2TB的磁盘，建议使用`parted`或`gdisk`工具，因为fdisk只支持MBR分区表。

## mount

用于挂载文件系统到Linux目录树的指定位置

```
mount [选项] <设备> <挂载点>
mount [选项] -t <类型> <设备> <挂载点>
mount -a [选项]
```

**常用选项**

- **-t, --types=<类型>**：指定文件系统类型(ext4/xfs/nfs等)
- **-o, --options=<选项>**：指定挂载选项(多个选项用逗号分隔)
- **-a, --all**：挂载/etc/fstab中所有可挂载的文件系统
- **-r, --read-only**：以只读方式挂载
- **-w, --rw**：以读写方式挂载(默认)
- **-n, --no-mtab**：不写入/etc/mtab
- **-v, --verbose**：显示详细执行过程
- **-l, --show-labels**：显示文件系统标签
- **--help**：显示帮助信息

**常用挂载选项(-o参数)**

- `ro/rw`：只读/读写
- `noexec`：不允许执行二进制文件
- `nosuid`：忽略suid/sgid位
- `nodev`：不解释设备文件
- `remount`：重新挂载已挂载的文件系统
- `defaults`：使用默认选项(rw,suid,dev,exec,auto,nouser,async)

> **注意**
>
> 1. 需要root权限执行
> 2. 挂载点目录必须存在
> 3. 卸载使用`umount`命令
> 4. 永久挂载需要写入/etc/fstab文件
> 5. 使用`df -h`可查看已挂载的文件系统

## umount

用于卸载已挂载的文件系统

```
umount [选项] <挂载点|设备>
```

**常用选项**

- **-f, --force**：强制卸载（文件系统忙时使用）
- **-l, --lazy**：延迟卸载（先断开文件系统，等不忙时再清理）
- **-v, --verbose**：显示详细信息
- **-a, --all**：卸载/etc/mtab中所有文件系统
- **-t, --types=TYPE**：只卸载指定类型的文件系统

> **注意**
>
> 1. 需要root权限执行
> 2. 卸载前应确保没有进程正在使用该文件系统
> 3. 遇到"device is busy"错误时：
>    - 使用`lsof <挂载点>`查看哪些进程在使用
>    - 或使用`fuser -vm <挂载点>`查看
> 4. NFS等网络文件系统可能需要`umount -f`强制卸载

## <a id=lsblk>lsblk</a> 

用于列出所有可用块设备（磁盘、分区、挂载点等）的信息，以树状结构展示其层次关系

```
lsblk [选项] [设备]
```

**选项**

- **-a, --all**：显示所有设备（包括空设备）
- **-b, --bytes**：以字节为单位显示大小
- **-d, --nodeps**：仅显示磁盘，不显示分区
- **-e, --exclude**：排除指定设备
- **-f, --fs**：显示文件系统信息
- **-i, --ascii**：仅使用ASCII字符显示树状图
- **-J, --json**：以JSON格式输出
- **-l, --list**：使用列表格式输出（非树状）
- **-m, --perms**：显示权限信息
- **-n, --noheadings**：不显示标题行
- **-o, --output**：指定输出列（如NAME,SIZE,FSTYPE,MOUNTPOINT）
- **-p, --paths**：显示完整设备路径
- **-P, --pairs**：以key="value"格式输出
- **-r, --raw**：使用原始格式输出
- **-s, --inverse**：显示依赖关系
- **-S, --scsi**：仅显示SCSI设备
- **-t, --topology**：显示拓扑信息
- **-h, --help**：显示帮助信息
- **-V, --version**：显示版本信息

**常用输出列**

- `NAME`：设备名称
- `MAJ:MIN`：主设备号和次设备号
- `RM`：是否为可移动设备（1表示可移动）
- `SIZE`：设备大小
- `RO`：是否为只读设备
- `TYPE`：设备类型（disk磁盘，part分区，lvm逻辑卷等）
- `MOUNTPOINT`：挂载点
- `FSTYPE`：文件系统类型
- `LABEL`：文件系统标签
- `UUID`：文件系统UUID
- `MODEL`：磁盘型号
- `SERIAL`：磁盘序列号

> **注意**
>
> 1. 无需root权限即可运行，但部分信息（如某些设备型号）可能需要sudo
> 2. 输出中的`TYPE`列可以区分磁盘、分区、LVM逻辑卷等
> 3. 结合`-f`选项可以查看文件系统类型和挂载点
> 4. 对于LVM管理的设备，可以配合`lvs`和`vgs`命令获取更多信息

## df

用于显示文件系统的磁盘空间使用情况

```
df [选项] [文件或目录]
```

**常用选项**

- **-h, --human-readable**：以易读格式显示（K/M/G）
- **-T, --print-type**：显示文件系统类型
- **-i, --inodes**：显示inode使用情况而非块使用情况
- **-a, --all**：显示所有文件系统
- **-x, --exclude-type=TYPE**：排除指定类型的文件系统
- **--total**：显示总计信息
- **-l, --local**：只显示本地文件系统

## du

用于估算文件和目录的磁盘使用空间

```
du [选项] [文件或目录]
```

**常用选项**

- **-h, --human-readable**：以易读格式显示
- **-s, --summarize**：只显示总计
- **-a, --all**：显示所有文件的统计
- **-c, --total**：显示总计并输出总用量
- **--max-depth=N**：显示N级子目录的统计
- **--exclude=PATTERN**：排除匹配的文件/目录
