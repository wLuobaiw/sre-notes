
# 基本权限（rwx）

每个文件有三组权限，分别对应三类用户：

| 符号 | 数值 | 文件 | 目录 |
|------|------|------|------|
| r | 4 | 读取内容 | 列出目录内容（ls） |
| w | 2 | 修改内容 | 创建/删除目录内文件 |
| x | 1 | 执行为程序 | 进入目录（cd） |

三组权限顺序：**所有者（owner）— 所属组（group）— 其他人（other）**

```shell
# ls -l 输出示例
-rwxr-xr-- 1 alice dev 1024 Jun  3 10:00 script.sh
# ├┘├┘├┘
# │ │ └─ others: r--
# │ └─── group:  r-x
# └───── owner:  rwx
```

# chmod——修改权限

## 数字模式

```shell
chmod 755 file       # owner=rwx, group=r-x, others=r-x
chmod 644 file       # owner=rw-, group=r--, others=r--
chmod 600 file       # owner=rw-, 其他全无（私密文件）
```

## 符号模式

```shell
chmod u+x file       # 所有者加执行权限
chmod go-w file      # 组和其他人去掉写权限
chmod a+r file       # 所有人加读权限
chmod o= file        # 其他人权限全部清除
```

符号含义：`u`=owner, `g`=group, `o`=others, `a`=all, `+`=添加, `-`=移除, `=`=精确设置

## 递归修改

```shell
chmod -R 755 dir/            # 递归设置（目录和文件都 755）
find dir/ -type d -exec chmod 755 {} \;   # 只改目录
find dir/ -type f -exec chmod 644 {} \;   # 只改文件
```

# chown——修改所有者

```shell
chown user file                 # 修改文件所有者
chown user:group file           # 同时修改所有者和组
chown -R user:group dir/        # 递归修改
```

# chgrp——修改所属组

```shell
chgrp group file
chgrp -R group dir/
```

# 特殊权限

| 权限 | 数值 | 文件 | 目录 |
|------|------|------|------|
| SUID | 4 | 以**文件所有者**身份执行 | 无效 |
| SGID | 2 | 以**文件所属组**身份执行 | 新建文件继承目录所属组 |
| SBIT | 1 | 无效 | 只有文件所有者能删除自己的文件 |

```shell
chmod u+s file      # 设置 SUID
chmod g+s dir       # 设置 SGID
chmod o+t dir       # 设置 SBIT（粘滞位）

# 数字模式：将特殊权限位加在三位数字前面
chmod 4755 file     # SUID + rwxr-xr-x
chmod 2775 dir      # SGID + rwxrwxr-x
chmod 1777 dir      # SBIT + rwxrwxrwx（如 /tmp）
```

常见示例：`/usr/bin/passwd`（SUID——普通用户修改密码需要写入 /etc/shadow）、`/tmp`（SBIT——任何人可创建文件但只能删除自己的）

# umask——默认权限掩码

新建文件和目录的默认权限由 umask 决定：
- 文件默认 666，目录默认 777
- 实际权限 = 默认 - umask

```shell
umask           # 查看当前 umask（通常是 0022）
umask 0027      # 设置新 umask
```

umask 022 → 文件为 644，目录为 755

# ACL（访问控制列表）

基本权限每文件只能指定一个所有者、一个组、一组 others 权限。ACL 允许针对特定用户或组设置额外权限。

```shell
# 查看 ACL
getfacl file

# 给用户 alice 添加读写权限
setfacl -m u:alice:rw file

# 给组 dev 添加读权限
setfacl -m g:dev:r file

# 删除 ACL 条目
setfacl -x u:alice file

# 递归设置
setfacl -R -m u:alice:rx dir/

# 设置默认 ACL（目录中新建文件自动继承）
setfacl -d -m u:alice:rw dir/
```

`ls -l` 中 `+` 号表示文件有 ACL。

# 注意

- 权限 777（所有人可读写执行）基本等于安全漏洞——永远不要这样设置
- 特殊权限 SUID/SGID 有安全风险——只对不同用户需要临时提权的场景使用
- 文件权限和目录权限的含义不同——能读文件不意味着能 `cd` 进文件所在的目录
