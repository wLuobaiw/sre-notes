
# 用户管理

## useradd——创建用户

```shell
useradd [选项] 用户名
```

| 选项 | 作用 |
|------|------|
| `-d 目录` | 指定家目录（默认 `/home/用户名`） |
| `-s Shell` | 指定登录 Shell（默认 `/bin/bash`） |
| `-g 组` | 指定主组 |
| `-G 组1,组2` | 指定附加组 |
| `-u UID` | 指定 UID |
| `-M` | 不创建家目录 |
| `-r` | 创建系统用户 |
| `-m` | 强制创建家目录 |
| `-e 日期` | 账户过期日期（YYYY-MM-DD） |

```shell
# 示例：创建用户并指定附加组
useradd -G wheel,docker -s /bin/bash alice
```

## usermod——修改用户

```shell
usermod [选项] 用户名
```

| 选项 | 作用 |
|------|------|
| `-l 新名` | 修改用户名 |
| `-d 目录` | 修改家目录 |
| `-s Shell` | 修改登录 Shell |
| `-aG 组` | 添加到附加组（-a 追加，不覆盖已有） |
| `-L` / `-U` | 锁定/解锁账户 |

## userdel——删除用户

```shell
userdel username        # 删除用户，保留家目录
userdel -r username     # 删除用户及家目录和邮件
```

## passwd——密码管理

```shell
passwd                  # 修改当前用户密码
passwd username         # root 修改指定用户密码
passwd -l username      # 锁定账户密码
passwd -u username      # 解锁账户密码
passwd -S username      # 查看密码状态
passwd -e username      # 强制用户下次登录修改密码
```

## chage——密码过期策略

```shell
chage [选项] 用户名
```

| 选项 | 作用 |
|------|------|
| `-M 天数` | 密码最大有效天数 |
| `-m 天数` | 密码修改最小间隔天数 |
| `-W 天数` | 密码过期前多少天开始警告 |
| `-E 日期` | 账户过期日期（YYYY-MM-DD） |
| `-d 0` | 强制用户下次登录修改密码 |
| `-l` | 查看当前密码策略 |

# 组管理

## groupadd / groupmod / groupdel

```shell
groupadd groupname         # 创建组
groupadd -g GID groupname  # 指定 GID 创建组
groupmod -n newname oldname # 重命名组
groupdel groupname         # 删除组（组内不能有用户）
```

## groups——查看用户所属组

```shell
groups              # 查看当前用户的组
groups username     # 查看指定用户的组
```

# 注意

- 用户创建后默认只属于同名主组——如需 sudo 权限，需加入 `wheel`（RHEL 系）或 `sudo`（Debian 系）组
- `usermod -G` 不加 `-a` 会**覆盖**原有附加组——始终使用 `-aG` 追加
- 删除用户前确认没有残留进程和文件：`find / -user username` 查找
