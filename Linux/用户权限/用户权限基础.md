
# Linux 用户模型

Linux 是多用户系统，每个用户有一个唯一的 **UID**（用户 ID）。用户隶属于一个主组和若干附加组，组有唯一的 **GID**（组 ID）。

## 用户类型

| 类型 | UID 范围 | 说明 |
|------|---------|------|
| root（超级用户） | 0 | 拥有所有权限 |
| 系统用户 | 1-999（RHEL 7+） | 运行服务进程，通常不能登录 |
| 普通用户 | 1000+ | 日常使用，权限受限 |

## 关键文件

| 文件 | 内容 |
|------|------|
| `/etc/passwd` | 用户基本信息（用户名、UID、GID、家目录、Shell） |
| `/etc/shadow` | 加密后的密码及密码策略 |
| `/etc/group` | 组信息（组名、GID、组成员） |

# 用户切换与提权

## su——切换用户

```shell
su - username       # 切换到 username，加载其完整环境
su username         # 切换用户但不切换环境
su -                # 切换到 root
```

## sudo——以其他用户身份执行命令

```shell
sudo command                # 以 root 身份执行
sudo -u username command    # 以指定用户身份执行
sudo -i                     # 获取 root shell
sudo -l                     # 查看当前用户 sudo 权限
```

sudo 的权限配置在 `/etc/sudoers`，通过 `visudo` 编辑。

# id / whoami——查看身份

```shell
id                  # 显示当前用户的 UID、GID、所属组
id username         # 显示指定用户的信息
whoami              # 显示当前用户名
who                 # 显示当前登录的所有用户
w                   # 显示登录用户及正在执行的操作
```
