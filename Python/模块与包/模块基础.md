
Python 通过模块（`.py` 文件）和包（含 `__init__.py` 的目录）组织代码。

# import 基本形式

```python
import os                  # 导入模块
from os import path        # 导入指定名称
from os import path as p   # 别名
```

# `__name__ == "__main__"`

文件直接运行时 `__name__` 为 `"__main__"`，被导入时为模块名。用于区分"作为脚本执行"还是"作为库被引用"。

# pip 包管理

```shell
pip install <pkg>                    # 安装
pip install -r requirements.txt      # 批量安装依赖
pip freeze > requirements.txt        # 导出依赖清单
```
