# 字符串常用方法速查

Python 字符串对象提供了丰富的内置方法，覆盖查找、替换、拆分、拼接、判断、格式化等场景。

> 字符串是**不可变**对象，所有"修改"操作实际返回新字符串，原字符串不变。

---

## 拆分 —— split / rsplit / splitlines

### split

按分隔符切分字符串，默认按空白字符（空格、换行、制表符等）切分。

```python
s = "a  b  c"
s.split()            # ["a", "b", "c"] —— 默认按任意空白切，连续空白合并

s = "a,b,c"
s.split(",")         # ["a", "b", "c"] —— 指定分隔符
s.split(",", 1)      # ["a", "b,c"] —— maxsplit=1，只切一次

# split 默认与指定分隔符的区别
s = "  a  b  "
s.split()            # ["a", "b"] —— 默认会去除首尾空白
s.split(" ")         # ["", "", "a", "", "b", "", ""] —— 指定空格时不合并、不忽略首尾
```

### rsplit

从右侧开始切分，仅 `maxsplit` 生效时结果不同：

```python
s = "a,b,c,d"
s.split(",", 1)      # ["a", "b,c,d"]
s.rsplit(",", 1)     # ["a,b,c", "d"]
```

### splitlines

按行切分，自动识别 `\n`、`\r\n`、`\r` 等换行符。`keepends=True` 保留换行符。

```python
text = "line1\nline2\r\nline3"
text.splitlines()           # ["line1", "line2", "line3"]
text.splitlines(keepends=True)  # ["line1\n", "line2\r\n", "line3"]
```

## 拼接 —— join

将可迭代对象中的字符串元素用**分隔符**拼接成一个字符串。

```python
",".join(["a", "b", "c"])    # "a,b,c"
" ".join(["hello", "world"]) # "hello world"
"".join(["a", "b", "c"])     # "abc" —— 空分隔符直接拼接
"/".join("abc")              # "a/b/c" —— 字符串也是可迭代对象
```

> 与 `+` 拼接对比：`join()` 在拼接大量字符串时**性能远优于 `+`**（`join` 只分配一次内存，`+` 每次创建新字符串对象）。

## 去除空白字符 —— strip / lstrip / rstrip

去除首尾指定的字符（默认去除空白字符：空格、`\t`、`\n`、`\r` 等）。

```python
s = "  hello  "

s.strip()            # "hello"
s.lstrip()           # "hello  "
s.rstrip()           # "  hello"

# 指定去除的字符集合
"***hello**".strip("*")      # "hello"
"xyxhelloxyx".strip("xy")    # "hello" —— 注意！不是去掉 "xy" 子串，而是去掉任意 x 或 y
```

> `strip("xy")` 是去除字符集合 `{"x", "y"}` 中的**任意字符**，不是去除子串 `"xy"`。这是常见误区。

## 查找与定位 —— find / index / count

### find & rfind

`find` 查找子串，返回**首次出现**的索引，**找不到返回 -1**（不抛异常）。

```python
s = "hello world"
s.find("o")          # 4 —— 第一个 o 在索引 4
s.find("o", 5)       # 7 —— 从索引 5 开始找
s.rfind("o")         # 7 —— 从右侧找（最后一次出现）
s.find("xyz")        # -1 —— 找不到
```

### index & rindex

与 `find` 功能相同，但找不到时**抛出 ValueError**。

```python
s.index("o")         # 4
s.index("xyz")       # ValueError —— 找不到直接报错
```

选择建议：用 `find` 查不确信是否存在的子串（返回 -1 易处理），用 `index` 查确信该存在的子串（报错能尽早暴露问题）。

### count

统计子串出现次数：

```python
"hello world".count("o")       # 2
"ababab".count("aba")          # 2 —— 不重叠计数
"aaaa".count("aa")             # 2 —— 视为 [aa][aa]，不会交叉匹配
```

## 替换 —— replace

```python
"hello world".replace("world", "Python")  # "hello Python"
"a b c".replace(" ", "")                  # "abc" —— 删除所有空格
"aaaa".replace("a", "b", 2)              # "bbaa" —— count 参数限制替换次数
```

## 判断方法 —— startswith / endswith / isXXX

### startswith & endswith

检查前缀/后缀，支持**元组**传入多个选项：

```python
"hello.py".startswith("he")      # True
"hello.py".endswith(".py")       # True
"hello.py".endswith((".md", ".py", ".txt"))  # True —— 元组匹配任一
```

### isXXX 系列

这些方法全部返回布尔值，用于判断字符串的内容特征：

| 方法 | 用途 | 注意 |
|------|------|------|
| `isalpha()` | 全为字母（含中文、日文等Unicode字母） | `"abc中文".isalpha()` → True |
| `isdigit()` | 全为数字 | `"123".isdigit()` → True；`"Ⅷ".isdigit()` → True（Unicode数字） |
| `isnumeric()` | 全为数值字符 | 比 `isdigit()` 范围更宽，含中文数字等 |
| `isalnum()` | 全为字母或数字（无符号） | `"abc123".isalnum()` → True |
| `isspace()` | 全为空白字符 | `" \t\n".isspace()` → True |
| `islower()` | 全为小写（字母部分） | `"hello world".islower()` → True |
| `isupper()` | 全为大写（字母部分） | `"HELLO".isupper()` → True |
| `istitle()` | 每个单词首字母大写 | `"Hello World".istitle()` → True |
| `isascii()` | 全为 ASCII 字符 | Python 3.7+ |
| `isdecimal()` | 全为十进制数字（最严格） | `"123".isdecimal()` → True; `"Ⅷ".isdecimal()` → False |

> `"".isalpha()` → **False** —— 空字符串对大多数 `isXXX` 方法返回 False。

## 大小写变换

```python
"hello".upper()          # "HELLO"
"HELLO".lower()          # "hello"
"hello world".title()    # "Hello World" —— 每个单词首字母大写
"hello".capitalize()     # "Hello" —— 只有首字母大写（其余变小写）
"hELLO".swapcase()       # "Hello" —— 大小写反转
"hello".casefold()       # "hello" —— 比 lower() 更激进的变小写（处理多语言特殊大小写）
```

## 对齐与填充

```python
s = "hi"
s.center(10)          # "    hi    " —— 居中，默认填充空格
s.center(10, "-")     # "----hi----"

s.ljust(10)           # "hi        " —— 左对齐
s.ljust(10, "*")      # "hi********"

s.rjust(10)           # "        hi" —— 右对齐
s.rjust(10, "*")      # "********hi"

"42".zfill(5)         # "00042" —— 用 0 填充左侧，专门用于数字字符串
"-42".zfill(5)        # "-0042" —— 符号也算在宽度内但放在前面
```

> 也可以用格式化字符串来做对齐，效果相同：`f"{s:*^10}"` 等价于 `s.center(10, "*")`。

## 拆分三段 —— partition / rpartition

按分隔符拆分为 `(前面部分, 分隔符, 后面部分)` 的三元组。**总能返回三元组**，找不到时返回 `(原字符串, "", "")`。

```python
"a=b=c".partition("=")     # ("a", "=", "b=c")
"a=b=c".rpartition("=")    # ("a=b", "=", "c")
"hello".partition("=")     # ("hello", "", "") —— 找不到，分隔符为空
```

## 编码与解码 —— encode / decode

Python 中 `str` 是 Unicode 字符串，`bytes` 是字节序列。两者通过 `encode()` / `decode()` 互转。

```python
# str → bytes
"hello".encode("utf-8")          # b"hello"
"你好".encode("utf-8")           # b"\xe4\xbd\xa0\xe5\xa5\xbd"

# bytes → str
b"hello".decode("utf-8")         # "hello"
b"\xe4\xbd\xa0\xe5\xa5\xbd".decode("utf-8")  # "你好"

# 指定编码错误处理
"你好".encode("ascii")           # UnicodeEncodeError —— ascii 不含中文
"你好".encode("ascii", errors="ignore")   # b"" —— 忽略无法编码的字符
"你好".encode("ascii", errors="replace")  # b"??" —— 用 ? 替换
```

## translate & maketrans（略）

`translate` + `maketrans` 用于**字符级批量替换/删除**，常用于清理文本。

```python
trans = str.maketrans({"a": "1", "b": "2"})  # 映射表
"abc".translate(trans)                        # "12c"

# 删除指定字符
"abc123".translate(str.maketrans("", "", "0123456789"))  # "abc"
```
