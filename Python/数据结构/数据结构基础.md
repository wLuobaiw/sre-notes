
Python 内置四种核心容器类型：list、tuple、dict、set。选择哪种结构取决于数据的使用模式。

# 四种结构速查

| 类型 | 有序？ | 可变？ | 可哈希？ | 典型场景 |
|------|:-----:|:-----:|:------:|---------|
| `list` | 是 | 是 | 否 | 有序集合、栈 |
| `tuple` | 是 | 否 | 是（元素全可哈希时） | dict key、多返回值 |
| `dict` | 是（3.7+） | 是 | 否 | 键值映射、缓存 |
| `set` | 否 | 是 | 否 | 去重、成员判断 |
| `frozenset` | 否 | 否 | 是 | 作为 dict key 的集合 |

# 选择原则

- 需要**键值映射** → `dict`
- 需要**去重**或**快速成员检查**（O(1)）→ `set`
- 需要**有序可变**序列 → `list`
- 需要**不可变**序列（如作 dict 的 key）→ `tuple`
- 需要**不可变**集合 → `frozenset`
