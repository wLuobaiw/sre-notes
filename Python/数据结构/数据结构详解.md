# list / tuple / dict / set 方法详解

## list —— 有序可变序列

列表是 Python 中最常用的容器，底层是**动态数组**。

### 创建

```python
lst = [1, 2, 3]
lst = list("abc")                   # ["a", "b", "c"]
lst = list(range(5))                # [0, 1, 2, 3, 4]
lst = [0] * 5                       # [0, 0, 0, 0, 0]

# 注意！嵌套列表的 * 会复制引用，不是复制值
lst = [[]] * 3                      # [[], [], []] —— 三个元素指向同一个空列表
lst[0].append(1)                    # [[1], [1], [1]] —— 全部变了！
```

### 常用方法

| 方法 | 功能 | 返回值 |
|------|------|:------:|
| `append(x)` | 尾部追加一个元素 | 无（原地修改） |
| `extend(iterable)` | 尾部追加多个元素 | 无 |
| `insert(i, x)` | 在索引 i 处插入 | 无 |
| `remove(x)` | 删除第一个值为 x 的元素（找不到报 ValueError） | 无 |
| `pop(i=-1)` | 移除并返回索引 i 的元素（默认最后一个） | 被移除的元素 |
| `clear()` | 清空所有元素 | 无 |
| `index(x)` | 返回第一个值为 x 的索引（找不到报 ValueError） | int |
| `count(x)` | 统计 x 出现次数 | int |
| `sort(key=None, reverse=False)` | 原地排序 | 无 |
| `reverse()` | 原地反转 | 无 |
| `copy()` | 浅拷贝 | 新 list |

```python
# append vs extend
lst = [1, 2]
lst.append([3, 4])         # [1, 2, [3, 4]] —— 把整个 [3,4] 当做一个元素加进去
lst.extend([3, 4])         # [1, 2, 3, 4] —— 把 [3,4] 的元素逐个加入

# sort：key 参数指定排序依据
items = ["ab", "abc", "a"]
items.sort(key=len)        # ["a", "ab", "abc"] —— 按长度排序
items.sort(key=str.lower)  # 忽略大小写排序

# 需要保留原列表 → 用 sorted() 而不是 .sort()
sorted_lst = sorted(items, key=len)   # 返回新列表，原列表不变
```

### 栈与队列

```python
# 栈（后进先出）
stack = []
stack.append(1)            # push
stack.append(2)
stack.pop()                # 2 —— 弹出最后一个

# 队列（先进先出）—— list 不是好选择，pop(0) 是 O(n)
# 应使用 collections.deque
from collections import deque
queue = deque()
queue.append(1)
queue.append(2)
queue.popleft()            # 1 —— O(1)
```

### 性能特性

| 操作 | 复杂度 | 说明 |
|------|:------:|------|
| 索引 `lst[i]` | O(1) | 底层数组，直接寻址 |
| `append` / `pop()` | O(1) | 尾部操作，无需移动元素 |
| `insert(i)` / `pop(i)` | O(n) | 中间操作，需移动后续元素 |
| `x in lst` | O(n) | 线性扫描 |
| `sort()` | O(n log n) | Timsort 算法 |

## tuple —— 有序不可变序列

元组一旦创建，**内容不可修改**。

### 创建

```python
t = (1, 2, 3)
t = 1, 2, 3               # 括号可省略
t = tuple([1, 2, 3])

# 单元素元组 —— 必须加逗号
t = (1,)                   # 这才是元组
t = (1)                    # 这是整数 1，括号只是分组符
```

### 不可变的含义

"不可变"指元组**自身内容**不可变。但如果元组包含可变对象（如 list），该可变对象的内部可以改变：

```python
t = ([1, 2], 3)
t[0].append(3)             # t → ([1, 2, 3], 3) —— 里面的 list 变了
t[0] = [4, 5]              # TypeError —— 但替换元组元素本身不行
```

### 为什么需要 tuple

- **作为 dict 的 key**（list 不可哈希，tuple 可哈希）
- **不可变 = 安全**：不怕被意外修改，适合传常量数据
- **多返回值**：`return x, y` 本质是返回了 tuple
- **格式化传递多个值**
- **序列解包**：`a, b, c = (1, 2, 3)`

### 方法

tuple 只有两个方法（因为没有增删改操作）：

```python
t = (1, 2, 3, 1, 2)
t.count(1)                 # 2
t.index(2)                 # 1
```

## dict —— 键值对映射

字典底层是**哈希表**，key → value 的映射关系。

### 创建

```python
d = {"a": 1, "b": 2}
d = dict(a=1, b=2)              # 仅当 key 是合法标识符时可用
d = dict([("a", 1), ("b", 2)])  # 从键值对列表创建
d = dict.fromkeys(["a", "b"], 0)  # {"a": 0, "b": 0} —— 统一默认值

# 字典推导式
d = {x: x**2 for x in range(5)}  # {0:0, 1:1, 2:4, 3:9, 4:16}
```

### key 的要求

**key 必须是可哈希的**（不可变类型）：

```python
d = {}
d["key"] = 1               # OK —— str 可哈希
d[(1, 2)] = 2              # OK —— tuple 可哈希
d[[1, 2]] = 3              # TypeError: unhashable type: 'list'
```

### 常用方法

#### 取值

| 方法 | 行为 |
|------|------|
| `d[key]` | key 不存在抛 KeyError |
| `d.get(key, default)` | key 不存在返回 default（默认 None），不抛异常 |
| `setdefault(key, default)` | 若 key 存在返回其值，不存在则设置为 default 并返回 |

```python
# get 的典型用法
config = {}
timeout = config.get("timeout", 30)           # 30 —— key 不存在时用默认值

# setdefault —— 计数器场景
d = {}
for word in ["a", "b", "a"]:
    d[word] = d.setdefault(word, 0) + 1       # {"a": 2, "b": 1}
```

#### 遍历

```python
d = {"a": 1, "b": 2}

# 遍历 key
for k in d:                    # 默认遍历 key

# 遍历 value
for v in d.values():

# 遍历 key-value
for k, v in d.items():         # 最常用

# Python 3.7+ 遍历顺序 = 插入顺序
```

#### 增删

| 方法 | 功能 |
|------|------|
| `d[key] = value` | 设置/覆盖（key 存在则覆盖） |
| `update(other_dict)` | 批量合并（更新已有 key，添加新 key） |
| `pop(key)` | 移除并返回 value（key 不存在报 KeyError） |
| `popitem()` | 移除并返回最后一对 key-value（Python 3.7+ 是最后插入的） |
| `del d[key]` | 删除指定 key |
| `clear()` | 清空 |

### 合并字典

```python
# Python 3.9+: | 运算符
d1 = {"a": 1}
d2 = {"b": 2}
merged = d1 | d2                       # {"a": 1, "b": 2} —— 返回新字典
d1 |= d2                               # 原地更新 d1

# Python 3.5+: ** 解包
merged = {**d1, **d2}                  # {"a": 1, "b": 2}
```

### 字典视图

`keys()`、`values()`、`items()` 返回的是**字典视图（view）**，不是拷贝——会随原字典的变化而变化：

```python
d = {"a": 1}
keys = d.keys()
d["b"] = 2
print(keys)        # dict_keys(["a", "b"]) —— 视图自动反映变化
```

## set —— 无序不重复集合

集合底层也是**哈希表**，元素必须是可哈希的。

### 创建

```python
s = {1, 2, 3}
s = set()                          # 空集合 —— 不能用 {}，那是空 dict
s = set([1, 2, 2, 3])             # {1, 2, 3} —— 自动去重
```

### 基本方法

| 方法 | 功能 | 备注 |
|------|------|------|
| `add(x)` | 添加一个元素 | 已存在则无效果 |
| `remove(x)` | 移除元素 | 不存在抛 KeyError |
| `discard(x)` | 移除元素 | 不存在不报错 |
| `pop()` | 移除并返回任意一个元素 | 空集合抛 KeyError |
| `clear()` | 清空 | |
| `update(iterable)` | 批量添加 | 等价于 `|=` |

### 集合运算

```python
a = {1, 2, 3}
b = {2, 3, 4}

# 运算符方式
a | b          # {1, 2, 3, 4} —— 并集
a & b          # {2, 3} —— 交集
a - b          # {1} —— 差集（a 有而 b 无）
a ^ b          # {1, 4} —— 对称差集（仅出现在其中一方的元素）

# 方法方式（参数不限于 set，任意可迭代对象均可）
a.union([3, 4])
a.intersection([2, 3])
a.difference([2, 3])

# 子集/超集判断
{1, 2}.issubset({1, 2, 3})       # True
{1, 2, 3}.issuperset({1, 2})      # True
{1, 2}.isdisjoint({3, 4})         # True —— 不相交
```

### 性能特性

集合的增、删、查（`in`）都是 **O(1)**，因为底层是哈希表。这使得集合在**成员判断**和**去重**场景中远优于列表。

### frozenset —— 不可变集合

set 不可哈希（不能作 dict 的 key 或另一个 set 的元素），frozenset 可以。

```python
fs = frozenset([1, 2, 3])
d = {fs: "value"}                 # OK —— frozenset 可哈希

# 所有集合运算都支持，但不能增删改
fs | frozenset([3, 4])            # frozenset({1, 2, 3, 4})
fs.add(4)                         # AttributeError —— 不可变
```

### 典型应用

```python
# 去重
unique = list(set([1, 2, 2, 3]))                 # [1, 2, 3]

# 快速成员检查
if item in my_set:                                # O(1)，比 list 的 O(n) 快得多

# 交并差集操作
seen = set()
new_items = incoming - seen                       # 找出新元素
```

## 四种结构对比速查

| 类型 | 有序？ | 可变？ | 可哈希？ | 底层 | 常用场景 |
|------|:-----:|:-----:|:------:|------|---------|
| `list` | 是 | 是 | 否 | 动态数组 | 有序集合、栈 |
| `tuple` | 是 | 否 | 是（元素全可哈希时） | 数组（不可变） | dict key、多返回值、常量 |
| `dict` | 是（3.7+） | 是 | 否 | 哈希表 | 键值映射、配置、缓存 |
| `set` | 否 | 是 | 否 | 哈希表 | 去重、成员判断、集合运算 |
| `frozenset` | 否 | 否 | 是 | 哈希表 | 作为 dict key 或 set 元素 |
