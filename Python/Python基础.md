# 数据类型速览

|   类型    | 可变性 |      可哈希      |           说明           |
| :-------: | :----: | :--------------: | :----------------------: |
|   `int`   | 不可变 |      可哈希      |           整数           |
|  `float`  | 不可变 |      可哈希      |          浮点数          |
|   `str`   | 不可变 |      可哈希      |          字符串          |
|  `bool`   | 不可变 |      可哈希      | 布尔值，是 `int` 的子类  |
|  `None`   | 不可变 |      可哈希      |        空值（单例）        |
|  `list`   |  可变  |  **不可哈希**  |      列表，有序集合      |
|  `tuple`  | 不可变 | 可哈希（元素全可哈希时） |      元组，有序不可变      |
|  `dict`   |  可变  |  **不可哈希**  |      字典，键值对映射      |
|   `set`   |  可变  |  **不可哈希**  |    集合，无序不重复元素    |
| `frozenset` | 不可变 |      可哈希      |    冻结集合，可作 dict 的 key  |

## 可变 vs 不可变

**不可变对象**创建后内容不可修改，任何"修改"操作实际上是**创建了新对象**并返回。

```python
s = "hello"
print(id(s))       # 原字符串的内存地址
s = s + " world"   # 实际上是创建了一个新字符串对象
print(id(s))       # 地址变了 —— 新对象
```

**可变对象**可以在原地修改内容，内存地址不变。

```python
lst = [1, 2, 3]
print(id(lst))     # 原列表的内存地址
lst.append(4)      # 原地修改
print(id(lst))     # 地址不变 —— 同一个对象
```

**为什么重要：**

- 只有不可变对象才能作为 `dict` 的 key 和 `set` 的元素（可哈希）
- 函数参数传递时，可变对象在函数内的修改会影响外部
- 不可变对象作为默认参数是安全的（可变对象作为默认参数有陷阱）

## 可哈希 vs 不可哈希

**可哈希** = 对象实现了 `__hash__()` 方法，且哈希值在其生命周期内不变。

简单规则：**不可变对象通常可哈希，可变对象不可哈希**。

`dict` 的 key 和 `set` 的元素必须是可哈希的，因为底层依赖哈希表快速查找。

```python
# 可哈希 → 能当 key
d = {}
d["hello"] = 1       # OK
d[(1, 2)] = 2        # OK — tuple 不可变

# 不可哈希 → 报错
d[[1, 2]] = 3        # TypeError: unhashable type: 'list'
d[{1, 2}] = 4        # TypeError: unhashable type: 'set'
```

> **注意**：tuple 包含不可哈希元素时自身也不可哈希。如 `([1,2], 3)` 不可哈希，因为里面有个 list。

# 字符串切片

切片语法：`[start:stop:step]`，start 包含、stop 不包含。

```python
s = "Hello World"

s[0:5]    # "Hello" — 索引0到5（不含5）
s[:5]     # "Hello" — 省略 start，默认从 0 开始
s[6:]     # "World" — 省略 stop，默认到末尾
s[:]      # "Hello World" — 完整拷贝
s[::2]    # "HloWrd" — 步长 2，每两个取一个
s[::-1]   # "dlroW olleH" — 步长 -1，反转字符串
s[-5:]    # "World" — 负数索引，从末尾倒数
```

# 推导式与生成器表达式

## 列表推导式

```python
# 基本形式
[x**2 for x in range(10)]                     # [0, 1, 4, 9, ..., 81]

# 带过滤条件
[x**2 for x in range(10) if x % 2 == 0]       # [0, 4, 16, 36, 64]

# 嵌套循环
[(x, y) for x in range(2) for y in range(2)]  # [(0,0), (0,1), (1,0), (1,1)]
```

## 字典推导式

```python
{x: x**2 for x in range(5)}                              # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 反转键值对
d = {"a": 1, "b": 2}
{v: k for k, v in d.items()}                            # {1: "a", 2: "b"}
```

## 集合推导式

```python
{x % 3 for x in range(10)}                               # {0, 1, 2}
```

## 生成器表达式

写法与列表推导式相同，但用**圆括号**而非方括号。**惰性求值**——不会一次性生成所有结果，而是每次迭代时才计算下一个值，省内存。

```python
gen = (x**2 for x in range(10**6))   # 不会立即生成 100 万个值
next(gen)  # 0
next(gen)  # 1

# 常用于 sum、max 等不需要一次性持有所有数据的场景
sum(x**2 for x in range(10**6))      # 无需中间列表，省内存
```

# 函数参数

## 五种传参方式

```python
def func(a, b, c=0, *args, **kwargs):
    """
    a, b    —— 位置参数（必传）
    c       —— 默认参数（可选）
    *args   —— 接收多余的位置参数，打包为元组
    **kwargs —— 接收多余的关键字参数，打包为字典
    """
    pass

# 1. 位置传参
func(1, 2)

# 2. 关键字传参（可调换顺序）
func(b=2, a=1)

# 3. 混合传参（位置在前，关键字在后）
func(1, b=2, c=3)

# 4. 元组解包传参
args = (1, 2, 3)
func(*args)

# 5. 字典解包传参
kwargs = {"a": 1, "b": 2, "c": 3}
func(**kwargs)
```

> `*args` 和 `**kwargs` 的名字只是约定俗成——关键是 `*` 和 `**` 这两个符号。写成 `*items`、`**options` 一样有效。

# import 与 `__name__`

## 导入方式

```python
import os                     # 导入模块，使用时需完整的 os.path
from os import path           # 导入模块中指定名称，直接使用 path
from os import path as p      # 别名

# 相对导入（仅限包内部使用）
from . import sibling         # 同目录下的兄弟模块
from .. import parent_mod     # 上级目录的模块
```

## `__name__ == "__main__"`

每个 Python 文件都有一个 `__name__` 属性：
- 当文件**直接执行**时，`__name__` 为 `"__main__"`
- 当文件**被 import** 时，`__name__` 为模块名

```python
# my_module.py
def helper():
    return "这是一段逻辑"

if __name__ == "__main__":
    # 只有直接运行时才执行
    print("脚本被直接执行")
    print(helper())
```

这个机制让同一个文件既可以作为模块被导入（复用逻辑），也可以作为脚本独立运行（测试入口）。

# collections 模块（略）

`collections` 模块提供了常用容器的扩展类型：

| 类型 | 用途 |
|------|------|
| `defaultdict` | 访问不存在的 key 时自动创建默认值（省去手动判断 key 是否存在） |
| `Counter` | 计数器，统计可迭代对象中元素出现次数 |
| `deque` | 双端队列，两端插入/删除均为 O(1) |
| `namedtuple` | 带字段名的元组，可读性更好 |
| `OrderedDict` | 保持插入顺序的字典（Python 3.7+ 普通 dict 已默认保序） |
