
Python 中三种并发执行的方式：进程、线程、协程。

# 三者对比

| 维度 | 进程 | 线程 | 协程 |
|------|------|------|------|
| 内存 | 独立空间 | 共享进程内存 | 共享线程内存 |
| 切换开销 | 大（内核态） | 中（内核态） | 小（用户态） |
| 适用场景 | **CPU 密集** | **IO 密集** | **高并发 IO** |
| 并行能力 | 真正并行（多核） | 受 GIL 限制 | 并发非并行 |
| Python 模块 | `multiprocessing` | `threading` | `asyncio` |

# GIL

CPython 的全局解释器锁：同一时刻只有一个线程执行字节码。IO 等待时 GIL 释放，所以多线程对 IO 密集有效、对 CPU 密集无效。
