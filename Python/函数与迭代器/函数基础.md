
Python 中函数是第一公民——可以赋值给变量、作为参数传递、作为返回值返回。

# 函数定义

```python
def func(a, b, c=0, *args, **kwargs):
    """
    a, b     —— 位置参数（必传）
    c        —— 默认参数（可选）
    *args    —— 多余位置参数打包为元组
    **kwargs —— 多余关键字参数打包为字典
    """
    pass
```

# 五种传参方式

```python
func(1, 2)                    # 位置传参
func(b=2, a=1)                # 关键字传参
func(1, b=2, c=3)             # 混合传参
func(*[1, 2, 3])              # 元组解包传参
func(**{"a": 1, "b": 2})      # 字典解包传参
```
