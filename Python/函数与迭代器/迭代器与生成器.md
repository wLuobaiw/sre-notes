# 可迭代对象、迭代器协议与 yield

## 概念辨析

三个容易混淆的概念：

| 概念 | 定义 | 判断方式 |
|------|------|----------|
| **可迭代对象（Iterable）** | 实现了 `__iter__` 方法，可以被 `for` 遍历 | `hasattr(obj, "__iter__")` |
| **迭代器（Iterator）** | 实现了 `__iter__` 和 `__next__` 方法，维护遍历状态 | `hasattr(obj, "__next__")` |
| **生成器（Generator）** | 一种特殊的迭代器，由含 `yield` 的函数或生成器表达式创建 | `type(obj) is generator` |

三者关系：**生成器 ⊂ 迭代器 ⊂ 可迭代对象**。生成器是最简便的创建迭代器的方式。

---

## 可迭代对象

`list`、`tuple`、`dict`、`set`、`str` 都是可迭代对象——它们实现了 `__iter__`。

```python
from collections.abc import Iterable

isinstance([1, 2, 3], Iterable)    # True
isinstance("hello", Iterable)      # True
isinstance(123, Iterable)          # False
```

`for` 循环的底层机制：

```python
for item in iterable:
    do_something(item)

# 上面的 for 循环等价于：
iterator = iter(iterable)          # 调用 __iter__ 获取迭代器
while True:
    try:
        item = next(iterator)      # 调用 __next__ 获取下一个值
        do_something(item)
    except StopIteration:
        break                      # 迭代结束
```

### 可迭代对象 ≠ 迭代器

```python
lst = [1, 2, 3]
next(lst)         # TypeError: 'list' object is not an iterator

it = iter(lst)    # 手动获取迭代器
next(it)          # 1 —— 迭代器可以调用 next
next(it)          # 2
next(it)          # 3
next(it)          # StopIteration —— 耗尽
```

list 是可迭代对象，自己不是迭代器；通过 `iter()` 获取的才是迭代器，它记住当前"读到哪了"。

## 迭代器

迭代器的核心是**维护遍历状态**——知道"下一次该返回哪个值"。

### 手动实现迭代器

```python
class CountDown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self          # 迭代器自身必须是可迭代对象

    def __next__(self):
        if self.current <= 0:
            raise StopIteration   # 迭代结束的信号
        self.current -= 1
        return self.current + 1
```

### 迭代器的特性

- **单向一次性**：只能前进，不能后退，耗尽后无法重置（除非重新创建）
- **惰性求值**：每次调用 `next()` 才计算下一个值，不会预先生成全部数据
- **省内存**：不像 list 那样一次性把所有数据加载到内存

```python
# 迭代器只能遍历一次
it = iter([1, 2, 3])
list(it)   # [1, 2, 3]
list(it)   # [] —— 已耗尽

# list 可以反复遍历
lst = [1, 2, 3]
list(lst)  # [1, 2, 3]
list(lst)  # [1, 2, 3]
```

## 生成器

生成器是**创建迭代器的最简洁方式**。只要函数中出现 `yield` 关键字，它就不再是普通函数，而是生成器函数——调用它返回生成器对象。

### yield 基本用法

```python
def countdown(start):
    """生成器函数：包含 yield"""
    while start > 0:
        yield start       # 返回一个值，同时在此处暂停
        start -= 1

gen = countdown(3)        # 调用不会执行函数体，而是返回生成器对象
next(gen)  # 3 —— 执行到第一个 yield，返回 3，暂停
next(gen)  # 2 —— 从暂停处继续，直到下一个 yield
next(gen)  # 1
next(gen)  # StopIteration —— 函数体执行完毕

# 生成器可以 for 遍历
for n in countdown(3):
    print(n)              # 3 / 2 / 1
```

### yield 的执行模型

函数执行到 `yield` 时**挂起**（suspended），保留当前状态（局部变量、指令位置等）。下一次 `next()` 调用时从挂起点**恢复**执行。这个过程循环直到函数体结束（自动抛出 `StopIteration`）。

### 无穷生成器

因为生成器是惰性的，可以表示无穷序列：

```python
def infinite_counter():
    n = 0
    while True:
        yield n
        n += 1

counter = infinite_counter()
next(counter)  # 0
next(counter)  # 1
# 只取前5个 —— 如果全部遍历将永不终止
for i, n in enumerate(infinite_counter()):
    if i >= 5:
        break
    print(n)               # 0 / 1 / 2 / 3 / 4
```

### 生成器表达式

用类似列表推导式的语法创建生成器（圆括号）：

```python
gen = (x**2 for x in range(10**6))    # 不会生成 100 万个值
next(gen)  # 0
next(gen)  # 1

# 直接作为函数参数时可以省略外层括号
sum(x**2 for x in range(10**6))       # 无需创建中间列表，省内存
```

生成器表达式 vs 列表推导式：
- 列表推导式：`[x**2 for x in range(n)]` → 立即生成全部结果，占用内存
- 生成器表达式：`(x**2 for x in range(n))` → 惰性生成，每次返回一个，省内存

### yield from —— 委托子生成器

`yield from` 将迭代任务委托给另一个生成器（或任意可迭代对象），避免写嵌套循环：

```python
# 不用 yield from
def flat(nested):
    for sublist in nested:
        for item in sublist:
            yield item

# 用 yield from
def flat(nested):
    for sublist in nested:
        yield from sublist        # 把生成委托给子可迭代对象

list(flat([[1, 2], [3, 4]]))      # [1, 2, 3, 4]
```

`yield from` 不只是语法简化，它还建立了调用方与子生成器之间的**双向通道**（见下文 send/throw）。

## 生成器的高级特性 —— send / throw / close

生成器不只是单向"吐出"值，它还是一个**双向通信通道**。

### send

`send(value)` 将值发送给生成器内部的 `yield` 表达式，替换 `yield` 的返回值：

```python
def accumulator():
    total = 0
    while True:
        inc = yield total         # 执行到这里先返回 total，等外部 send 后再把值赋给 inc
        if inc is None:
            inc = 1               # 首次 next() 或 send(None) 时 inc 为 None
        total += inc

gen = accumulator()
next(gen)          # 0 —— 必须先用 next() 或 send(None) 启动，执行到第一个 yield
gen.send(5)        # 5 —— 恢复执行，yield 返回 5，total=5，到下一个 yield
gen.send(3)        # 8 —— yield 返回 3，total=8，到下一个 yield
gen.send(0)        # 8
```

> 生成器**必须先启动**（`next()` 或 `send(None)`），即在第一个 `yield` 被触发后才能用 `send()` 传值。

### throw

向生成器内部注入异常：

```python
gen = countdown(3)
next(gen)          # 3
gen.throw(ValueError("手动异常"))  # 在 yield 处抛出异常
```

生成器内可以用 try/except 捕获，实现优雅终止或错误处理。

### close

关闭生成器，内部在下一次 yield 处抛出 `GeneratorExit`：

```python
gen = countdown(10)
next(gen)          # 10
gen.close()        # 生成器终止，后续无法 next
next(gen)          # StopIteration
```

## itertools 模块（略）

`itertools` 是标准库中专门处理迭代器的模块，提供了三组工具：

- **无穷迭代器**：`count`、`cycle`、`repeat`
- **有限迭代器**：`accumulate`、`chain`、`compress`、`groupby`、`islice`、`filterfalse`、`takewhile`/`dropwhile`
- **组合迭代器**：`product`（笛卡尔积）、`permutations`（排列）、`combinations`（组合）

```python
import itertools

list(itertools.chain([1, 2], [3, 4]))           # [1, 2, 3, 4]
list(itertools.product("AB", [1, 2]))            # [("A",1), ("A",2), ("B",1), ("B",2)]
list(itertools.islice(range(100), 5, 15, 2))    # [5, 7, 9, 11, 13]
```
