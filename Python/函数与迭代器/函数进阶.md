# 闭包、装饰器与函数式工具

## 闭包

闭包 = **函数 + 其捕获的外部变量**（称为"自由变量"）。

外部变量被封装在函数内部，外部无法直接访问和修改，形成一个**封闭的作用域**。

```python
def make_counter():
    count = 0  # 外部变量，闭包捕获后外部无法直接访问

    def counter():
        nonlocal count  # 声明要修改外层变量（否则只能读取不能赋值）
        count += 1
        return count

    return counter

c = make_counter()
print(c())  # 1
print(c())  # 2
print(c())  # 3
# count 变量被封装在闭包内，外部代码无法直接访问或篡改
```

**关键点：**

- 内部函数引用了外部函数作用域的变量
- 外部函数返回内部函数
- 被捕获的变量生命周期延长，不会随外部函数执行完毕而销毁
- `nonlocal` 关键字用于在闭包内修改外层变量（Python 默认在嵌套函数中对外层变量只能读取，赋值会创建新的局部变量）

**典型应用**：计数器、配置隔离、简单的状态封装（比类更轻量）。

## 装饰器

装饰器本质是**语法糖**：把被装饰函数传入装饰器函数，返回一个包装后的新函数。

### 无参装饰器

```python
import time
import functools

def timer(func):
    """统计函数执行时间的装饰器"""
    @functools.wraps(func)  # 保留原函数的 __name__、__doc__ 等元信息
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)         # 执行原函数
        cost = time.time() - start
        print(f"{func.__name__} 执行耗时: {cost:.4f}s")
        return result
    return wrapper

@timer                         # 等价于：slow = timer(slow)
def slow():
    time.sleep(1)
```

**执行流程**：`@timer` 定义时 → `slow = timer(slow)` → 此后调用 `slow()` 实际调用的是 `wrapper()`，在执行原函数前后加入计时逻辑。

**`@functools.wraps(func)` 的作用**：将 wrapper 的 `__name__`、`__doc__` 等属性替换为原函数的，否则调试和日志中看到的是 `wrapper` 而非真实函数名。

### 带参装饰器

带参装饰器本质是**"返回装饰器的函数"**——多一层嵌套来接收配置参数。

```python
import time
import functools

def retry(max_attempts=3, delay=1):
    """重试装饰器：max_attempts 和 delay 为可配置参数"""
    def decorator(func):                            # ← 这一层才是真正的装饰器
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for i in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except Exception:
                    if i == max_attempts - 1:       # 最后一次尝试，异常直接抛出
                        raise
                    time.sleep(delay)
        return wrapper
    return decorator

@retry(max_attempts=5, delay=2)  # = retry(5,2)(func)
def unstable():
    ...
```

**执行流程**：`@retry(max_attempts=5, delay=2)` → 先调用 `retry(5, 2)` 返回 `decorator`，再等价于 `func = decorator(func)`。

### 类装饰器

用类实例来包装函数，核心是 `__call__` 方法使实例可调用。

```python
import time
import functools

class Timer:
    def __init__(self, func):
        functools.update_wrapper(self, func)  # 类似 @wraps，保留原函数元信息
        self.func = func
        self.total_time = 0                   # 可在实例上保存统计状态

    def __call__(self, *args, **kwargs):
        start = time.time()
        result = self.func(*args, **kwargs)
        self.total_time += time.time() - start
        print(f"{self.func.__name__} 耗时: {time.time() - start:.4f}s")
        return result

@Timer
def my_func():
    ...
```

**类装饰器 vs 函数装饰器**：类装饰器可以用实例属性保存状态（如累计耗时），利于复杂场景。

### 常见应用场景

- **计时统计** —— 性能分析
- **日志记录** —— 自动打印函数调用信息
- **权限校验** —— 检查用户是否有权限执行某操作
- **缓存** —— 如标准库 `@functools.lru_cache`
- **重试机制** —— 网络请求等不稳定操作

## lambda 匿名函数

匿名函数，使用 `lambda` 关键字定义，随用随写。适用于**简单的单表达式逻辑**：

```python
# 语法: lambda 参数: 返回值表达式
add = lambda x, y: x + y
print(add(3, 5))  # 8

# 常见用法：作为排序的 key 参数
users = [{"name": "张三", "age": 25}, {"name": "李四", "age": 20}]
users.sort(key=lambda u: u["age"])                # 按年龄排序

# 不需要给 lambda 命名 —— 直接在调用处写
pairs = [(1, "b"), (2, "a"), (3, "c")]
pairs.sort(key=lambda x: x[1])                    # 按第二个元素排序
```

**限制**：lambda 只能包含单个表达式，不能有语句（赋值、if/for、return 等）。复杂逻辑应写普通函数。

## map / filter / reduce（略）

内置的函数式编程工具，对可迭代对象做批量处理：

| 函数 | 位置 | 功能 |
|------|------|------|
| `map(func, iterable)` | 内置 | 对每个元素应用 `func`，返回结果的迭代器 |
| `filter(func, iterable)` | 内置 | 筛选出 `func` 返回 `True` 的元素 |
| `reduce(func, iterable)` | `functools` 模块 | 累积计算（如累加、累乘） |

```python
nums = [1, 2, 3, 4, 5]

list(map(lambda x: x**2, nums))              # [1, 4, 9, 16, 25]
list(filter(lambda x: x % 2 == 0, nums))     # [2, 4]

from functools import reduce
reduce(lambda a, b: a + b, nums)              # 15（累加求和）
```

> 多数情况下，**列表推导式和生成器表达式比 map/filter 更可读**，优先使用推导式。
