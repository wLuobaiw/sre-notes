
Python 的面向对象基于类（class）和实例（instance），核心机制包括封装、继承、多态。

# 基本语法

```python
class Animal:
    def __init__(self, name):          # 构造方法
        self.name = name

    def speak(self):                   # 实例方法
        return f"{self.name} 发出了声音"

class Dog(Animal):                     # 继承
    def speak(self):                   # 重写父类方法
        return f"{self.name} 汪汪叫"
```

# 三大核心概念

- **封装** —— 将数据和行为捆绑在类中，通过 `_` / `__` 前缀约定访问级别
- **继承** —— 子类复用父类的属性和方法，通过 `super()` 调用父类逻辑
- **多态** —— 不同子类对同一方法有不同实现，调用方无需关心具体类型
