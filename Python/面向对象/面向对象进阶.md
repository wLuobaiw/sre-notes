
# 继承与 super()

## 单继承

子类继承父类的属性和方法，通过**方法重写**来定制行为：

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name} 发出了声音"

class Dog(Animal):
    def speak(self):              # 重写父类方法
        return f"{self.name} 汪汪叫"
```

## super() —— 调用父类方法

`super()` 用于在子类中调用父类的方法。最常见的使用场景是在 `__init__` 中先执行父类的初始化逻辑，再扩展子类的特有逻辑。

```python
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)    # 先调父类 __init__ 设置 name
        self.breed = breed        # 再设置子类独有的属性

    def speak(self):
        base = super().speak()    # 先获取父类方法的返回值
        return f"{base}，品种是{self.breed}"
```

`super()` **不是"多态"**——多态是指"不同子类对同一方法有不同实现"。`super()` 只是让你在重写方法时能方便地调用父类版本，避免重复写父类的逻辑。

## 多继承与 MRO

Python 支持多继承。当多个父类中存在同名方法时，Python 通过 **MRO（Method Resolution Order，方法解析顺序）** 来决定搜索顺序。

MRO 使用 **C3 线性化**算法，确保每个类在其父类之前被搜索。

```python
class A:
    def method(self): return "A"

class B(A):
    def method(self): return "B"

class C(A):
    def method(self): return "C"

class D(B, C):   # 多继承：B 在前，C 在后
    pass

d = D()
print(d.method())          # "B" —— 按 MRO 顺序，B 先于 C
print(D.__mro__)           # D → B → C → A → object
# 查看 MRO 可用：类名.__mro__ 或 类名.mro()
```

`super()` 正是按照 MRO 的顺序找到"下一个"类的方法，**不一定是直接父类**——这是理解多继承中 `super()` 行为的关键。

# 魔术方法

魔术方法（Magic Methods / Dunder Methods）是以**双下划线**开头和结尾的特殊方法，用于定制对象的内置行为。

## 字符串表示

| 方法 | 用途 | 触发方式 |
|------|------|----------|
| `__str__` | 面向用户的字符串表示 | `str(obj)` / `print(obj)` |
| `__repr__` | 面向开发者的字符串表示 | `repr(obj)` / 交互环境直接输入变量 |

经验法则：`__repr__` 应尽可能返回一个可以直接重建对象的表达式，做不到则返回有意义的技术描述。

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __str__(self):
        return f"Point({self.x}, {self.y})"

    def __repr__(self):
        return f"Point(x={self.x}, y={self.y})"

p = Point(3, 4)
print(p)       # Point(3, 4) —— 调用 __str__
p              # Point(x=3, y=4) —— 交互环境调用 __repr__
```

## 比较运算符

| 方法 | 运算符 | | 方法 | 运算符 |
|------|--------|-|------|--------|
| `__eq__` | `==` | | `__ne__` | `!=` |
| `__lt__` | `<` | | `__le__` | `<=` |
| `__gt__` | `>` | | `__ge__` | `>=` |

实现 `__eq__` 后 Python 会自动推导 `__ne__`（取反）。实现 `__lt__` 和 `__eq__` 后，配合 `@functools.total_ordering` 可自动推导其余比较方法。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __eq__(self, other):
        return self.score == other.score

    def __lt__(self, other):
        return self.score < other.score

a = Student("张三", 90)
b = Student("李四", 85)
print(a > b)   # True —— 虽然没定义 __gt__，但 Python 通过 __lt__ + __eq__ 推导
```

## 算术运算符

| 方法 | 运算符 | | 方法 | 运算符 |
|------|--------|-|------|--------|
| `__add__` | `+` | | `__sub__` | `-` |
| `__mul__` | `*` | | `__truediv__` | `/` |
| `__floordiv__` | `//` | | `__mod__` | `%` |
| `__pow__` | `**` | | | |

每个运算符还有**反向版本**（`__radd__` 等，当左操作数不支持该运算时调用）和**增强赋值版本**（`__iadd__` 等，对应 `+=`）。

## 其他常用魔术方法

| 方法 | 用途 | 示例 |
|------|------|------|
| `__hash__` | 返回哈希值，决定对象可否作为 dict 的 key | 实现 `__eq__` 后通常也需实现 `__hash__` |
| `__call__` | 让实例可以像函数一样被调用 | `obj(args)` |
| `__iter__` | 返回迭代器，使对象可被 `for` 遍历 | `for x in obj:` |
| `__next__` | 定义迭代器的下一个值 | 配合 `__iter__` 使用 |
| `__getitem__` | 支持索引访问 `obj[key]` | 实现后支持切片、遍历 |
| `__setitem__` | 支持索引赋值 `obj[key] = value` | 配合 `__getitem__` |
| `__len__` | 支持 `len(obj)` | 返回容器长度 |
| `__bool__` | 定义对象的布尔值 | `if obj:` — 决定对象被视为 True 还是 False |
| `__enter__/__exit__` | 上下文管理器，配合 `with` | 见 [异常处理与上下文管理](../异常与上下文/异常处理与上下文管理.md) |

## 迭代器示例

```python
class CountDown:
    """倒计时迭代器"""
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self          # 迭代器自身也是可迭代对象

    def __next__(self):
        if self.current <= 0:
            raise StopIteration   # 迭代结束必须抛出此异常
        self.current -= 1
        return self.current + 1

for n in CountDown(3):
    print(n)                 # 3 / 2 / 1
```

# @property / @staticmethod / @classmethod

## @property

将方法调用伪装成**属性访问**。常用于：

- 计算属性（值由其他属性推导而来，无需存储）
- 属性访问控制（赋值时做校验）
- 保持接口简洁（对外是属性，对内是方法）

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):           # getter —— 像读属性一样调用
        return self._radius

    @radius.setter
    def radius(self, value):    # setter —— 像赋值一样触发校验
        if value < 0:
            raise ValueError("半径不能为负")
        self._radius = value

    @property
    def area(self):             # 只读计算属性（无 setter）
        return 3.14159 * self._radius ** 2

c = Circle(5)
print(c.area)      # 78.53975 —— 像属性一样直接访问
c.radius = 10      # 像属性一样赋值，背后调用了 setter 方法
```

## @classmethod

**类方法** —— 第一个参数是 `cls`（类本身）而非 `self`（实例）。

- 可通过类直接调用，无需创建实例
- 常用于**工厂方法**（创建实例的替代途径）
- 可以被子类继承，`cls` 自动指向子类

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_birth_year(cls, name, birth_year):
        """工厂方法：通过出生年份创建用户"""
        return cls(name, 2026 - birth_year)

u = User.from_birth_year("张三", 1990)  # 直接用类调用，无需实例
```

## @staticmethod

**静态方法** —— 不需要 `self` 也不需要 `cls`，本质是放在类命名空间里的普通函数。

- 与类的逻辑相关，但不操作实例数据也不操作类数据
- 可通过类或实例调用

```python
class Math:
    @staticmethod
    def clamp(value, low, high):
        """将值限制在 [low, high] 区间内"""
        return max(low, min(value, high))

Math.clamp(15, 0, 10)   # 10 —— 直接用类调用
```

## 三者对比

| 类型 | 第一个参数 | 调用方式 | 访问实例属性 | 访问类属性 | 典型场景 |
|------|:--------:|---------|:----------:|:--------:|---------|
| 普通方法 | `self` | `obj.method()` | 能 | 能 | 操作实例数据 |
| `@classmethod` | `cls` | `Class.method()` | 否（无self） | 能 | 工厂方法、多态构造 |
| `@staticmethod` | 无特殊参数 | `Class.method()` | 否 | 需通过类名 | 工具函数 |
| `@property` | `self` | `obj.prop`（无括号） | 能 | 能 | 计算属性、访问控制 |

# __slots__（略）

`__slots__` 限制实例可拥有的属性，用更紧凑的方式存储属性。默认每个 Python 实例用 `__dict__` 字典存储所有属性，内存开销较大；`__slots__` 改为固定大小的数组，节省内存。

```python
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
p.z = 3   # AttributeError —— 不允许添加 __slots__ 之外的属性
```

代价：不能动态添加新属性、某些继承场景需要多留意。

# 元类 metaclass（略）

元类是"类的类"——控制类的**创建过程**。普通类由 `type` 创建，自定义元类继承 `type` 可拦截类的创建、自动修改类属性、注册类等。是 Python 最深层的机制之一，框架（如 Django ORM、SQLAlchemy）常用，日常业务代码很少需要。

---

# abc 抽象基类（略）

`abc` 模块提供 `ABC` 基类和 `@abstractmethod` 装饰器，用于定义**接口规范**——强制子类必须实现特定方法，否则无法实例化。

---

# dataclasses 数据类（略）

`@dataclass` 装饰器（Python 3.7+）自动为类生成 `__init__`、`__repr__`、`__eq__` 等样板方法，减少重复代码。适合主要用于存储数据的类（配置、DTO 等）。
