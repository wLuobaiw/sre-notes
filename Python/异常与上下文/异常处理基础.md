
Python 用 `try/except/else/finally` 捕获和处理异常，用 `with` 管理资源。

# try/except/else/finally

| 子句 | 执行时机 |
|------|---------|
| `try` | 监控代码块 |
| `except` | 捕获指定异常 |
| `else` | 未发生任何异常时执行 |
| `finally` | 无论如何都执行（释放资源） |

# with 上下文管理器

```python
with open("data.txt", "r") as f:
    content = f.read()
# 退出 with 块时文件自动关闭，无需 finally
```
