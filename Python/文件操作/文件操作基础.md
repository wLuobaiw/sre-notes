# open() 模式与基本读写操作

Python 通过内置 `open()` 函数操作文件，支持文本和二进制模式。

## 核心模式

| 标识 | 含义 | 文件不存在时 |
|:----:|------|:-----------:|
| `r` | 只读 | 报错 |
| `w` | 只写 | 创建（存在则清空） |
| `a` | 追加 | 创建 |
| `x` | 独占创建 | 创建（存在则报错） |
| `t` | 文本模式（默认） | — |
| `b` | 二进制模式 | — |
| `+` | 扩展读写 | — |

## 基本用法

```Python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello")
```
