
# 文件读取

# `open()`



Python 文件打开模式的核心是**基础权限**（r/w/a/x）+**数据类型**（t/b）+**扩展读写**（+）的组合，其中**t（文本模式）是默认值**（可省略）、**b（二进制模式）为加密 / 非文本文件刚需**，以下按「**基础分类 + 完整组合**」整理，标注**常用程度**（⭐越多越常用），覆盖所有官方支持的模式，无遗漏：

- ### 基础核心标识（所有模式的组合基础）

| 标识 |  核心含义  |                           关键特性                           |
| :--: | :--------: | :----------------------------------------------------------: |
| `r`  |    只读    |             文件不存在则**报错**，指针在文件开头             |
| `w`  |    只写    |         文件不存在则**创建**，存在则**清空原有内容**         |
| `a`  |    追加    |      文件不存在则**创建**，指针在文件末尾，仅追加不覆盖      |
| `x`  |  独占创建  |   文件不存在则**创建**，存在则**报错**（避免覆盖已有文件）   |
| `t`  |  文本模式  | 默认值（可省略），按**字符**处理，需指定`encoding`，支持换行符自动转换 |
| `b`  | 二进制模式 | 按**字节**处理，**不可指定 encoding**，适用于加密 / 图片 / 视频等非文本文件 |
| `+`  |  扩展读写  | 配合 r/w/a/x 使用，赋予「只读 / 只写」模式**额外的写入 / 读取权限**，不改变原模式的核心特性 |

- ### 完整文件操作模式

| 模式  | 组合说明  | 常用程度 |           核心特性（文件存在 / 不存在 + 权限）           |                    适用场景                    |
| :---: | :-------: | :------: | :------------------------------------------------------: | :--------------------------------------------: |
|  `r`  | `rt` 简写 |  ⭐⭐⭐⭐⭐   |             存在则只读，不存在则报错（文本）             |   读取文本配置（YAML/JSON）、日志、明文信息    |
| `rb`  |  `r + b`  |  ⭐⭐⭐⭐⭐   |            存在则只读，不存在则报错（二进制）            |      读取加密文件、图片、视频、字节流数据      |
| `r+`  | `rt+`简写 |   ⭐⭐⭐    |  存在则读写（不清空），不存在则报错（文本）；指针在开头  |          文本文件的局部修改、读写结合          |
| `rb+` | `r + b +` |   ⭐⭐⭐    | 存在则读写（不清空），不存在则报错（二进制）；指针在开头 |       加密文件的局部修改、二进制数据读写       |
|  `w`  | `wt` 简写 |  ⭐⭐⭐⭐⭐   |          不存在则创建，存在则清空（文本）；只写          |  新建 / 覆盖写入文本（解密后的明文、新配置）   |
| `wb`  |  `w + b`  |  ⭐⭐⭐⭐⭐   |         不存在则创建，存在则清空（二进制）；只写         |     新建 / 覆盖写入加密字节流、二进制文件      |
| `w+`  | `wt+`简写 |    ⭐⭐    |          不存在则创建，存在则清空（文本）；读写          |    新建文本文件并立即读写（极少用，可替代）    |
| `wb+` | `w + b +` |    ⭐⭐    |         不存在则创建，存在则清空（二进制）；读写         |   新建二进制文件并立即读写（加密文件初始化）   |
|  `a`  | `at` 简写 |  ⭐⭐⭐⭐⭐   |    不存在则创建，存在则追加（文本）；只写，指针在末尾    |           文本日志追加、明文信息补录           |
| `ab`  |  `a + b`  |  ⭐⭐⭐⭐⭐   |   不存在则创建，存在则追加（二进制）；只写，指针在末尾   |          加密日志追加、二进制数据补录          |
| `a+`  | `at+`简写 |    ⭐⭐    |    不存在则创建，存在则追加（文本）；读写，指针在末尾    |    文本文件追加后立即读取（需手动移动指针）    |
| `ab+` | `a + b +` |    ⭐⭐    |   不存在则创建，存在则追加（二进制）；读写，指针在末尾   |    加密文件追加后立即读取（需手动移动指针）    |
|  `x`  | `xt` 简写 |   ⭐⭐⭐    |          不存在则创建，存在则报错（文本）；只写          |      新建文本文件（避免覆盖已有重要文件）      |
| `xb`  |  `x + b`  |   ⭐⭐⭐    |         不存在则创建，存在则报错（二进制）；只写         |   新建加密文件（避免覆盖已有加密数据，推荐）   |
| `x+`  | `xt+`简写 |    ⭐⭐    |          不存在则创建，存在则报错（文本）；读写          |     新建文本文件并读写（避免覆盖，极少用）     |
| `xb+` | `x + b +` |    ⭐⭐    |         不存在则创建，存在则报错（二进制）；读写         | 新建加密文件并读写（避免覆盖，加密初始化刚需） |
