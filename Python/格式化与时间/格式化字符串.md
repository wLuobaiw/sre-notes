
# 什么是格式化字符串

Python 的字符串格式化核心是**将变量、表达式或数值以指定格式嵌入到字符串中**，使得字符串可以更多元的按照我们预期的显示

# 格式化方式

Python有**三种**主流的格式化方式

## 一、% 操作符（旧式）

这是 Python 早期的格式化方式，类似 C 语言的`printf`，兼容性好但功能有限，现在不推荐优先使用。

**基本语法**

```python
"格式化字符串" % (值1, 值2, ...)
```

格式化字符串中用`%占位符`表示要替换的位置，常见占位符：

- `%s`：字符串（万能占位符，可兼容数字、列表等任意类型）
- `%d`：整数
- `%f`：浮点数（默认保留 6 位小数）
- `%.nf`：浮点数，保留 n 位小数

**示例**

```python
# 1. 单个变量
name = "小明"
print("你好，%s！" % name)  # 输出：你好，小明！

# 2. 多个变量（需用括号包裹）
age = 18
score = 98.5
print("姓名：%s，年龄：%d，成绩：%.1f" % (name, age, score))  # 输出：姓名：小明，年龄：18，成绩：98.5

# 3. 特殊场景：百分比格式化
rate = 0.85
format_str = "通过率：%.2f%%" % (rate * 100)
print(format_str)  # 输出：通过率：85.00%（注意%%表示输出%符号）
```

## 二、str.format () 方法（Python2.6+）

这是对旧式格式化的改进，更灵活、可读性更好，兼容 Python2 和 Python3，是过渡阶段的主流方式。

**基本语法**

```python
"格式化字符串".format(值1, 值2, ...)
```

格式化字符串中用`{}`作为占位符，支持**位置参数、关键字参数、索引复用**。

**示例**

```python
# 1. 位置参数（按顺序匹配）
print("姓名：{}，年龄：{}".format("小红", 20))  # 输出：姓名：小红，年龄：20

# 2. 索引指定（可打乱顺序、复用）
print("年龄：{1}，姓名：{0}，再次显示姓名：{0}".format("小红", 20))  # 输出：年龄：20，姓名：小红，再次显示姓名：小红

# 3. 关键字参数（更直观，推荐）
print("姓名：{name}，成绩：{score:.2f}".format(name="小红", score=99.456))  # 输出：姓名：小红，成绩：99.46

# 4. 字典解包（适合变量多的场景）
info = {"name": "小刚", "age": 19, "score": 88.0}
print("姓名：{name}，年龄：{age}，成绩：{score}".format(**info))  # 输出：姓名：小刚，年龄：19，成绩：88.0
```

**特点**

- 支持更灵活的参数匹配方式，可读性优于`%`操作符；
- 兼容低版本 Python，适合需要跨版本运行的代码。

## 三、f-string（推荐，Python3.6+）

这是 Python3.6 及以上版本推出的**最优方案**，语法最简洁、执行效率最高，也是现在官方推荐的方式。

**基本语法**

在字符串前加`f`或`F`，字符串内用`{变量/表达式}`直接嵌入内容，支持格式指定

### 基础用法

```python
name = "小李"
age = 21
# 直接嵌入变量
print(f"姓名：{name}，年龄：{age}")  # 输出：姓名：小李，年龄：21

# 嵌入表达式（无需额外计算）
print(f"明年年龄：{age + 1}")  # 输出：明年年龄：22
print(f"姓名大写：{name.upper()}")  # 输出：姓名大写：小李 → 注意：中文无大写，若为英文则生效（如name="Tom" → TOM）
```

### 格式定制（和`format`语法一致）

#### 通用结构

```
{表达式:格式规范}
```

- `{}`：格式化占位符的边界，是 f-string 的标识；
- `表达式`：要格式化的内容（变量、数字、表达式、函数调用等）；
- `:`：**分隔符**，左边是 “要格式化的内容”，右边是 “怎么格式化”（格式规范）；
- `格式规范`：是控制格式化规则的核心。

#### 规范数字输出

该格式化的**格式规范**部分完整语法为

```
[[填充字符]对齐方式] [符号] [#] [0] [宽度] [,] [.精度] [类型]
```

- 仅当指定「宽度」时，「填充字符 + 对齐方式」「0（零填充）」才会生效；

- 不同类型的数字（整数 / 浮点数）对「精度」「类型」的支持不同，下文会明确区分。

1. **`[填充字符]对齐方式` → 填充与对齐**（可选）

   这是一个**组合可选段**，用于控制数字的对齐方式和不足宽度时的填充字符。

   | 组成部分 |                      含义 & 可选值                      |                           规则                           |                示例（num=123）                 |
   | :------: | :-----------------------------------------------------: | :------------------------------------------------------: | :--------------------------------------------: |
   | 填充字符 |     单个字符（默认是空格），用于补全不足宽度的位置      | 只能是**单个字符**，多字符会报错<br>省略则默认用空格填充 |    `{123:*-^10d}` → `***123****`（填充`*`）    |
   | 对齐方式 | `>`：右对齐（数字默认）<br>`<`：左对齐<br>`^`：居中对齐 |            必须和「宽度」配合使用，否则无效果            | `{123:<10d}` → `123       `（左对齐，宽度 10） |

2. **`[符号]` → 符号显示规则**（可选，仅对数字有效）

   控制正负号的显示方式，是数字格式化中对齐正负数字的关键。

   | 可选值 |                        含义                        |          示例（num=123 /num=-123）           |
   | :----: | :------------------------------------------------: | :------------------------------------------: |
   |  `+`   |       强制显示正负号（正数加`+`，负数加`-`）       | `{123:+5d}` → `+123`；`{-123:+5d}` → `-123`  |
   |  `-`   |            仅显示负数的`-`（默认行为）             | `{123:-5d}` → ` 123`；`{-123:-5d}` → `-123`  |
   |  空格  | 正数前加 1 个空格，负数前加`-`（用于正负数字对齐） | `{123: 5d}` → `  123`；`{-123: 5d}` → `-123` |

3. **`[#]` → 进制前缀标记**（可选，仅对进制类型有效）

   仅用于整数的进制格式化（`b/o/x/X`），作用是添加进制的 “标识前缀”。

   |                             规则                             |                    示例（num=15）                    |
   | :----------------------------------------------------------: | :--------------------------------------------------: |
   | 加`#`：显示进制前缀（二进制`0b`、八进制`0o`、十六进制`0x/0X`） | `{15:#04x}` → `0x0f`（宽度 4，补 0，加十六进制前缀） |
   |               不加`#`：仅显示进制数字，无前缀                |            `{15:04x}` → `000f`（无前缀）             |

4. **`[0]` → 零填充简写标记**（可选，优先级最高）

   这是「填充字符 = 0 + 右对齐」的**简写形式**，优先级高于普通的「填充字符 + 对齐方式」，且符号会放在 0 前面（区别于普通填充）。

   |                  规则                   |                 示例（num=-123）                 |
   | :-------------------------------------: | :----------------------------------------------: |
   | 等价于`0>`（填充 0 + 右对齐），符号前置 | `{-123:06d}` → `-00123`（符号占 1 位，剩余补 0） |
   |   普通填充 0：符号会和数字一起右对齐    |   `{-123:0>6d}` → `00-123`（和`06d`效果不同）    |

5. **`[宽度]` → 最小显示长度**（可选）

   指定格式化后字符串的**最小总长度**（整数），是所有填充 / 对齐生效的前提。

   |                   规则                    |                 示例（num=123）                  |
   | :---------------------------------------: | :----------------------------------------------: |
   |      数字位数 < 宽度：用填充字符补全      | `{123:5d}` → `  123`（前面 2 个空格，总长度 5）  |
   | 数字位数 ≥ 宽度：按实际长度显示（不截断） | `{123456:5d}` → `123456`（超过宽度 5，完整显示） |
   |        省略宽度：取数字的实际长度         |                `{123:d}` → `123`                 |

6. **`[,]` → 千位分隔符**（可选，用于大数格式化）

   用于给大数字添加千位分隔符，提升可读性，Python3.6+ 也支持`_`（效果和`,`一致）。

   | 可选值 |                 示例（num=1234567）                 |
   | :----: | :-------------------------------------------------: |
   |  `,`   |            `{1234567:,d}` → `1,234,567`             |
   |  `_`   |            `{1234567:_d}` → `1_234_567`             |
   |  拓展  | 浮点数也支持：`{1234567.89:, .2f}` → `1,234,567.89` |

7. **`[.精度]` → 精度控制**（可选，区分整数 / 浮点数）

   精度的含义随「类型」不同而变化，是新手最易混淆的点。

   |      数字类型       |                精度含义                |                         示例                          |
   | :-----------------: | :------------------------------------: | :---------------------------------------------------: |
   | 浮点数（f/F/e/E/%） |   指定小数点后保留的位数（四舍五入）   |  `{123.456:.2f}` → `123.46`；`{0.85:.1%}` → `85.0%`   |
   |    浮点数（g/G）    | 指定有效数字的位数（自动去掉末尾的 0） | `{123.456:.3g}` → `123`；`{1234.56:.3g}` → `1.23e+03` |
   |  整数（d/b/o/x/X）  |         **无效**（指定会报错）         |        `{123:.2d}` → 报错（整数不能指定精度）         |

8. **`[类型]` → 核心：数字的显示类型**（可选，有默认值）

   决定数字以何种形式展示（进制、小数、百分比等），是格式化的核心，省略时整数默认`d`，浮点数默认`g`。

   **（1）整数专属类型** 

   | 类型符 |             含义              |             示例（num=15）              |
   | :----: | :---------------------------: | :-------------------------------------: |
   |  `d`   |      十进制整数（默认）       |             `{15:d}` → `15`             |
   |  `b`   |          二进制整数           |            `{15:b}` → `1111`            |
   |  `o`   |          八进制整数           |             `{15:o}` → `17`             |
   |  `x`   |       十六进制（小写）        |             `{15:x}` → `f`              |
   |  `X`   |       十六进制（大写）        |             `{15:X}` → `F`              |
   |  `n`   | 类似`d`，但使用本地千位分隔符 | `{1234567:n}` → `1,234,567`（中文系统） |

   **（2）浮点数专属类型** 

   | 类型符 |                含义                |      示例（num=123.456）       |
   | :----: | :--------------------------------: | :----------------------------: |
   | `f/F`  |   固定小数格式（f 小写，F 大写）   |   `{123.456:.2f}` → `123.46`   |
   | `e/E`  |    科学计数法（e 小写，E 大写）    | `{123.456:e}` → `1.234560e+02` |
   | `g/G`  | 通用格式（自动选 f/e，去掉末尾 0） |    `{123.456:.3g}` → `123`     |
   |  `%`   |   百分比格式（数字 ×100，加 %）    |     `{0.85:.1%}` → `85.0%`     |

#### 组合示例

通过复杂示例理解各部分的组合逻辑：

```python
# 示例1：填充* + 居中 + 强制+号 + 千分位 + 1位小数 + 浮点数
num = -1234.56
print(f"{num:*^+10,.1f}")  # 输出：*+-1,234.6*
# 拆解：
# *：填充字符；^：居中；+：强制符号；10：宽度；,：千分位；.1：1位小数；f：浮点数

# 示例2：零填充 + 十六进制 + 进制前缀 + 宽度6
num = 255
print(f"{num:#06x}")  # 输出：0x00ff
# 拆解：
# #：加进制前缀；0：零填充；6：宽度；x：十六进制小写

# 示例3：空格符号 + 左对齐 + 宽度8 + 百分比 + 1位小数
num = 0.789
print(f"{num: <8.1%}")  # 输出：78.9%   （空格符号+左对齐，宽度8）
```































```python
# 百分比格式化
rate = 0.789
```

```python
# 字符串对齐（左对齐<，右对齐>，居中^，总长度10）
text = "Python"
print(f"左对齐：{text:<10}结束")  # 输出：左对齐：Python    结束

```
