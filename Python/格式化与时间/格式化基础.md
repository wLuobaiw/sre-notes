# 字符串格式化与 datetime 处理

Python 提供了三种字符串格式化方式，以及 datetime 模块处理日期时间。

## 三种格式化方式

| 方式 | 语法 | 版本 | 推荐度 |
|------|------|------|:-----:|
| `%` 操作符 | `"name: %s" % name` | 早期 | 不推荐 |
| `str.format()` | `"name: {}".format(name)` | 2.6+ | 可用 |
| f-string | `f"name: {name}"` | 3.6+ | **推荐** |

## f-string 示例

```Python
name = "张三"
age = 25
print(f"姓名：{name}，年龄：{age}，明年：{age+1}")
```
